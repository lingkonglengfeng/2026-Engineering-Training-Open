# 开发与协作

[Core](../../Core/README.md)列出固件职责，[双路视觉](../../vision/README.md)列出相机与 PC 入口，[测试](../../tools/tests/README.md)提供无设备回归命令。

开工前从目标赛制分支建立工作分支。修改跨端接口时同时核对发送、解析、单位、时序及旧版本兼容。硬件改动须核对 `.ioc`、外设初始化和 `.uvprojx`。提交或 PR 中记录联动部署组合、验证命令和结果、已知限制和回退方法。流程见 [贡献说明](../../CONTRIBUTING.md)。
