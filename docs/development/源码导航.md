| `ZDT_Motor_Task` | [zdt_motor.c](../../Core/Src/zdt_motor.c)：电机服务、导航接入、比赛脚本与控制台命令的主要集成点 |

## 电脑与相机链路

```text
STM32 SET 任务 → 对应相机 UART → Wi-Fi 控制连接 → PC 服务/识别
相机图像      → Wi-Fi 图传     → PC 识别结果
PC 结果       → Wi-Fi 控制连接 → 对应相机 UART → STM32
```

## 跨模块改动核对点

1. **消息**：确认发送端、桥接端和主控接收端，保持现有 8 字节协议语义。CAM2 障碍使用专用 `0x86`，不挪用旧 `0x08`；细节见 [CAM2 说明](../../vision/maixcam_qr_bridge/README.md)。
2. **坐标**：注明单位和参考点。障碍 `gap` 为车头前沿到圆柱近侧外壁的毫米净距，`right` 向右为正；场地毫米坐标与内部栅格行号分别核对，不把像素直接写进地图。
3. **动作完成**：核对请求、实际反馈与完成回执；发送成功不等于机械到位。不能跳过原工位后直接报告完成。
4. **部署**：固件、PC、CAM1 桥和 CAM2 桥分别列版本，明确哪些必须一起更新。
5. **行为边界**：保持既有速度和工序；新增或改变停机保护前先告知车主。正常避障暂停与 `NO_PATH` 保持暂停有别，详见 [V194](../electrical/2026-10-27_CAM2障碍融入比赛流程_V194.md)。
