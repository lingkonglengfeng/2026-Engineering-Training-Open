# 线材与端子采购清单

> 版本：v2.3（补达妙 XT30(2+2) 与 GH1.25-3P 线材规格；含 v2.2 补光灯定案）
> 日期：2026-08-29
> 依据：`原理图/SCH_原理图1（底部拓展板）`、`原理图2（电源板）`、`原理图3（步进电机总线控制板）`，均为嘉立创EDA V1.0（2026-08-29 更新）
> 统一原则：**电池口 XT60（电源板现状保留），电机动力 XT30，信号/小电源全车 XH2.54（唯一例外：两个视觉模块是 PH2.0-4P，板上已焊）**
> 保护方案：主直流空开 1P C20（DC250V 档）串入电池正极，TVS 用 SMBJ26A

## 1. 整车供电与信号架构（识别自原理图，作为清单依据）

- **电源板**：XT60 进线 + 自锁开关（MT-0-123）→ 电机电源端子 XT30；金升阳 **URB4805YMD-10WR3** 出 5V；**AMS1117-3.3** 出 3.3V；**7.4V 模块（带 EN 使能脚）**专供舵机；各轨 XH2.54-3P 接口 ×2
- **底部拓展板**：核心板 2×30P 双排座；板载 AMS1117-3.3、W25Q64；全部外设口 XH2.54（串口屏/HWT101/SWD/按键×2/LED 板×2）；**视觉模块为 PH2.0-4P ×2**；IPS 用 2.54 排针；调试串口排针；舵机口 ×2；供电口 XT30W
- **步进电机总线控制板**：双 SN65HVD230；**FDCAN1 → P1~P6 六路步进接口**（XH2.54-4P：VCC/CANH/CANL/GND，含 120Ω）；**FDCAN2 → 达妙接口**（XT30 动力 + 2P 信号）；电机动力经 XT30 输入后由板上 VCC 分配
- ⚠ **注意**：原理图的 CAN 分配（FDCAN1=六步进、FDCAN2=达妙）与《接口冻结表 v1》**相反**，冻结表需改版确认；当前 zdt_motor.c 在 FDCAN1 与原理图一致

## 7. 器件级差异备忘（识别原理图时发现，与旧文档冲突处）

| 项 | 原理图现状 | 旧文档/交互图 | 处理建议 |
|---|---|---|---|
| CAN 分配 | FDCAN1=6 步进、FDCAN2=达妙 | 冻结表相反 | **2026-09-14 澄清**：本条"原理图现状"与**实车不符**。实际接线与代码都是 **FDCAN1=达妙（PA11/PA12）、FDCAN2=张大头步进（PB12/PB13）**，与冻结表一致。此前"达妙驱动按 FDCAN2 写"是照抄了旧驱动头文件的错误注释（该注释已修）。**以冻结表 + 代码为准** |
| 舵机电压 | 7.4V 专用模块（带 EN） | 文档 6V/UBEC | 按原理图执行；EN 建议接 MCU 做 SAFE_STOP 断电 |
| 电池口 | XT60 | 曾建议统一 XT30 | 保留 XT60，仅电机支线 XT30 |
| 5V 来源 | 金升阳 URB4805YMD-10WR3（带 CTRL） | LM2596 模块 | 按原理图执行 |
| 视觉模块接口 | PH2.0-4P | 统一 XH2.54 | 板上已焊，接受例外，成品线按 PH2.0 买 |
| 按键数量 | 板上 2 个（CN2/CN3） | 冻结表曾有 4 个 | **已确认砍 MODE/DEBUG**（冻结表 v1.2），PA8/PA10 释放 |
| LED 输出 | 板上无 LED 驱动电路 | 冻结表曾有 4 路 LED | **已全砍**（v1.2），PD1/PD2 转补光灯 PWM（软件 PWM 或 PB0/PB1 硬件 PWM，待电控确认） |
| FDCAN3 | 原理图未使用 | 冻结表曾列为预留 | **已取消**（v1.2），PF6/PF7 释放 |
| 补光灯供电 | 电源板无 12V 轨 | 旧电源文档有 12V/1A 轨 | **已定案（v2.2）**：补光灯 3.3V 直驱（PD1/PD2 软件 PWM），取电自 3.3V 轨；12V 方案作废 |
| 20AWG→XH 转换 | 板载 XH2.54 座 + 成品线 | 曾建议转接洞洞板 | **取消洞洞板** |
