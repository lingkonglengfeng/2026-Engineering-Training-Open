# 硬件与接线

主控 STM32H723ZGT6，底盘为四麦轮，机械臂由 5 号升降、6 号伸缩及达妙旋转关节组成，夹爪和载物盘使用 PWM 舵机。机器人连接两台 MaixCAM、HWT101 和 W25Q64。

- [工程首页接口表](../../README.md#系统连接)列出数据通道。
- [CubeMX 工程](../../Engineering_Training_Project.ioc)和 `Core/Src` 外设初始化是当前固件引脚的核对入口。
- [原理图目录](原理图/)有分日期的图纸。先确认实际板卡版次，再用图纸核对电源、地、信号电平和 CAN 收发器。
- [车头方向与摆位](2026-10-04_车头翻转与摆位说明.md)、[底盘方向](底盘方向与麦轮排布说明.md)、[场地地图](场地地图与栅格说明.md)说明坐标和轮组关系。涉及参数值时按当前分支确认。

厂商资料通过 ST、达妙和张大头的对应型号渠道获取。图纸用作接线与硬件变更参考，电机方向和零位按装车后的实测标定。
