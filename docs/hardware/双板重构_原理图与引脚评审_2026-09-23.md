# 双板重构：原理图与引脚评审

> 2026-09-23。依据 `原理图/SCH_原理图1/2/3_1-P1_2026-08-29.png`、根目录 `Engineering_Training_Project.ioc`、当前 `Core/Src` 和 `docs/electrical/接口冻结表_v1.md`。这是改版输入清单，不是已完成的嘉立创EDA 原理图；没有可编辑工程/网表，ERC、DRC 和封装针序仍需在 CAD 中复核。

## 1. 现状与目标

| 现状板 | 图中功能 | 双板改造去向 |
| --- | --- | --- |
| 底部拓展板（图 1） | 核心板 2×30P 排母、双舵机、双视觉、串口屏、HWT101、W25Q64、IPS、按键、补光、步进/达妙逻辑接口 | 保留为**主控拓展板**，并入图 3 的两路 CAN 收发器和电机信号插座 |
| 电源板（图 2） | 6S 电池入口/开关、约 24V 动力、5V、3.3V、7.4V 及各轨输出 | 保留为**电源板**，负责电池保护、电压转换和所有电机动力线分配 |
| 步进电机总线控制板（图 3） | 两颗 SN65HVD230、六个步进 4P 口、达妙 XT30(2+2) 口、24V 分配 | 取消独立板；CAN 收发与信号接插件并入拓展板，24V 铜排/输出移至电源板 |

建议板间仅传 `5V`、`GND`、`SERVO_V`、`SERVO_EN`（若由 MCU 控制）和可选 `VBAT_SENSE`。电机 6S 动力电从电源板单独出线。拓展板不承担六个步进电机的总动力电流。两板须有共同的信号地参考；电机/舵机大电流返回电源板，不沿主控排针或细信号线回流。

## 3. 两板功能边界和连接器

### 电源板

`6S 电池 → 主开关/急停动力链 → 保险及反接/浪涌保护 → 分支保护 → 24V 电机输出、5V DC/DC、舵机 DC/DC`。保留电池 XT60，电机动力用满足最大电流的 XT30/端子分别输出。5V 经独立限流支路送拓展板；两路视觉模块和屏幕的实际电流之和须纳入 5V 预算。舵机电源单独 DC/DC、独立使能和输出滤波，电压按**两只舵机的确切型号/铭牌**确认。电源板提供 `BAT+`、`5V`、`SERVO_V`、`GND` 测试点。

图 2 现状缺可见的电池保险、反接保护和 TVS；7.4V 模块 `EN` 画为悬空。新图需补齐或在 BOM 中明确它们位于板外。`URB4805YMD-10WR3` 官方额定是 5V/2A、输入 18–75V；6S 电池规划截止 18V，电机瞬间压降可能使它触到工作下限。若保持这一家族，`URB2405YMD-10WR3` 为 9–36V、5V/2A，更贴合 6S 范围，但仍须按浪涌、保护和总负载复核。两种模块的 `CTRL` 开路为启动，接低电平为关断；不可把 3.3V MCU GPIO 直接接到以电池输入地为参考的控制脚而不核电平/隔离。

### 主控拓展板

保留图 1 的核心板插座和既有外设口；把图 3 的两颗 SN65HVD230 及 CAN 输出移到本板。CAN 收发器紧靠电机信号连接器；每颗 `RS` **各自**配下拉/斜率控制电阻，RX 路加可断开的 0Ω 和测试点，CANH/CANL 加接口侧保护，120Ω 终端用跳线选择。分别在板上丝印 `DM_CAN_1M` 和 `ZDT_CAN_500K`，不再使用容易颠倒的 `CAN1/2` 泛称。

六台步进电机走一条总线主干、各支线尽量短；终端仅装在物理两端。原图 3 六个 4P 口同时含 `VCC_OUT`，若保留原线束和 4P 插头，就必须把 6S 动力送过拓展板并按总电流重新选连接器、铜厚、线宽和回流路径。这与“拓展板只转接信号”的目标冲突。推荐**电源板给电机动力，拓展板给 CANH/CANL/GND**，电机端通过线束合并；最终连接器针序须按电机实物线束定义。

传感器接口分为 `3.3V I2C`、`3.3V UART`、`GPIO 输入` 三类，分别丝印电压、信号、1 脚方向。预留限位/载物检测座可以先做为 `3.3V/GND/SIG`，但信号 GPIO **尚未冻结**；不可把未分配的脚直接写入量产针序。视觉模块继续保留 PH2.0-4P，先核供电和 TX 输出电平；若 TX 为 5V，则在 STM32 RX 前加电平转换或经证实适用的输入保护。

## 4. 必须改的具体问题

1. **CAN 映射**：实际 `FDCAN1=达妙`、`FDCAN2=六步进`。图 3 的 `FDCAN_TX/RX`、`FDCAN2_TX/RX` 与物理座容易倒置；新图使用设备名网络名，逐针核对 `PA12→D`、`PA11←R`、`PB13→D`、`PB12←R`。
2. **CAN RS 和终端**：图 3 两颗收发器的 `RS` 共用一个 10k 网络；应各配电阻。两组 120Ω 固定在板上；应改跳线并按实际总线端点装配。
3. **RX路径可测性**：收发器前后、连接器和MCU排针建议设TP，装配后常规检查通断。2026-10-03用户确认旧问题为代码原因，不能再以“PB12曾短路”作为改板或故障判断依据。
4. **3.3V 来源唯一**：图 2 电源板自带 AMS1117-3.3，其他文档又称拓展板/核心板有 LDO。先确定核心板是否自带并输出 3.3V，再选择单一主电源；多个 LDO 输出不能直接并联。AMS1117 在 5V→3.3V、0.6A 时约耗散 1.02W，需实测电流并核散热。
5. **舵机电压与急停**：图 1/2 为 7.4V，旧文档有 6V；依据舵机实物确定。把 7.4V 模块的 EN 接入明确电路，急停应能切断舵机/电机动力使能，且断电不切 MCU/视觉的故障显示电源。
6. **供电与接插件**：图 2 3.3/5/7.4V 轨用相同 3P 外形，必须逐针丝印、电压分组及防误插；电机动力不能经 XH2.54 信号座或主控排针承载。
7. **外设版本漂移**：旧的交互式原理图、电源设计文档和快速参考卡保留了 6V/12V/三板/FDCAN3 等旧方案；它们不能作为本次绘图事实源。

## 5. CAD 重画与验收顺序

1. 在嘉立创EDA 复制现有工程为新版本，保留原版；分两个板项目/两套原理图。板间连接器先定针序和额定电流，再摆器件。
2. 电源板按“入口→保护→转换→滤波→输出”排布；拓展板按主控排针、通信、传感器、执行器、调试接口分区。功率回流和数字地连接点及路径在图上标明，避免 CAN/UART 回流穿过电机大电流区。
3. 拓展板合并 CAN 后，逐条与 `.ioc`、`Core/Src/fdcan.c` 和实车接线核网；所有外部口丝印针号、信号、电压与 1 脚。核 BOM、封装和线束视角。
4. 出板前执行 ERC/DRC、逐网核对、元件/位号/丝印不重叠、去耦/TVS/终端靠近对应器件；两板各测电源短路、5V/3.3V/舵机轨和 CAN 断电阻值，再分级上电。

**待确认后才能定版的三项**：两只舵机的准确型号及允许电压；六台步进的现有 4P 线束能否拆分动力与 CAN；核心板是否自带 3.3V 稳压。三项均影响电源及连接器图，不能靠现有截图推定。
