## 1. 芯片架构与 LQFP144 封装特性

- **引脚总数**：144 引脚（包含 113 个通用 I/O 引脚、2 个专用模拟输入引脚 PC2_C/PC3_C、28 个电源/接地/稳压引脚及 1 个 BOOT0 输入引脚）。
- **工作电压**：主电源 VDD 为 1.62V ~ 3.6V（典型 3.3V）；模拟电源 VDDA 为 1.62V ~ 3.6V；USB PHY 电源 VDD33USB 为 3.0V ~ 3.6V。
- **最高主频**：550 MHz（VDD LDO 供电或外部 SMPS 供电）。
- **内核存储**：高达 1024 KB Flash，564 KB SRAM（包含 128 KB DTCM、64 KB ITCM、128 KB AXI-SRAM、128 KB AHB-SRAM1、64 KB AHB-SRAM2、32 KB AHB-SRAM3、4 KB 备份 SRAM）。
- **通信外设**：3 个 FDCAN 控制器（支持 CAN FD）、最多 5 个 USART + 5 个 UART + 1 个 LPUART、最多 6 个 SPI、4 个 I2C、2 个 SDMMC 接口、1 个 USB OTG HS（内置 PHY）。

## 2. 引脚电气特性与缩写说明

### 2.1 引脚类型（Pin Type）

- **I/O**：通用输入/输出引脚（Input / Output bidirectional）。
- **I**：纯输入引脚（Only Input，如 BOOT0）。
- **S**：电源或地引脚（Supply Pin，如 VDD、VSS、VCAP、VBAT、VDDA 等）。
- **ANA**：带专用模拟通道的引脚（如 PC2_C、PC3_C）。具体数字复用功能以当前 CubeMX 选项为准；本项目的 CubeMX 已将 PC2_C 显示为 `SPI2_MISO`，但它不作为 IPS200 的通用控制 GPIO 使用。
- **RST**：复位引脚（带双向弱上拉的复位脚 NRST）。

### 2.2 I/O 结构与耐压特性（I/O Structure）

- **FT**：五伏容限引脚（5V Tolerant，可承受最高 5.5V 电压）。
- **TT**：三点三伏耐压引脚（3.3V Tolerant，不可接超过 VDD 的电压，如 PA4、PA5、PA7、PC4、PC5 等）。
- **_h**：具备高速特性（High-speed capability）。
- **_f**：具备快速 I2C Fm+ 特性（Fast Mode Plus 20mA 灌电流能力）。
- **_a**：支持模拟功能（Analog capability，可直连 ADC / DAC / OPAMP / COMP）。
- **_u**：带 USB HS 高速特性。
- **B**：专用 Dedicated BOOT0 专用输入结构。

### 3.3 W25Q64 与现有 SPI1 的接入建议

W25Q64 的普通 SPI 模式可以与其他 SPI 从设备共享同一组总线信号，不需要额外占用一个 SPI 外设：

| W25Q64 信号  | 建议连接                   | 说明                         |
|:---------- |:---------------------- |:-------------------------- |
| SCK        | SPI1_SCK / PA5         | 与其他 SPI1 从设备共用             |
| MOSI / IO0 | SPI1_MOSI / PA7        | 与其他 SPI1 从设备共用             |
| MISO / IO1 | SPI1_MISO / PA6        | 与其他 SPI1 从设备共用             |
| CS#        | PA4（当前软件片选，规划给 W25Q64） | 每个 SPI 从设备必须有独立片选；空闲必须为高电平 |
| WP#、HOLD#  | 3.3V 上拉或 GPIO          | 不使用 Quad-SPI 时保持为高电平       |

接入前在 CubeMX 中把 SPI1 数据帧设为 **8 Bits**、主机模式、MSB first，并确认 SPI 模式/频率符合 W25Q64 数据手册；当前生成的 `Core/Src/spi.c` 仍是 `SPI_DATASIZE_4BIT`，不能直接用于按字节发送的 W25Q64 驱动。当前 `.ioc` 计算的 SPI1 速率约为 91.67 Mbit/s，实际应按所用 W25Q64 型号额定值和走线信号完整性确认，调试时可先降低分频。W25Q64 的 CS# 空闲时必须为高电平，而当前 `MX_GPIO_Init()` 将 PA4 初始化为低电平，接入后需在 CubeMX/初始化代码中改为高电平。若只沿用 PA5/PA6/PA7 并新增一个未占用的 GPIO 作为 CS，不需要重新分配 SPI1 的 SCK/MISO/MOSI；若改用 SPI2/其他 SPI，或采用 Quad-SPI/OCTOSPI，则需要在 CubeMX 中启用对应外设、选择不冲突的复用引脚并重新生成代码。

### 3.5 IPS200 的 CubeMX 配置清单（由操作者执行）

需要新增 SPI2，但不改动 SPI1、系统时钟、TIM4 或 USART10。打开根目录 `Engineering_Training_Project.ioc` 后按以下顺序配置：

1. 在 **Connectivity > SPI2** 选择 `Full-Duplex Master`；`Hardware NSS Signal` 保持 `Disable`，与当前截图一致。将 `PA9` 选为 `SPI2_SCK`、`PC1` 选为 `SPI2_MOSI`、`PC2_C` 保持 CubeMX 自动分配的 `SPI2_MISO`。不得使用 `PB10`（USART3_TX）、`PB13`（FDCAN2_TX）或 `PD3`（LED_COM）作 SPI2 时钟。
2. 在 **System Core > GPIO** 中分别设置：`PC6` 的 User Label 为 `IPS_CS`、`PC7` 为 `IPS_DC`、`PC8` 为 `IPS_RST`；均为 `Output Push Pull`、`No pull-up and no pull-down`、`Low` speed、初始输出电平 `High`。PC6/PC7/PC8 不是 SPI 复用脚，不要选成 SPI 功能。
3. 在 **Connectivity > SPI2 > Parameter Settings** 设置 `Data Size = 8 Bits`、`First Bit = MSB First`、`Clock Polarity = Low`、`Clock Phase = 1 Edge`、`NSS = Software`、`Baud Rate Prescaler = 32`，CRC 保持关闭。SPI123 内核时钟当前约为 `183.333 MHz`，故首版 SCK 约为 `5.73 Mbit/s`，低于参考工程的 10.5 Mbit/s，适合首次点屏。
4. 在 **Clock Configuration** 不修改时钟树；`550 MHz` 的 SYSCLK 和 `183.333 MHz` 的 SPI123 内核时钟保持当前自动配置即可。
5. 点击 **Generate Code**。生成后应能在 `.ioc`、`Core/Inc/main.h`、`Core/Src/gpio.c`、`Core/Src/spi.c` 中看到 SPI2、IPS 标签、三个 PC 控制脚的 GPIO 初始化、`hspi2`、`SPI_DATASIZE_8BIT` 和 `SPI_BAUDRATEPRESCALER_32`。生成结束前不要把 IPS 驱动文件加入工程。

代码生成后，请把更新后的 `.ioc` 保留在工程根目录；届时再将本节中 SPI2 与 PC6/PC7/PC8 的状态由“待配置”改为“已配置”，并以新 `.ioc` 重新核验本表。

## 6. 电源、接地与去耦设计建议

STM32H723ZGT6 为 550MHz 超高主频 MCU，对电源完整性要求极高：

1. **数字电源 (VDD / VSS)**：
   
   - LQFP144 共有 9 组 VDD/VSS 电源对（Pins 17/16, 30/38, 39/51, 52/61, 62/83, 72/94, 84/107, 108/120, 121/130, 131/144 等）。
   - **每个 VDD 引脚必须放置一颗 100nF 高频去耦陶瓷电容（0402 或 0603 封装）**，且电容焊盘必须紧贴芯片引脚，通过过孔直接就近打入内层完整地平面。
   - 建议在板级电源入口处并联 2~3 颗 4.7μF ~ 10μF 低 ESR 陶瓷电容。

2. **内部稳压电容 (VCAP Pins 71, 106)**：
   
   - VCAP 是 MCU 内部 1.2V 核心逻辑电压稳压输出。
   - **Pin 71 与 Pin 106 必须各连接一颗 2.2μF ~ 4.7μF 低 ESR（< 0.1Ω）陶瓷电容到 GND**。禁止在 VCAP 引脚上施加任何外部电压！

3. **模拟电源与基准 (VDDA / VSSA / VREF+)**：
   
   - Pin 33 (VDDA) 连接 100nF + 1μF 陶瓷电容至模拟地。
   - Pin 32 (VREF+) 连接 100nF + 1μF 陶瓷电容至 VSSA。
   - 建议在 VDDA 前端增加磁珠（如 100MHz @ 600Ω）与数字 VDD 隔离。

4. **USB 电源 (VDD33USB Pin 95)**：
   
   - 若使用 USB 功能，Pin 95 必须接 3.0V ~ 3.6V 电源，并旁路 100nF + 1μF 电容；若不用 USB，可直接连接至 VDD。

## 7. 硬件设计与 PCB 走线注意事项

1. **CAN 总线 (FDCAN1 / FDCAN2 / FDCAN3)**：
   
   - PA11/PA12 (FDCAN1) 与 PB12/PB13 (FDCAN2) 直连板载 CAN 收发器（如 SIT1044 / TJA1051 / SN65HVD230）。
   - PF6/PF7 (FDCAN3) 为预留扩展接口。
   - CAN 收发器的 CANH/CANL 差分对走线阻抗控制为 120Ω，等长并行走线，末端必须预留 120Ω 终端电阻（或跳线选配）。

2. **UART 串口与视觉模块**：
   
   - USART1 (PB14/PB15) 与 USART2 (PA2/PA3) 连接摄像头模块，走线应尽量平直，避免穿越电感和开关电源区域。
   - 陶晶驰串口屏 (USART3: PB10/PB11) 与调试串口 (UART4: PC10/PC11) 需共地，建议在串口 TX/RX 串联 22Ω~33Ω 阻尼电阻抑制过冲。

3. **舵机控制信号 (PD12 / PD13)**：
   
   - 舵机信号为 50Hz 周期 PWM，峰值电流较大的是舵机供电线路而非信号线。
   - **舵机电源严禁从 STM32 的 3.3V LDO 供电**，必须使用大电流独立 6.0V DC-DC 降压模块（建议持续 3A 以上），舵机地线与 MCU 地线必须在电源入口处单点大面积共地。

4. **按键输入**：
   
   - 当前工程按键为 PA0、PA1、PA8、PA10；其中 PA1 配置为 EXTI1 下降沿中断。建议在硬件端并联 100nF 贴片电容与 10kΩ 上拉电阻，配合软件消抖（10ms~20ms）消除机械触点抖动。
