# V224：PD1外部中断与按键日志

[电控版本索引](README.md) · [上一版V223](2026-10-29_DM保持门限与机械臂提速_V223.md)

启动按键PD1由普通输入周期读电平改为**内部上拉、上升沿/下降沿双边沿EXTI1中断**，开关接地为低电平有效。`EXTI1_IRQHandler`继续使用现有HAL入口，回调只读取当时电平并记录毫秒时间戳，ISR共享字段均为`volatile`；不在中断内延时、打印、调用RTOS或执行机械臂/底盘动作。

EXTI1只能选择一个GPIO端口，原PA1的下降沿中断配置改为上拉普通输入，EXTI1映射交给PD1。当前源码没有PA1的中断业务回调。GPIO源码和CubeMX `.ioc`同时更新，避免重新生成时恢复PA1映射。

原任务只消费中断通知和30ms消抖到期，不再周期读取PD1。初始化读取一次当前电平；后续电平变化来自中断。接点抖动在任务消费前合并为最新电平及边沿时间，日志记录消费到的中断状态，不保证逐个打印全部抖动毛刺。

消抖仍为30ms：高电平稳定后允许下一次低电平闭合，长按只触发一次；上电已经按住时须先松开。启动仍仅在`MATCH_WAIT_START_OK`接受，走原`OK`检查和使能流程。保持硬件边沿的原时间戳，准备阶段按下的按键不会因为任务稍后运行或消抖结束而变成READY后的新启动。

## 日志

UART4/上位机串口日志中按`[START KEY]`筛选。没有按键事件时不重复刷屏；打印由原任务执行。

```text
[START KEY] PD1 EXTI1 both edges, pull-up active LOW; debounce30ms in task; boot-held release/press; READY only
[START KEY] EXTI1 level=LOW/pressed edge_tick=12345ms; debounce30ms
[START KEY] PD1 pressed -> OK; release required before next press
[START KEY] launch accepted; MATCH LEAVING
[START KEY] EXTI1 level=HIGH/released edge_tick=12500ms; debounce30ms
[START KEY] stable HIGH/released; next LOW press armed
```

非READY阶段按下打印`press ignored`；原启动条件不满足打印`launch rejected by original OK checks`并保留原具体拒绝原因；上电低电平或未形成新按下时打印`stable LOW/held`。这些是按键状态记录，没有新增停机动作。
