# V205：下降阶段结束后，伸出50mm与闭爪并行

按用户最新时序要求，将圆盘抓取改为：**下降ACK确认 → 下降预计时间结束 → 伸出50mm与闭爪同时开始 → 伸出预计时间及闭爪PWM均完成 → 抬升**。

下降阶段的“结束”沿用已选择的ACK＋预计运动时长，不新增位置起步或到位等待。真实物理动作效果仍需实机核对。

## 相对V204的变化

- 伸出量20→50mm，基准是固定等待位置，下一轮会先回等待位再执行，不是逐次累加。
- 触发物料后先只给5号下发下降，6号保持等待位，夹爪保持张开。5号100ms无有效ACK重发同一绝对目标、最多3次，仍然保留。
- 收到下降ACK后，按5号行程/RPM/234档曲线单独计算下降时间；这段时间结束才下发6号绝对伸出目标及闭爪，两条动作在同一次ArmTask轮询中连续发出，日志打印安排在两条命令之后。
- 伸缩目标按`等待百分比 + 50/标定总行程×100`换算，使用6号独立的预计运动时间。抬升要求该时间已结束，并且夹爪PWM爬坡完成，避免夹爪先完成时提前抬升。
- 下降时仍使用原等待位5度偏移检查；伸出命令发出后允许等待位至50mm目标的移动区间。原有健康、故障、取消、反馈等待和120秒动作超时规则保持。

默认178mm伸缩行程下，等待位约25.416%，50mm目标约53.51%，位于原有效行程内。默认配置的指令估算约为下降0.38秒、伸出0.85秒；闭爪PWM约0.24秒，与伸出重叠。实际负载和驱动器响应不能由这些估算证明。
