# PLACE先缩回再转向 V72

按用户要求，将载物盘放置改成顺序执行：5号升到TOP → 6号缩回PLACE目标−4°并确认停止保持 → DM转向载物盘+162.8250°并确认实际到位 → 5号下降PLACE高度 → 张爪225°。

连续物料取放与单次`arm material`内部的载物盘放置都调用同一个PLACE流程，因此同步生效；手动`&arm place`也采用此顺序。PICK、START/CAMERA及圆环已有流程不在此次变更范围。

6号缩回期间DM使能并保持启动缩回时的实际角度，不提前下发载物盘转向目标。6号原生绝对位置到位、STOP后新反馈保持确认完成，才发送DM转向命令；已有小残差编码器修正继续适用。若6号已经位于缩回目标，不额外发送位置命令，但仍需至少3个不同的新位置反馈、跨200ms稳定确认。

DM转向到位后再检查6号目标，才允许5号下降。缩回超时、堵转、位置异常、停止或姿态失败都不会继续转向、下降或松爪。夹爪仍需处于稳定闭合状态才能开始PLACE。

速度保持：6号60RPM，DM默认90°/秒，5号120RPM。零点、抓取后直升TOP及伸出50mm不改。

同时合入用户在视觉对话的窗口修改：默认(0,−30,30,30)，中心累计上移30px、横纵半宽各30px。320×240图像窗口中心(160,90)，边界x130..190、y60..120。静态初始化与ArmMaterial_Init均同步，重启恢复此默认；仅电控窗口偏移，相机MAT_PX原点仍(160,120)，不在相机再叠加偏移。现有固件空闲或WAIT_RED也能发 `&arm material window 0 -30 30 30` 临时生效。

关键回显顺序：

```text
[ARM PLACE] retract reach FIRST; DM holds current angle
[ARM REACH] STOP queued; verify fresh held position
[ARM PLACE] reach actual target/STOP hold confirmed; NOW rotate DM
[ARM PLACE] DM actual target/hold confirmed after retraction
[ARM PLACE] 3/4 DM/reach confirmed; lower lift
[ARM PLACE] 4/4 open grip
```

烧录V72后先测一轮：

```text
&arm material loop limit 1
&arm material loop start
```

状态/停止：

```text
&arm material loop status
&arm material loop stop
```
