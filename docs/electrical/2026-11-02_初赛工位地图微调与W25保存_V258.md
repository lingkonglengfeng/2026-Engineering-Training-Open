# V258 PRELIM / PC2.6.9：工位地图与±10mm微调

按本次确认，只微调工位停车点，采用用户给定的每轴基准±10mm范围。保留2400×2400mm规则底图、50mm栅格、黄区、设备台面、启停区和路线中间点；界面显示上述区域作位置参照。仅更新初赛，决赛仍V245/PC2.6.7。

## 操作

1. 烧录 `Engineering_Training_Project_V258_PRELIM.hex`，关闭旧上位机，重新打开桌面“视觉上位机”或 `比赛版本/初赛/启动初赛上位机.cmd`。界面版本为PC2.6.9，新增“工位地图”页。相机程序不需更新。
2. 在车辆/机械臂空闲时接入串口，点击“读取主控地图”。页面先核对初赛V258及以后固件，再读取四工位数据；不能连接旧固件后误发地图写入。
3. 选择工位，在X/Y输入框按1mm步进修改；主图可选点并放大，局部放大图可点击/拖动蓝点。输入坐标为车中心坐标，原点在场地左下，X向右、Y向上，单位mm。
4. 空心点是基准、绿色是主控当前RAM、蓝色是输入预览。预览本身不下发指令。“基准值填入预览”也只填界面。
5. 点击“应用全部到RAM”，四工位8个偏移量一次校验、整组应用，并自动读回确认。修改立即用于后续路线；应用不发车、不移动机械臂、不改变当前车辆位姿。
6. 点击“保存当前RAM到W25”，看到 `[FIELD MAP SAVE] OK` 才算保存。未应用的蓝色预览不在保存范围内。下次上电自动读取已保存工位微调；“从W25读回”恢复已保存值并更新界面。

运行中读写地图返回REJECTED，等待空闲后重试；不会为改图新增比赛停机。串口重连后需重新读取，页面不自动下发旧会话的输入。

## 基准与坐标范围

| 工位 | 基准接近停车点X/Y | 允许输入X | 允许输入Y | 视觉完成后车中心锚点 |
| --- | --- | --- | --- | --- |
| 二维码 QR | 2125 / 1150 | 2115～2135 | 1140～1160 | 沿用扫码停车点；没有新增视觉重定位 |
| 圆盘 RAW | 1250 / 2100 | 1240～1260 | 2090～2110 | 1250 / 2090，加同一偏移 |
| ROUGH | 1200 / 400 | 1190～1210 | 390～410 | 1190 / 380，加同一偏移 |
| TEMP | 350 / 1200 | 340～360 | 1190～1210 | 380 / 1280，加同一偏移 |

例如ROUGH输入(1204,394)，偏移是(+4,−6)mm；自动接近目标为(1204,394)，视觉对齐完成后的锚点为(1194,374)。一、二轮共用这一工位偏移。二维码修改扫码停车目标；圆盘/圆环的接近点和视觉锚点一起平移，避免对齐完成后跳回旧坐标。

微调已接入固定路线中的QR/RAW/ROUGH/TEMP目标、RAW退出接近点、命名工位查询、QR/RAW避障后的目标恢复及视觉定位锚点。实际编码器位姿、工位朝向、机械臂姿态、圆环三点取放参数、距离系数、速度和现有检查保持。点位修改不等于改变视觉像素目标框，也不会自动改实物设备位置。

## 串口命令

建议使用以下裸指令；整组应用顺序固定为QR、RAW、ROUGH、TEMP，每组dx/dy，值为整数毫米：

```text
fieldmap status
fieldmap apply 0 0 0 0 4 -6 0 0
fieldmap save
fieldmap load
```

应用成功为 `[FIELD MAP APPLY] OK`；任一值越界、非整数、缺项或多项，整组拒绝且保留原RAM。状态以 `[FIELD MAP BEGIN]` 开始、四条 `[FIELD MAP POINT]` 给出基准/偏移/实际目标/锚点、以 `[FIELD MAP END]` 结束。`source=W25Q64` 表示当前值与最近成功保存/读取的快照一致；RAM有修改时显示RAM。

## W25与兼容

初赛地图微调使用W25Q64倒数18/17扇区：8MB芯片地址 **0x7EE000 / 0x7EF000**。保存4×2个有符号整数偏移，带格式版本、长度、序号和CRC，双银行交替写入并回读校验。读取选择最新有效银行，新记录损坏可回退上一份；读写失败不覆盖有效RAM，其他参数区不写入。

此区独立于底盘16/15、初赛机械臂14/13及8/7、决赛区域、旧导航和PID。首次无地图记录时用零偏移，保持V257路线；启动只读，不自动擦写。与机械臂争用存储锁时让出CPU重试，避免将BUSY误判为无参数。此前保存的参数不需重存。
