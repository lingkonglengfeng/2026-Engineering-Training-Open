| 指令 | 行为 |
| --- | --- |
| `&dm on` | 失能或位置过期时先查询，再检查当前位置、高度/角度和故障，安全使能；首次使能保持当前实际位置 |
| `&dm off` | 发失能并等待新反馈确认，成功回OFF confirmed |
| `&dm zero` | 自动失能/查静止位置，设置程序0°及dm pos软偏置；RAM零点，保持失能 |
| `&dm zero save` | 自动失能/确认静止，发一次FE保存电机内部零点，再查回读接近0，保持失能 |
| `&dm status` | 读最近反馈与CAN状态，本身不保证刷新位置 |

`dm enable/disable/zerohere`沿用on/off/软件zero；`dm zero confirm`沿用永久save。`arm enable dm`、`arm disable dm`、`arm zero dm`仍可用且自动查询；永久命令也支持 `arm zero dm save` / `arm zero dm confirm`。裸dm zero在当前工程入口是软件零点，只有明确save/confirm写电机。

内部零点使用特殊帧 `FF FF FF FF FF FF FF FE`，本车POS模式CAN ID0x101，不写ID/模式/波特率寄存器。FE前须本次FD请求的新合法失能反馈、状态码0、有限位置/速度及|vel|<=0.05rad/s。回读验证须失能、|pos|<=0.02rad、|vel|<=0.05rad/s。FE只发一次，后续FD查询不重发FE、不发FC、不自动使能。

回读近0不等于已证明断电保存。现场需**电机本身断电重上电**，保持机械位置不变，再dm off获取新反馈、dm status检查原始pos仍接近0。只重启MCU、或看到初始化pos=0但fb=0不算验证。
