# 载物盘角度 V35

用户指定默认位置：1号120°、2号210°、3号300°，固化在固件内，重启仍有效。

先发送 `&arm table enable`，然后按需逐条发送：

| 指令 | 角度 | PWM |
| --- | --- | --- |
| `&arm table go 1` | 120° | 1167us |
| `&arm table go 2` | 210° | 1667us |
| `&arm table go 3` | 300° | 2167us |

使能初始角度仍为160°。PD13/TIM4_CH2，50Hz，360°对应500..2500us。已使能时默认500us/s非阻塞斜坡。

`&arm table test 180` 可指定0..360°测试；失能时直接在目标PWM使能。
`&arm table status` 查询PWM推算角度与ramping状态，没有舵机真实角度反馈。
`&arm table save 1|2|3` 在PWM斜坡结束后覆盖对应位置，仅RAM有效，重启恢复120/210/300°。
`&arm table disable` 关闭输出。

本版未烧录或实机运行。
