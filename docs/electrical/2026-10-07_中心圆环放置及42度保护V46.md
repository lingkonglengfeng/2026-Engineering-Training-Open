# 中心圆环放置 V46

目标采用用户实测角度：5号−1017.5482°（raw −185239）、6号−199.8138°（raw −36375）、DM +2.6040°。

## 使用步骤

1. 发送 `&arm pick`，等待 `[ARM PICK] DONE`。
2. 发送 `&arm ring`。检查本次PICK已成功、夹爪仍在闭合PWM预设，满足则显示 `[ARM RING] WAIT_CONFIRM`；此时不运动。
3. 人工确认物料确实夹住，再发送 `&arm ring confirm`。
4. 保持夹爪闭合，5号先升TOP；DM到+2.6040°，6号到−199.8138°；两者到位后5号下降至−1017.5482°，再张开夹爪60°。
5. 完成显示 `[ARM RING] DONE`。保持当前位置，不自动抬升。

`&arm ring confirm` 不能跳过第2步。没有完成PICK时，单独闭合夹爪不够。没有夹持传感器，程序不自动判断是否抓到物料，confirm代表操作者实际确认。

本次上电后的PICK成功标志保存在RAM；重启后需要重新PICK。夹爪打开后标志失效；放置释放后再次ring会拒绝，需重新取料。camera等动作只要保持闭合，不会仅因切换姿态清除已完成PICK标志。

## 状态与停止

```text
&arm ring status
&arm status
&arm query 5
&arm query 6
&arm query dm
&arm stop
```

ring status显示pick_completed、grip_closed、waiting_confirm、active和phase。arm stop取消待确认或正在进行的动作。

测试指令要求比赛流程停止、底盘静止。未自动接入比赛取放料流程，也不进行视觉中心识别；本指令执行的是示教机械臂姿态，需先把小车停在合适位置。

5号目标约下降202.54mm，超过150mm转向保护边界，但DM +2.6040°在低位允许的±42°内，保护仍保留。5号60RPM、6号80RPM。沿用原生位置到位与保持检查。

验证：226项姿态测试包含PICK前拒绝、未请求时confirm拒绝、等待阶段不运动、完整目标到位后释放、释放后失效、start姿态不被覆盖。机械臂驱动及56834项比赛流程回归通过；蓝牙146条指令可达。Keil构建0错误0警告。

未烧录、未实机驱动。角度基于当前参考零点；不要把这个下降姿态重新记录为TOP。

V46补充：下降超过150mm时，DM允许范围改为−42°至+42°。软件回归中校验深度位置±41°允许、±43°拒绝。其余动作及确认条件保持。
