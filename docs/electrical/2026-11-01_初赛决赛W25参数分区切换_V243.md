# V243 FINAL / PC2.6.4：初赛、决赛机械臂参数互不串用

按用户确认，初赛和决赛仍使用两套代码。上位机按钮只准备/读取对应W25参数，不切换比赛流程，不把初赛姿态直接套入正在运行的决赛代码。

## 首次使用

1. 先烧录本包V243 FINAL，重启上位机到PC2.6.4。首次启动会把现有共用区的决赛圆环/舵机参数，校验迁移到新决赛区域；成功后原共用区尚未改变。
2. 机械臂和底盘空闲时，进入 **机械臂控制 → 一键动作 / 参数保存 → 初赛 / 决赛W25参数**。
3. 选择“初赛参数（供V237）”，点击“一键切换 / 准备W25参数”。先把当前已应用的决赛圆环/舵机、四姿态参数保存到决赛区，再准备初赛区。滑块未应用的预览值不保存。
4. 看到`[ARM PROFILE] READY target=PRELIM active=FINAL HAL=0`表示初赛区就绪。**当前RAM和代码仍是决赛，不会移动机械臂。** 此时再烧录包内`Engineering_Training_Project_V237_PRELIM.hex`，初赛代码会读取自己的初赛区。
5. 切回决赛时烧录V243 FINAL，它自动读取决赛独立区。也可在V243里选择“决赛参数（供决赛代码）”点击同一按钮，重新读取决赛保存值并刷新面板。读取会覆盖未保存的RAM修改，但不会发送动作。

首次准备初赛区使用10月30日23:27的V237日志预置：夹爪张开225°、闭合308°，盘槽19/109/199°；圆环三点微调为`(0,5.9,-1.7)`、`(0,0,-1.2)`、`(0,-5.59,-0.723)`，顺序为5号/6号/DM电机角度。两个初赛银行都写入并校验，防止旧决赛值残留在备用银行。

首次成功后会在决赛记录里保存“初赛已准备”标志。此后再次点击准备初赛，只备份当前决赛并核对初赛区，不会重置在初赛V237里后来调整并保存的初赛参数。

## 参数区域

| 代码/参数 | W25区域 | 8MB地址 |
| --- | --- | --- |
| 初赛V237：圆环微调、夹爪与盘槽预置 | 倒数8/7扇区，保持旧格式version1 | 0x7F8000 / 0x7F9000 |
| 决赛V243：圆环微调、夹爪与盘槽预置 | 倒数12/11扇区，独立双银行 | 0x7F4000 / 0x7F5000 |
| 决赛四姿态 | 原倒数10/9扇区 | 0x7F6000 / 0x7F7000 |

普通“保存主控参数到W25”和“从W25读取”在V243里只访问决赛12/11区；四姿态仍用原10/9区。初赛V237不需要改代码，仍访问8/7区，且不读取四姿态区。

决赛区域尚全为空白时才迁移旧共用区；决赛区域已有内容但损坏时，不会再把初赛区当作决赛备份读取。迁移/保存失败会回报FAILED，不继续准备初赛。原始旧记录在决赛备份成功前不覆盖。

本次隔离的是机械臂参数。PID和导航参数仍在原区域，不由这个按钮切换；123/321取料顺序、航向门限、速度及具体运动流程由烧录的代码决定。发车START、零点和行程标定也不由该按钮修改。

**V242及更早的决赛代码仍读取旧共用区，参数分区后决赛必须使用V243或之后的配套版本。** 本次没有代为烧录、连接串口发送指令或操作机器人。
