# 夹取伸出减至25mm V74

按用户“夹取的时候伸缩改小25mm”的要求，将物料抓取时6号向外伸出量从50mm减少25mm，改为25mm。

等待位6号仍为−185.1581°；默认178mm全行程换算后，抓取终点约为−287.4755°。每轮从同一个等待位伸出25mm，不在上轮位置累计。串口目标脉冲及超时根据新目标计算，触发回显同步为extend=25mm和reach +25mm。

5号抓取终点仍为−612.7679°，入窗时下降/6号伸出/闭爪同时启动；抓取后升到TOP，已到TOP时跳过重复上升，放置仍先6号缩回、再DM转向、下降、松爪。6号60RPM、DM90°/秒、5号120RPM及窗口(0,−30,30,30)保持。单次/连续取料与比赛自动接入共享新伸出量。

指令不变，烧录后可先测一轮：

```text
&arm material loop limit 1
&arm material loop start
```

状态/停止：

```text
&arm material loop status
&arm material loop stop
```

生产物料FSM2974项、姿态FSM543项通过；已有回归验证25mm换算、原生绝对目标、同轮下降/伸出/闭爪、停止后保持及循环。Keil结果见build.log；未烧录或驱动实物。
