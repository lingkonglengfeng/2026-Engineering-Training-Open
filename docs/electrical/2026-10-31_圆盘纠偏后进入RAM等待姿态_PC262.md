# PC2.6.2：圆盘纠偏完成后进入RAM等待物料姿态

决赛上位机“机械臂控制 → 决赛圆盘 / 姿态微调”的按钮改为“圆盘纠偏 → RAM等待姿态”。动作顺序：

1. 发送`valign run plate`，先完成比赛圆盘纠偏。
2. 收到新的`[MANUAL ALIGN] DONE`后，发送`arm disc pose wait`。
3. 等到`[ARM MOVE] READY`后，提示已进入等待物料姿态，并结束这组动作；不自动夹取。

等待姿态由主控执行时读取RAM中已应用的三轴微调值，不从上位机滑块的未应用预览值生成角度，也不额外读取W25覆盖RAM。如果刚修改滑块，先点击“应用所选微调到RAM”，再执行圆盘纠偏。

纠偏失败、手动STOP或串口会话变化仍按原动作链逻辑取消后续步骤，不进入等待姿态。移动保持夹爪状态，沿用主控原抬升/旋转/伸缩/下降动作。

本次只修改上位机，主控继续使用V238 FINAL；已烧V238的设备只需更新并重启PC2.6.2，无需重烧主控。若直接在串口单独发送`valign run plate`，仍只执行纠偏；需要同样效果时，收到DONE后再发`arm disc pose wait`。

验证：三姿态PC专项5项通过，覆盖等待纠偏回执才下发RAM姿态、等待姿态READY后才结束，以及纠偏失败不发送移动。没有发送设备指令或重启正在运行的上位机。
