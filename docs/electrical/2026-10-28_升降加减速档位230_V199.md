# V199：升降加减速档位 200 → 230

V198 增大了升降最高转速，原生位置命令的加速度仍为 200 档；本版仅把 5 号升降的驱动器运动档位提高为 **230**，上升、下降共用，保留原有驱动器曲线加减速。

## 协议依据与理论变化

现有 5 号定位走 Emm `0xFD` 绝对位置模式。厂商手册规定：非零档位每改变 1 RPM 所需时间为 `(256 - acc) × 50 μs`，因此档位越大，加减速越快。同一字段同时影响加速和减速。

| 项目 | V198：200档 | V199：230档 |
| --- | ---: | ---: |
| 每改变 1 RPM 的理论时间 | 2.8 ms | 1.3 ms |
| 理论速度斜率 | 约357 RPM/s | 约769 RPM/s |
| 从0到238 RPM | 约0.666 s | 约0.309 s |
| 从0到392 RPM | 约1.098 s | 约0.510 s |

按公式，斜率约为原来的 **2.15 倍**。这些是驱动器指令曲线的估算，不包含负载、电源、反馈与机械响应；短行程可能在达到速度上限前就进入减速，不能当作实测动作时长。

来源：仓库 X42S 厂商手册 V1.0.5 PDF第53页（速度模式）与第57页（Emm位置模式）；[张大头智控发布的 Emm V5.0 Rev1.3](https://devpress.csdn.net/xian/68945b69080e555a88d61cd3.html)第6.3.1节也给出同一公式。

## 修改范围

- `ARM_LIFT_POSITION_ACCEL=230`，仅作为 5 号驱动配置的默认档位。
- 升降速度上限沿用 V198：载料238 RPM、自动空载392 RPM。
- 6号伸缩、标定/寻端点用的原档位和软件速度斜坡参数保留。
- W25启动优先、ROUGH/TEMP共用放置与XY→yaw→XY、普通圆环±2px、第二轮叠层±10px及72mm抬高量沿用 V198。
- 不改抓放位置、到位窗口或停机保护；Flash 参数记录不含这项运动档位，因此读取旧 W25 保存值不会把它改回200。

定位仍由驱动器保持原生绝对目标，主控继续按实际编码器确认到位，不增加到位 STOP。启动标志为 `CAMERA_DEPLOY_V199: LIFT_ACCEL230`，长配置行中显示 `LIFT_FD_ACCEL230`。

## 验证和使用

```powershell
python tools/tests/run_arm_driver_tests.py --native-lift-only
python tools/tests/run_arm_driver_tests.py --speed-profile-only
```

专项覆盖真实 C 调用发送的 230 档、上下行和载料/空载配置、绝对位置目标与原有到位保持逻辑。编译与回归不代表已验证真实负载下的启停和到位精度。

更新本包 V199 主控 HEX 后重新上电；上位机2.5.4、相机桥和已有 W25 参数无需因本次档位调整而更新。可用附带 V198 HEX 回退原200档，不需要擦除 W25。本次没有代为烧录或操作真实电机。

本次结果：Keil 0错误/0警告；原生升降2125、升降/载荷速度配置2715项检查通过，覆盖上下行和载料/空载实际发送的230档参数。程序大小 Code 292226、RO-data 57518、RW-data 6692、ZI-data 314524 字节。
