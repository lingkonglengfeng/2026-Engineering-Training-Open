# 取料后PLACE误判DM失能修复 V67

## 日志原因

用户V66实机回显已经完成：红色入窗、5号下降、6号伸出50mm、夹爪闭合、抬升50mm、选择载物盘1号205°。04:38:06.538启动PLACE，随后04:38:06.594被外层连续取料检查判为 `axis disabled/faulted/stale during loop`，阶段6放置未继续。

代码确认冲突：PLACE复用姿态状态机，开始时主动失能DM，先升5号至TOP，再使能DM并转向载物盘。外层连续取料状态机却在PLACE升高过程中仍要求DM请求使能、反馈使能及500ms内位置反馈，因而把正常的主动失能误认为硬件故障。原仿真PLACE端口没有模拟这一步失能，遗漏了该问题。

## 修复

姿态状态机新增只读状态 `ArmStartPose_IsRotationReleaseExpected()`，仅PLACE的TOP_ENABLE/TOP阶段为真。连续取料仅在PLACE、该状态为真、DM请求已关闭时，认可预期失能。失能电机没有周期位置反馈，该阶段不要求DM新位置；已记录的DM驱动器故障码和任务故障仍检查。TOP结束后原姿态程序重新刷新DM反馈、确认使能再旋转，外层恢复完整使能及位置新鲜度检查。

ZDT5/6反馈、使能、堵转/保护、相机掉线、底盘运动、舵机故障及原机械超时继续检查。PLACE其他阶段的意外失能、请求使能却反馈未使能仍会退出。未修改零点、姿态、高度保护或电机速度。

V66保留：入窗后5号下降原位−612.7679°、6号从等待位向外50mm、夹爪同步305°；窗口默认(0,−20,20,20)。每轮放载物盘1号205°，松爪后回等待位。用户每轮取走槽1物料。

## 测试指令

烧录V67后，小车停在工作位、机械臂空闲，先执行一轮完整连续模式（包含此次故障点）：

```text
&arm material loop limit 1
&arm material loop start
```

状态、停止：

```text
&arm material loop status
&arm material loop stop
```

放置时应出现 `place red into tray1; DM release expected only while PLACE raises to TOP, then enable/rotate`，随后升高、DM/6号转向载物盘、5号下降、松爪，最终 `[MAT LOOP] DONE rounds=1 limit=1`。有限轮数完成保持放置姿态。

连续测试前在停止状态发 `&arm material loop limit 0`，再发start；仍需每轮清空槽1。相机统一main.py及协议不需更新。

## 软件验证

生产物料状态机2832项、姿态状态机374项、跨任务91项通过。新增回归模拟真实PLACE开始主动失能及失能期间反馈变旧，验证仍能进入放置完成并重新等待下一颗；同时覆盖预期失能时真实DM故障、ZDT故障、相机掉线、PLACE非TOP阶段失能及请求使能但反馈失能的故障退出。生产姿态测试验证仅PLACE TOP阶段宣告预期失能、使能转向后取消该状态。
