# V238决赛夹爪：圆盘纠偏、三姿态微调与W25保存

## 版本与分支

- 初赛保留在`codex/arm-control-panel`，基线提交`6956f6e`（V237 / PC2.6.0）。
- 决赛单独维护`codex/final-gripper-control`，主控V238 FINAL、PC2.6.2。
- 主控启动标记`CAMERA_DEPLOY_V238_FINAL`，`arm ui`返回`firmware=238 variant=FINAL disc_profiles=1`。
- 本次没有自动烧录、发送机器人动作或重启正在运行的上位机。新夹爪的尺寸和实际姿态仍需现场标定。

## 上位机怎么用

烧录决赛V238主控后，关闭旧上位机，再通过根目录`视觉上位机.cmd`打开PC2.6.2。相机桥接程序沿用CAM1 1.3.0、CAM2 1.4.0，不需重装。

1. 在“主控串口日志”接入串口，打开“机械臂控制 → 决赛圆盘 / 姿态微调”，点击“读取三套姿态”。
2. 车摆在原料圆盘工位后，点击“圆盘纠偏 → RAM等待姿态”。它会接入双路视觉、先到CAMERA姿态，再使用比赛的CAM1圆盘XY纠偏；纠偏完成后进入主控RAM中已应用的等待物料姿态，到位后结束，不自动夹取，也不推进比赛阶段。详见[PC2.6.2动作顺序](2026-10-31_圆盘纠偏后进入RAM等待姿态_PC262.md)。
3. 分别选择“等待物料”“夹取物料”“放回载物盘”。通过5号升降、6号伸缩、DM角度增量调整；灰色原目标、绿色已应用、蓝色预览，并显示相对下降/伸出毫米数、旋转角和最终三轴角度。
4. 可以用“用当前三轴角度作为目标”把已有有效实测角度换算为所选姿态的增量。滑块和填充本身不发送运动。
5. 每套调好后点“应用所选微调到RAM”。要现场验证，点击“移动到预览姿态”或对应姿态按钮；均沿用原抬升、旋转、伸缩、下降流程并保持夹爪。对应姿态按钮使用已应用参数，预览移动使用当前输入值。
6. 三套都应用后，点“保存三套姿态到W25Q64”。看到`[ARM DISC PARAMS] SAVED HAL=0`才算保存成功；保存的是主控已应用的三套值，不是尚未应用的滑块值。
7. 可以选择颜色和载物盘1/2/3槽，点击“等物料进框 → 夹取 → 放回载物盘”，只执行一次完整抓取。姿态按钮本身不会自动夹取；“放回载物盘当前槽”使用已应用放盘姿态并松爪。

“圆盘纠偏”会移动底盘；上述调试需要车已摆到对应工位。“到夹取终点姿态”只移动三轴，不会自动闭爪。停止仍使用原“停止当前动作”按钮。

## 三套参数如何用于自动流程

用户最终确认：三套参数同时用于决赛自动流程和独立调试。三套都以现有初赛目标为基准保存绝对角度增量，重复应用同一值不会累加。

这三套不包含发车准备START姿态；“准备1号/2号起点”仍使用V237原发车目标。圆盘纠偏先用原CAMERA高位观察姿态，之后抓取动作才进入已微调的等待物料姿态。

| 姿态 | 自动应用位置 | 默认值 |
| --- | --- | --- |
| 等待物料 | 原料台确认CAM1会话后，进入等待识别位置 | 沿用原低位等待、6号−185.1581°、DM−2.0217°；升降由原抓取高度与10mm抬高量换算 |
| 夹取物料 | 新物料顶面进入原抓取框后 | 默认与等待姿态同升降/DM，伸缩终点比原等待位伸出25mm |
| 放回载物盘 | 抓取后返回载物盘，以及同分支原`arm place`/圆环返盘使用的共同放盘终点 | 沿用原放盘高度、6号+1°、DM162.825°；三个盘槽共用三轴姿态，槽位由盘舵机选择 |

等待和夹取的升降/DM相同，则不增加中间姿态动作，直接向夹取伸缩终点运动。两者不同，则先保持6号在等待位置，沿用原抬升/旋转/下降动作达到夹取升降/DM，再开始6号伸缩；在本次等待位置到夹取终点的**实测半程**闭爪。不同高度/旋转的接近动作会占用额外时间。

闭爪/PWM和原伸缩预计时间完成后，沿用原真正TOP起升、实测半程开始DM与回缩、放盘前真正TOP及DM5°提前下降和最终到位松爪。三套增量全为0时，沿用初赛的等待/抓取/放盘目标和时序。

速度和加速度未再提高：6号空爪182/带物246/圆盘抓取262RPM，加速档209；5号、DM、舵机及转向PID沿用V237。23秒进框上限、同目标10ms最多50次补发、原到位/错向/恢复/超时和高度联锁保持，没有新增自动停机条件。原料抓取框和识别规则不在本次修改范围。

## W25Q64与回退

三套姿态存放在独立双银行，地址为容量减10/9个4KB扇区（8MB器件为`0x7F6000`、`0x7F7000`）。记录含独立magic、版本、大小、序号和CRC，交替保存并校验；最新记录损坏时可选择另一份有效记录。

初赛圆环/舵机记录仍使用容量减8/7个扇区，导航和PID仍使用倒数第2/1扇区。本次不覆盖这些记录，也不存储电机零点或行程标定。现有夹爪开闭PWM预置仍通过原“一键动作 / 参数保存”页单独设置和保存。

上电自动读取决赛三姿态；没有有效记录时使用零增量，不新增停机。手动读取只更新RAM，不移动机器人。未成功保存的RAM修改在重启后丢失。

回退初赛用V237 HEX及`codex/arm-control-panel`源码。V237不读取决赛三姿态扇区，已保存的决赛参数仍保留，后续切回决赛可继续读取。

## 串口指令

```text
valign run plate
arm disc points
arm disc trim wait 0 -10 0
arm disc trim grab -5 -15 1
arm disc trim tray 0 -3 0
arm disc pose wait
arm disc pose grab
arm disc pose tray
arm disc params save
arm disc params load
arm disc params status
arm material once 1 2
```

三轴单位为电机角度，增量顺序为5号/6号/DM。最后一条表示指定颜色1进入原抓取框后，抓取并放入载物盘2号槽；颜色线上编号1红、2黄、3蓝、4绿、5浅蓝、6黑。
