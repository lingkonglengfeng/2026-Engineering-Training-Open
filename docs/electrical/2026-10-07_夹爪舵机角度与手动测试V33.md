参考用户指定工程：`D:\projects\Engineering training competition\competition project - 11_26_比赛版`。

- `Device/SERVO/servo.c`：servo360_angle_control使用`500 + 2000/360 × angle`。
- `Device/Car_ctrl/car_ctrl.h`：servo_cputure_angle=238、servo_loosen_angle=186。
- `Device/Car_ctrl/car_ctrl.c`：使用238-14=224软夹、186-40=146大开。

当前板继续使用PD12/TIM4_CH1作为夹爪PWM，20ms周期/1us计数；不会复制参考工程的TIM2引脚配置。换算按0..360度标度、500..2500us，末位取最近1us；启动不输出PWM。

## 一条指定角度测试指令

```
&arm grip test 186
```

使能夹爪并以186度为目标。PWM原本关闭时，第一份PWM就是指定目标，不先跳到另一个初始角度；已经使能时，用现有非阻塞渐变更新目标。

将186换成你指定的0..360角度，支持小数。例如：

```
&arm grip test 200
&arm grip test 224.5
```

逐条发送并观察动作。参考工程常用146..238度，先用186/238验证松开/夹紧位置。这个量程是软件PWM标度，不能代替实际夹爪机械行程的确认。

| 参考动作 | 角度 | PWM目标 |
| --- | --- | --- |
| 大开 | 146° | 1311us |
| 松开 | 186° | 1533us |
| 软夹 | 224° | 1744us |
| 夹紧 | 238° | 1822us |

## 常规操作

| 指令 | 作用 |
| --- | --- |
| `&arm grip enable` | 明确使能，初始PWM为松开186度 |
| `&arm grip angle 238` | 已使能时设置角度，支持小数 |
| `&arm grip open` | 已使能时到默认松开186度 |
| `&arm grip close` | 已使能时到默认夹紧238度 |
| `&arm grip status` | 查看PWM和换算角度、目标、渐变、使能和故障状态 |
| `&arm grip stop` | 冻结当前PWM输出并保持 |
| `&arm grip disable` | 关闭夹爪PWM |
| `&arm grip clear` | 显式清除舵机安全停止闩锁，仍保持PWM关闭；之后重新test或enable |

原有pulse、span、speed和save open/close接口保留。默认渐变500us/s；save记录输出PWM的临时开/合位置，仅RAM。

同一个测试接口也支持当前料盘通道，例如`&arm table test 160`；其PWM仍为PD13/TIM4_CH2，原有料盘角度和工位设置保持。

## 回显和验证

成功测试会显示`[SERVO] grip test requested=...deg target=...us enabled=1 ramping=... HAL=0`。status中的pwm_angle/target_angle由PWM换算，ramping=0表示软件输出已到目标，均不是舵机角度传感器反馈。

非法角度、NaN/Inf、不合法参数拒绝，不因测试指令使能；已有真实安全停止/故障不会被test悄悄清除。串口命令仍交给机械臂owner任务执行，没有ISR打印、阻塞等待或自动开机夹紧动作。

验证包括默认186/238换算、指定238度的首次PWM、已经使能的186度渐变、非法输入不使能、原夹爪位置记录与料盘独立通道回归、完整蓝牙参数传递及固件全工程编译。未烧录或实际操作舵机。
