# 6号中途堵转恢复改进 V83

## 现场记录

V82已正常完成出库、CAMERA展开、圆盘纠偏和前两颗物料的放置。第三颗抓取后，PLACE在DM转向与6号回缩并行时，6号驱动器连续报堵转，三次尝试后停止。

停机后查询：6号−261.4362°，目标约−4°；操作者确认回缩中途、第三颗仍夹着。故障并非发生在最内机械限位。随后flags0x83说明当前反馈未报告堵转/保护，不能证明原目标已经达到；实际角度仍差约257°。软件`tray=0x3`代表只记录1、2槽完成，第三槽未完成。

现有日志能确定“6号中途报堵转、任务按三次失败规则取消”，还不能唯一确定机械受阻、瞬态负载或驱动器设置等现场诱因。本版改进恢复过程，不能宣称已经修复机械故障。

## 恢复过程

正常动作保持6号60RPM、DM90°/秒并行；5号和夹爪仍等两者实际到位后再下降/松爪。

当并行PICK或PLACE的6号原生绝对位置任务报堵转：

1. 6号请求停止；DM改为保持读取到的当前位置，保持使能；夹爪输出不变。
2. 沿用非阻塞停止、150ms间隔、清堵转、新状态确认、使能、新使能确认。
3. 第2次位置尝试降至30RPM；若仍失败，第3次降至15RPM。若原本请求速度更低，不提高到这些上限。
4. 重发同一个绝对目标，不累加相对距离。6号收到ACK或清除堵转不算到位；还要实际位置与STOP后的新静止反馈确认。
5. 6号到位并确认保持后，DM恢复原目标角度。再次确认DM到位，然后才执行下降与松爪。

总共仍为3次尝试，不增加次数，不放宽终点到位、反馈期限或高度保护。原生位置加速度参数150保持。恢复重发后的行程期限按剩余编码器距离和新速度重新计算，范围10..120秒，避免速度降低后仍使用60RPM的旧期限。

恢复中STOP、失能或其他真实故障会取消原目标及待恢复的DM转向，后续反馈不能重新触发它。第3次失败仍停止整套任务，夹爪不会被自动张开；最终停机沿用原StopAll策略，DM不承诺继续使能。

CAMERA、圆盘抓取外伸、独立6号绝对位置命令也使用30/15RPM重试上限；这些动作没有并行PICK/PLACE的DM转向，因此不新增转向暂停动作。

## 新日志

在进入重试及最终失败前保存到串口的最新位置/状态快照：

```text
[REACH RETRY] phase=MONITOR attempt=1/3 ABS=36 speed=60RPM actual=-261.436deg raw=... zero=... flags=0x85 age=.../...ms
[ARM RECOVERY] reach stalled: DM holds current angle, grip unchanged; retry reach FIRST
[REACH RETRY] attempt=2/3 SAME ABS target=36 speed=30RPM resent; wait actual position
[REACH RETRY] attempt=3/3 SAME ABS target=36 speed=15RPM resent; wait actual position
[ARM RECOVERY] reach actual STOP/hold confirmed; resume original DM target; lift/grip wait
```

`phase`区分监控、STOP、清堵转、等待清除、使能、等待使能和重发阶段。位置是最新已收到反馈，旁边保留反馈年龄，不把它冒充为零延迟测量。

## 试跑

启动标记应为`CAMERA_DEPLOY_V83`。V81时钟误判修复、故障快照、V82顶部防重复上升与近TOP限速、三红第一轮流程全部保留，不改零点、槽位和示教终点。

当前失败现场第三颗仍在夹爪。先人工妥善取走这颗、清空已装的槽1/2，恢复正确初始位置，再更新和重新试跑。固件重启只会清空RAM记录，不会清除实物。

```text
&match reset
&prepare 1
```

2号发车位用`&prepare 2`，READY后发OK，其余沿用包内第一轮流程说明。若再次停下，保留新增`REACH RETRY phase=...`日志，再查询：

```text
&arm query 6
&arm status
&arm round1 status
```

## 验证

测试实际生产C：60→30→15RPM、低速请求不被提高、相同ABS目标、三次后停止、真实保护/失联立即退出、旧状态不能确认恢复、低速重试期限；模拟−261°中途堵转且DM尚在旋转时暂停保持，6号完成STOP/新反馈后再恢复DM，不提前下降/松爪；暂停中取消和最终失败不会重启转向。

编译和模拟不代替实机测试。本版未烧录、未操作实际电机；现场中途受阻的物理原因仍需试跑观察。
