# 载物盘PICK夹取提高15mm V85

本版只调整“从载物盘夹起物料，随后放到圆环”的PICK最终闭爪高度，提高15mm。独立`&arm pick`以及ROUGH/TEMP第一轮任务中的载物盘PICK均使用新高度。

| 点位 | V84的5号角度 | V85的5号角度 |
| --- | --- | --- |
| 载物盘PICK最终闭爪 | −540.8633° | **−465.5023°（提高15mm）** |
| 载物盘PLACE最终松爪 | −430.3338° | −430.3338° |
| 三个圆环最终松爪 | −917.0668° | −917.0668° |
| 圆环取回闭爪 | −1017.5482° | −1017.5482° |
| 圆盘视觉取料闭爪 | −562.5272° | −562.5272° |
| 圆盘视觉等待位 | −361.5644° | −361.5644° |

当前标定10mm约50.2407°，提高15mm约75.3611°。新PICK的相对编码器目标约−84742counts。载物盘PICK的6号−4°、DM+162.825°、闭爪305°以及转向前的升降安全高度均不变。

此前PLACE高度由PICK派生，本次将原抓取参考单独保留，避免提高PICK后误把PLACE也抬高15mm。PLACE现在比新PICK高7mm；其绝对示教高度保持V84不变。

PLACE继续先缩回6号并确认STOP后的新保持反馈，再转DM，再下降松爪。6号正常60RPM、堵转第2/3次30/15RPM、5号120RPM、近TOP修正1RPM、150mm/±44°保护和所有零点参考均不变。

按此前“先不修改”的要求，本版未顺带修改CAMERA的`native completed away from target`判断，也没有新增自动补偿、改微步或驱动器参数。

## 使用

启动应显示`CAMERA_DEPLOY_V85`。无新增操作指令，正常流程仍用：

```text
&match reset
&prepare 1
```

2号发车位用`&prepare 2`，等READY再发OK；站内自动动作及各站WAIT_OK流程保持。独立测试可在流程停止时使用`&arm pick`，`&arm pick status`查看新目标。
