# V218：窗口半宽55/半高80，10ms补发与圆盘目标75%

本版按用户截图及追加要求同时调整抓取窗口、6号未启动时的发送间隔和圆盘对齐目标线。

## 抓取窗口与截图对应

| 项目 | 当前设置 |
| --- | --- |
| 图像尺寸、中心 | 320×240；**(160,100)** |
| 半宽、半高 | **55、80** |
| 总宽、总高 | **110×160** |
| 主控偏移和允许范围 | 目标(0,−20)，dx=−55..55、dy=−100..60 |
| 图像范围 | **X=105..215，Y=20..180** |

主控静态及初始化默认值均同步该几何框。截图中的动作预判180ms、图像延迟80ms、观测误差6px是PC运动预判参数，继续由用户保留和设置；机械臂实际抓取高度、三轴姿态及伸出15mm目标不变。本次不改本机 `config.json`、颜色标定或PC运动预判默认值，上位机框参数仍由用户自行应用。

## 10ms、最多50次发送

6号圆盘抓取未实测启动时，**缺少有效ACK、已有ACK但尚未运动两种情况，均按10ms间隔补发原绝对目标**，不再使用此前的100ms/1.5秒两档间隔。

- 初发加补发合计最多50次；持续未动且队列可接受时，第50次约在初发490ms后。按任务轮询执行，忙或调度延迟会顺延，不突发补齐错过的次数。
- 每次仍为同一个绝对目标、原速度和加速度，不相对叠加15mm，不额外STOP或回退。
- 实测运动即停止补发；越过实测半程后闭爪。手动停止取消后续补发；队列BUSY不消耗成功发送次数；第50次后不会发送第51次。
- 50次用尽仍保持张爪，沿用原机械阶段120秒上限，不重置该计时；23秒进框上限继续只影响触发前。

`[MAT REACH RETRY]` 日志包含 `send=次数/50` 和 `gap=10ms`；gap表示配置间隔，串口接收日志的墙钟间隔还会受到缓冲和调度影响。

## 圆盘目标线65%→75%

`PLATE_AIM_Y_FRACTION` 从0.65改为 **0.75**。这里是有效图像高度比例，不是75像素：320×240图像中白色目标线由Y156下移到 **Y180**。绿线显示实际检测的圆盘底部切线，切线落在白线上时Y纠偏误差为0。

PC直接读取同一圆盘模块计算误差，新增对应目标白线与实测绿线显示，避免只移动线而回传仍对旧位置。独立相机圆盘源文件及生成的统一相机源文件同步75%；圆盘拟合阈值、几何筛选和连续三帧确认保持。
