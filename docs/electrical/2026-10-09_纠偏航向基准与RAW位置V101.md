# 纠偏航向基准与RAW位置 V101

## 三项修改

1. ROUGH、TEMP视觉角度和位置纠偏成功、四轮最终反馈到齐且车轮停止后，将当前位置的航向绑定到对应工位的地图朝向。后续导航、直走保持、转向PID和地图速度变换共用修正后的航向，不再回到开机摆车产生的偏差角度。两种发车位、两轮流程均生效。
2. RAW行驶接近点从(1200,2100)改为(1250,2100)mm，即X增加50mm。RAW1、RAW2和命名目标raw统一使用它。视觉到位后的定位锚点仍是(1250,2090)mm，导航接近点与视觉锚点用途不同。
3. 仅第二轮TEMP（三号工位）圆环松爪高度再提高7mm，从比地面高65mm改为72mm。第二轮ROUGH、载物盘、第一轮高度保留原设置。

V100的1、3号圆环放置平面试调继续保留，2号圆环平面参数不变。

## 航向说明

例如1号发车区在ROUGH完成纠偏时，传感器相对角度为+93.5°，实际车头已对准该工位，则导航将该方向认定为+90°。之后直走使用这个方向，下一次转90°也在新基准上计算。跨越±180°时保留原有圈数，避免突然产生整圈误差。

只有视觉角度纠偏确认成功才更新基准，关闭角度纠偏或只完成XY纠偏不会更新。重新prepare/startpose或发送zero重新建立IMU零点时清除旧修正；普通导航和工位切换保留修正。修正只在RAM中，更新时不重新启动3秒IMU零漂标定。

原来的三圆环观测可信度、角度修正幅度及反馈新鲜度要求保留。本修改消除航向基准不一致，实际精度仍需要新一轮实车验证。

## 串口验证

烧录 `Engineering_Training_Project_V101.hex` 后确认启动标记 `CAMERA_DEPLOY_V101`。

正常启动仍为 `&match reset`、`&prepare 1`或`&prepare 2`，START准备完成后发一次新的 `&ok`。后续自动执行两轮。

角度纠偏成功时新增一行：

```text
[VYAW] REFERENCE station=2 before=+93.50 map=+90.00 now=+90.00 delta=-3.50deg; following route uses this heading
```

`&yaw`还会输出navigation（导航航向）、sensor_ccw（传感器左转为正的相对角度）、reference_offset（两者偏移），便于确认修正沿用到了后续路段。
