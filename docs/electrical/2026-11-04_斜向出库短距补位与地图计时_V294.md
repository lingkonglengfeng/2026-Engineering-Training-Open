# V294 PRELIM / PC2.6.26：斜向出库、短距地图补位与地图计时

用户确认修复出库后因25mm横向偏差、6.5°航向偏差导致的两次大转向，并要求斜向出库、地图显示各环节耗时。仅初赛更新，决赛未同步。

## 运动

出库从原来“前进300mm、横移125mm”改成一段名义325mm的地图斜移：1号区地图位移(-125,+300)，2号区(-125,-300)，对应名义车道入口(2125,450)/(2125,1950)。车头保持本段开始的方向，CAMERA展开和二维码识别继续按原流程并行。实际目标继续沿用现有直行距离系数，结束坐标由反馈计算，不强行写成名义落点。旧的非里程模式仍走原两段动作。

导航中的短位移沿用原≤150mm范围、当前车身朝向扫掠检查、工位附加距离限制及原有速度设置。符合条件时，优先按地图方向平移，实时换算车体前进/横移分量，保持当前航向，不再因未满足“纯横移±3°”判定而绕到90°再转回来。当前出库后25mm补位也走此分支。不符合原短位移条件时仍保留原导航处理。

新增地图位移里程模式：四轮编码器增量先还原车体前进/横移，再用相邻实测航向的中值积分到地图坐标；沿指定方向的投影驱动原有减速、到位与停稳流程。短补位和脚本最终地图更新、避障实时车位同步使用实测X/Y。避障急停从已积分实际车位和最新轮位继续计算制动位移，避免用当前航向重新投影整段历史。正常直行/横移的原中位数里程分支保留，地图模式轮差仅作诊断。

二维码终点朝东动作、回库/跨区动作表、W25参数格式、速度/加减速度和圆弧半径不改。不新增停机条件，避障减速/暂停重规划继续使用原流程。斜移日志包含`[ODO MAP]`，短补位包含`[NAV] MAP_TRANSLATE`。

## 地图计时

主控每完成一个环节立即发送原有格式的`[MATCH STAGE]`，不必等整轮结束；最终`[MATCH TIME]`总时长保留。完成耗时为相邻完成里程碑的差，累计为从发车到该里程碑的时间，并行动作不重复相加。

PC2.6.26在工位地图上方显示出库、二维码、第一轮圆盘/ROUGH/TEMP、第二轮圆盘/ROUGH/TEMP、回库九个环节，每项显示“本段耗时 / 完成累计”；当前环节实时计时，停止后冻结并标为未完成。对应工位旁显示已完成环节用时。具体阶段包含该工位的行驶、纠偏和取放等原比赛阶段工作，而非单根机械臂电机的独立耗时。

串口接收线程保存本轮计时快照，晚打开地图不受最近1000条事件上限影响。新发车清空旧轮记录。旧固件没有实时完成回报时，显示明确标注的PC估算；最终主控精确回报会覆盖估算。中途接入且缺少起点或完成记录时显示“—”，不补造时长。计时显示不发送运动或参数指令。
