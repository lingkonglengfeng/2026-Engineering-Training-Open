# 圆环前伸6mm与单指令放置 V54

在V53基础上，圆环放置终点再向前伸出6mm。相对最初示教位置，累计内缩量从15mm改为9mm。

当前6号目标约−162.9795°（raw约−29670counts）。5号仍累计抬高20mm，目标约−917.0668°；DM仍+2.6040°。偏移根据当前轴行程标定动态换算。

## 单指令放置

PICK完成、夹爪仍闭合，并已人工确认夹住物料后，只需：

```text
&arm ring
```

这条命令直接开始圆环放置，不再进入WAIT_CONFIRM，也不需要再发confirm。没有夹持传感器，发出该指令代表操作者已确认物料夹住。仍保留“本次上电后PICK已成功、夹爪已闭合停稳、底盘/机械臂空闲”的条件。

流程：先升高 -> DM转向到+2.6040° -> 6号到新位置 -> 5号下降到新高度 -> 夹爪张开60° -> DONE。

原 `&arm ring confirm` 保留为同动作兼容别名，不再是第二阶段；运行中重复发送不会重启动作。

查询 `&arm ring status`；停止 `&arm stop`。成功释放后PICK标志失效，下一次放置需要重新取料。烧录/重启也会清除PICK标志。

PICK/载物盘PLACE配置保持原值，保留编码器末段纠偏、150mm下降保护与低位DM±42°。
