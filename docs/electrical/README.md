# 电控版本与参数

当前为 V306 有障碍外圈居中、20 mm 黄区余量、手动障碍和工位地图。 上位机 2.6.35，取盘顺序 1 → 2 → 3。

| W25Q64 内容 | 初赛 | 决赛 |
| --- | --- | --- |
| 圆环微调与夹爪/载物盘预置 | 0x7F8000、0x7F9000 | 0x7F4000、0x7F5000 |
| 圆盘与载物盘四姿态 | 0x7F2000、0x7F3000 | 0x7F6000、0x7F7000 |

上电优先加载当前固件有效记录。先应用到 RAM，确认装调结果后再用对应按钮保存，并等待主控回执。初赛的底盘和工位地图参数有独立设置页。切换固件前记录现用参数，按赛制选择正确固件和上位机。

场地坐标单位为毫米，西南角为原点，X 向右、Y 向上。图像像素 Y 向下。出场、扫码、取盘与放料目标由比赛流程和工位配置决定。主控诊断主要通过 UART4 115200。具体数据字段以 [固件](../../Core/README.md)和 [视觉](../../vision/README.md)的对应实现为准。
