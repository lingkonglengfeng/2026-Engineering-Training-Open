# V198：W25 启动优先、共用放置参数与升降提速

配套上位机 2.5.4；两台相机桥仍为 CAM1 1.3.0 / CAM2 1.4.0。

## 启动使用已保存参数

主控按以下顺序初始化机械臂：

1. 初始化驱动、标定和舵机参数结构，建立编译默认值，尚不启动舵机。
2. 读取并校验 W25Q64 双记录，选择最新有效记录。
3. 将已保存的共享放料微调、夹爪开闭预置和载物盘三槽角度应用到 RAM。
4. 使用生效后的夹爪张开角、载物盘 2 号槽角度，执行原有开机舵机动作。
5. 开始正常任务服务，后续自动抓放使用这套已加载参数。

有效的保存值优先于代码默认值，**不再把保存的旧三槽组合自动替换为 19/109/199**。需要这组三槽角度时，先在面板应用并保存。没有有效记录、记录不适用或读取失败时，打印说明并使用现有编译默认值；不增加新的停机故障。Flash 正被其它参数事务占用时，启动任务让出 CPU 后重试，不将“忙”误当成“已经加载”，也不依赖 CAN 就绪标志才读取。

启动日志：

```text
[ARM PARAMS] BOOT source=W25Q64 sequence=...
[ARM] boot OPEN=...deg from active parameters; CLOSE=...deg
[ARM] boot tray SLOT2=...deg from active parameters
```

无有效记录时显示 `BOOT source=DEFAULT`。上位机状态栏在读取 V198 状态后显示“启动参数：W25Q64 已保存参数”或“默认参数”；这是启动来源，不表示新编辑的 RAM 微调已经保存。读取动作本身不写 Flash、不改变电机零点；仍需显式点击保存才能持久化新修改。

## ROUGH / TEMP 共用三个放料点

两工位共用一份 **1/2/3号点 × 升降/伸缩/旋转增量**，基准使用原 ROUGH 三点，去掉原 TEMP 专用照片补偿。两边同号点的基准及已应用增量相同：在 ROUGH 或 TEMP 页修改任一同号点，都会用于两工位。

兼容原 V196/V197 W25 格式：旧记录读取 **ROUGH 组**作为共用微调，旧 TEMP 独立微调不再参与控制。新保存仍使用原双记录/CRC 格式，并把共用组写入原两组位置，避免改动 Flash 分区或破坏旧记录结构。原有夹爪和载物盘预置按保存值原样使用。

TEMP 第二轮原有 **72 mm 叠层抬高量**继续在共享基准上独立叠加。取回物料、载物盘抓取、发车姿态、相机姿态和电机零点没有并入这套放料参数。

操作：

1. “机械臂控制 → ROUGH / TEMP 三点微调”，选择任一工位和点号。
2. 调整三个角度增量，先应用到主控 RAM；主控会回传两工位相同的点参数。
3. 动作完成后，在参数页“保存主控参数到 W25Q64”，确认 `SAVED HAL=0`。
4. 重启主控，核对启动来源及点参数。自动流程无需再次手动读取或重新输入微调。

## 两工位采用相同纠偏顺序

ROUGH 和 TEMP 都执行：

```text
位置纠偏 → 角度纠偏 → 重新做位置纠偏 → 角度末端复核 → 到站完成
```

复用原 ROUGH 的同一套 XY/yaw 状态机，TEMP 在自动流程也启用圆环轴角观测；带物料叠层使用原有组合标志 `axis | occupied`。全局 `vyaw on/off` 继续同时控制两工位的角度纠偏。

普通圆环位置容差保持 **±2 px**，RAW 圆盘保持 **±16 px**；TEMP 第二轮叠层保持 **±10 px**、原 3 帧确认与 72 mm 抬高量。角度末端复核保持原 0.8°；位置 PID、纠偏速度、搜索和时间预算不因本次统一而改变。

## 升降上下行统一提高约 20%

5号升降默认载料上限 **198→238 RPM**，自动空载上限 **327→392 RPM**，均按原值乘 1.2 后取整，上升和下降共用。编码器速度曲线增益 9.9→11.88，原生 FD 位置模式继续使用驱动器曲线。手动明确指定的更低速度仍受原配置约束。

加速度档位保持 200，伸缩、DM 旋转、底盘和舵机速度保留原设置；没有新增停机保护。较短行程不一定达到速度上限，因此不能据此承诺整轮用时缩短 20%。
