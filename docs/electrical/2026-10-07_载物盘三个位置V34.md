# 载物盘三个位置 V34

参考 `D:\projects\Engineering training competition\competition project - 11_26_比赛版\Device\Car_ctrl\car_ctrl.h`：carplate1_pos=44、carplate2_pos=137、carplate3_pos=229。

载物盘使用 PD13 / TIM4_CH2，360°映射到500..2500us，50Hz PWM。上电不输出PWM，先手动使能：

```text
&arm table enable
```

使能时先输出160°（1389us）。随后按需要逐条选择位置：

| 指令 | 默认角度 | PWM |
| --- | --- | --- |
| `&arm table go 1` | 44° | 744us |
| `&arm table go 2` | 137° | 1261us |
| `&arm table go 3` | 229° | 1772us |

已使能时以非阻塞PWM斜坡切换，默认500us/s。

任意角度测试：`&arm table test 180`（支持0..360及小数）。失能时直接在该目标PWM使能；已使能时平滑改变PWM。

手动调整某位置：先 `&arm table test 150`，等 `&arm table status` 显示ramping=0，再 `&arm table save 2`。此覆盖仅RAM有效，重启恢复44/137/229°。

`&arm table stop` 冻结当前PWM并保持；`&arm table disable` 关闭该路输出。status显示的是PWM推算角度，没有舵机实际角度反馈。

本版仅补齐载物盘默认三个位置，不自动插入比赛流程。编译与软件回归不代表实机验证；尚未烧录或驱动实物。
