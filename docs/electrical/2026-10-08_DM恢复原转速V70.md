# DM恢复原转速 V70

按用户要求，将机械臂姿态状态机的DM转向恢复V68原来的方式：直接使用配置的默认90°/秒速度上限，取消V69带料时的5→30°/秒慢速斜坡和额外减速更新。DM到位等待期限恢复10秒。

PLACE仍在5号达到TOP后同时启动DM转向与6号缩回，实际两者到位后才下降放料。5号120RPM、抓取后直接升到TOP、取料6号外伸50mm、窗口(0,−20,20,20)、各目标角度和堵转/故障检查保留。

本次不修改驱动器固件、零点或视觉协议。已有6号堵转不会因为恢复DM速度自动清除；本版只恢复DM转向设置，不保证消除机械堵转原因。

烧录后启动标识为CAMERA_DEPLOY_V70。DM开始转向时会打印 `original rotation speed restored: default90deg/s; parallel reach preserved`。

测试一轮：

```text
&arm material loop limit 1
&arm material loop start
```

状态/停止：

```text
&arm material loop status
&arm material loop stop
```

生产姿态FSM437项、物料FSM2944项通过；覆盖夹爪闭合时正反向约165°动作恢复90°/秒、没有慢速更新、DM/6号仍并行及DM发送失败取消。编译结果见build.log。未烧录或驱动实物。
