# CAM1桥接1.3.2：A18 GPIO常亮补光

本次只修改CAM1电脑视觉桥接，主控仍V279、PC仍2.6.16。CAM2仍安装原1.4.1，不初始化任何补光GPIO；相机自识别旧服务及独立旧调试脚本未改。代码本地提交，暂不推送，不连接/安装相机，不操作机器人。

## 接线与使用

将CAM1原来接A19的灯板EN/S/CTRL控制线移到A18。灯板电源线保持原正确接法，与相机共地；A18只接逻辑控制端，不直接作为灯的供电输出。按原高电平使能灯板：程序启动后A18为高电平常亮，正常退出/finally清理为低电平关灯。

本次用`A18 -> GPIOA18`，不初始化PWM6/PWM7，不操作A19，也不改相机UART的A16/TX、A17/RX。固定为开关/常亮，不保留旧物料/圆环/圆盘分别20%/15%/30%的PWM调光。当前桥接版原先没有补光初始化；这次在相机桥接启动和退出接入GPIO控制。

用MaixVision的应用安装功能安装`maix-cam1_pc_bridge-v1.3.2.zip`到CAM1，再确认“工训CAM1电脑视觉桥接”为开机自启。也可用同名目录中的单文件`main.py`运行调试；它已经打包所需桥接代码，不要只上传开发用`bridge.py`。无需重新烧录主控，也不用更新CAM2。未代为安装到相机，物理换线也需用户完成。

## 路径

- 发布安装包：`比赛版本/共用相机程序/maix-cam1_pc_bridge-v1.3.2.zip`
- 发布单文件：`比赛版本/共用相机程序/maix-cam1_pc_bridge-v1.3.2/main.py`
- 维护源码：`vision/maixcam_bridge/bridge.py`
- 生成单文件：`vision/maixcam_bridge/main.py`

安装包仍使用原app id `cam1_pc_bridge`，版本升为1.3.2。旧1.3.1包保留，但不会控制新A18补光；旧A19/PWM识别脚本不能当作本次桥接程序。

## 行为与验证

启动日志为`[BRIDGE LIGHT] A18/GPIOA18 HIGH/ON; constant GPIO, no PWM`，退出为`LOW/OFF`。GPIO初始化失败会明确打印`unavailable; video/UART continue`并保持图传/串口桥接；部分初始化失败尽力拉低已取得的GPIO，后续UART等启动失败也经过关灯清理。只导入模块不操作GPIO。

假Maix GPIO/UART环境的6项启动/关灯/CAM2隔离/异常清理检查通过，桥接/发现/真实TCP回环14项、屏幕回显9项通过（共29项）；单文件语法和安装包CRC/内容核对通过。未实测A18电平、灯板和Wi-Fi并行效果，日志打印和离线检查不能代替实机测量。

参考：[官方GPIO](https://wiki.sipeed.com/maixpy/doc/en/peripheral/gpio.html)、[官方PWM资源限制](https://wiki.sipeed.com/maixpy/doc/en/peripheral/pwm.html)。普通MaixCAM开Wi-Fi时不建议使用PWM4～9，A18作为普通GPIO不使用PWM6。
