# V32 + CAM1 v17：三圆环小角度纠偏试验

默认关闭。仅2/3号圆环工位启用；1号圆盘保持原位置纠偏。关闭时自动流程仍请求flags0的16字节位置/数量帧；开启后请求flags1的24字节同图位置、行方向、数量帧。主控与视觉源码联调/模拟通过，尚未烧录或上传验证。

`vyaw`里的2/3是工位编号，不是电机地址。`vyaw zero`只记录视觉行方向零位，不移动小车，不修改DM内部零点，不控制机械臂归零。

## 最常用的开关

```
&vyaw off
&vyaw on
&vyaw status
```

停车后修改。ON要求工位2和3均已记录零位及左右转比例；不会用默认+1冒充标定。开关本身不使能电机、不触发运动。标定数据与开关在RAM，主控重启默认OFF并需重新标定；STOP/match reset只清运行状态，保留已标定的数据与显式开关设置。下一次动作仍需用户发起流程、等待READY、发送新OK。

已有运动或纠偏任务时，开关/标定操作拒绝；status在纠偏中延迟到下一个真正停稳的时刻输出。可用原有STOP/reset结束任务后再修改。开/关对比时保持相机、机械臂与工位摆放一致。

## 首次标定：2号点

先停止比赛流程（例如`&match reset`），将车放在实际2号工位并人为摆正。展开机械臂到camera并等READY；使中间圆环靠近画面中心，三组环稳定可见。相机必须运行统一入口main.py，BUILD为2026-10-07-ring-axis-v17；独立middle_ring.py仍是位置手调程序。

```
&vyaw view 2
```

仅切换CAM1圆环识别及角度监看，不驱动车辆。等SET ACK和三组环稳定后，用status确认station=2、valid=1、q>=80且该站stable>=3，再发：

```
&vyaw zero 2
&vyaw sample 2
```

zero记录人为摆正时的图像行方向。sample记录此时的行方向与IMU航向基线。两条都是立即尝试；失败会提示原因，不会后台悄悄记录，需等稳定后重发。

sample成功后，手动让车小幅左/右转1至8度（建议约3度）。例如确认车可安全小转、IMU已就绪后，可由用户手动发送：

```
&EN
&L3
```

等转向完成、车停稳、三组环重新稳定三帧，再发：

```
&vyaw solve 2
```

solve从实际IMU变化和图像角变化计算`gain=-IMU_delta/line_axis_delta`，因此不依赖假定的图像左右转符号。IMU转动必须1..8度，轴角变化至少0.5度；数据须同一个view会话。sample到solve期间不要重新view、切相机模式、重新对IMU零漂、移动机械臂或改镜头。若三环角无效/未停稳/会话变化，solve拒绝而不假造增益。

例如左转+3度，行方向变化-3度，则gain=+1；镜像相机行方向变化+3度，则gain=-1。增益合法范围为绝对值0.25..4。

## 3号点与运行

将车移至实际3号工位，重新人为摆正，以相同步骤发送view 3、zero 3、sample 3；手动小转并停稳后solve 3。然后可发`&vyaw on`。两站标定均有效时才会接受。

如果已有实测的符号/比例，也可显式用`&vyaw gain 2 <signed_ratio>`和`&vyaw gain 3 <signed_ratio>`设置；这是人工确认标定值，不会自动认定+1正确。

标定后把车摆回正确始停区，按原流程`&prepare 1`或`&prepare 2`，等发车姿态READY后发`&OK`。开关只影响后续2/3号点的角度步骤。

## 控制过程与边界

位置首次稳定 → 新三帧行角确认 → IMU内环连续低速小转 → 等停稳后的新图确认 → 重新精调位置 → 再用三帧稳定角均值确认。

转动使用现有IMU航向反馈，视觉更新航向目标；不与原固定航向保持同时争用输出。限速按轮周长、250RPM和300mm自转力臂换算为归一化omega，试验值约2度/秒（实际受整数RPM与负载影响）。不会每100ms强制停250ms；只在目标到位、数据失效或确认新图时停止。

控制接受q>=80、三地标、同图同会话、年龄<500ms的原始行方向。角度稳定窗口0.3度、三新帧且跨至少300ms；0.4度以内进入位置精调，最终三帧均值需在0.6度内。0.01度只是协议量化，不代表实车精度。

单次视觉误差窗口8度、角度阶段8秒、实际累计转角加当前剩余目标不超过10度、相对角度阶段起点实际偏转不超过10度；量化抖动小于0.03度不直接累加。最后位置精调等待角度验证最多3秒。原平移/搜索运动预算保留，不因重启精调被重置扩倍。

明确INVALID、CRC错误、会话变化、角度过期立即失效停转。正常新三帧组装的50ms窗口内，可保留上一完整同图快照及原年龄；超过窗口、缺组或错序即失效，不拼接新XY和旧轴，也不延长500ms。无效或仅两层边界补证可有合法XY，但不能冒充角度可靠；ON时可能因此等角/超时，OFF仍走原XY路径。

这是当前工位的小角度修正，不重标定全局地图或IMU零位；三环行方向有180度歧义，仍依赖已验证的粗朝向。更改镜头、相机安装、分辨率比例或机械臂camera姿态后，应重新现场标定。

## 诊断

phase数字：0=IDLE，1=XY首次对齐，2=等新稳定角，3=IMU转向，4=XY精调/角复核，5=DONE，6=失败。

状态/阶段回显包含enabled、phase、axis、VALID、q、地标数、年龄、图像SEQ、SET seq、误差、目标/实际IMU角及累计实际转角。raw_error为当前原始轴的估计误差；无有效标定/观测时nan表示未知。last_error是控制使用的最近稳定角均值误差。若显示XY DONE但不能OK，查看VYAW LIVE阶段及角度有效性，不要把位置完成当成角度验证完成。
