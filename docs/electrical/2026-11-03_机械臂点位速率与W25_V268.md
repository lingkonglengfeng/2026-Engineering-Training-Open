# V268 PRELIM / PC2.6.11：七点位五路速率

新增上位机“机械臂控制 → 各点位电机速率”。各点位独立设置5号升降、6号伸缩、DM旋转、夹爪、载物盘的速度倍率，自动流程与对应点位调试使用同一参数。范围10%～300%，分辨率0.1%；全部默认100%，沿用现有空载/带物速度策略。ROUGH/TEMP共用三点速率，载物盘各槽共用取料/放回对应的一组。

| 串口点位名 | 界面点位 | 作用 |
|---|---|---|
| wait | 圆盘等待物料 | 等待/观察姿态、CAMERA复位 |
| grab | 圆盘夹取物料 | 进框后的抓取定位、伸出、闭爪和初次回升 |
| tray | 放回载物盘 | 返载物盘运动及对应选槽 |
| traypick | 载物盘取料 | 取槽运动及对应选槽 |
| ring1 / ring2 / ring3 | 地面圆环1/2/3 | 对应地面环的取物/放物，ROUGH/TEMP共用 |

倍率是速率上限的倍率，不改变目标位置、伸缩长度、角度、动作顺序或加速度。短行程可能尚未达到速度上限就开始减速；实际速度仍受原反馈接近控制和驱动限值约束。某点原流程未动作的电机不会因设置倍率而新增动作；恢复/精细修正等专用低速仍按原流程执行。

## 上位机操作

1. 刷入V268初赛HEX。关闭旧上位机窗口，再通过原桌面快捷方式启动，标题应显示PC2.6.11。启动器、相机桥接和依赖不变。
2. 在新页选择点位并“读取主控速率”。右侧显示固件基准参考及倍率后的近似值；改输入只预览，不发送运动。
3. 例如圆盘夹取的6号需要加快20%，选“圆盘：夹取物料”，把6号输入120，其余保留100，点击“应用本点到RAM”。一次原子更新本点五路值，等待HAL=0并读回。
4. 每个点改完分别应用到RAM，最后点击“保存全部速率到W25”。未应用的预览会提示先应用；保存的是全部七点当前RAM速率。
5. “从W25读取全部速率”恢复已保存记录。“本点输入恢复100%”只改编辑框，仍需应用/保存。不支持的新固件会提示需V268，其他旧机械臂页面继续兼容。

每次启动自动读取本版本速率记录，无有效记录使用100%，不改变已有姿态、舵机角度、底盘参数或零点。设置/保存/读取速率不启动机械臂；运动中写参数返回BUSY，不停止正在进行的动作。普通单轴手动页仍使用原手动策略；地面/圆盘的“移动到预览姿态”会携带相应点位标签。

## 指令

上位机日志页可发送：

```text
&arm rates status
&arm rates set grab 100 120 100 100 100
&arm rates save
&arm rates load
&arm rates defaults
```

五个数依次为 **5号、6号、DM、夹爪、载物盘**，单位为%。`defaults`仅把RAM七点全部改为100%，不擦除保存记录；需要覆盖保存时再发送save。读取空记录/读取失败返回HAL=1，保留当前RAM参数。HAL=2表示忙。无效点位、NaN、越界或尾随参数都不部分应用。

参数回读为完整BEGIN/七条ARM RATE/END帧，PC只采用完整且有效的快照；ZDT提示前缀沿用原处理。设置、保存和读取分别有 `[ARM RATES ACK] op=... HAL=...; no motion`。正常点位动作沿用原一键按钮/指令。手动三轴动作可显式附加速率点位，例如 `arm move -20 -200 10 ring2`；不附加时保留原手动速度。此指令会运动，不能与只改参数的rates指令混淆。

## 默认速度参考

| 电机 | 100%基准参考 |
|---|---|
| 5号 | 空载约431RPM，带物约410RPM |
| 6号 | 空载约182RPM，带物约246RPM，圆盘抓取伸出约262RPM |
| DM | 空载约213.84°/s，带物约231.66°/s |
| 夹爪 | 默认360°映射下PWM角度斜率约386.1°/s |
| 载物盘 | 同映射下约193.05°/s |

这是固件默认参考，不是实测速度或W25现场快照；原手动全局base/slew命令的临时改动不由本功能保存。机械动作的等待预算按配置中最慢倍率只放宽，不缩短；23秒物料进框窗口、通信新鲜度和原停止联锁不变，没有新增停机保护。

## 参数结构与并行动作

速率为7×5个16位定点数（百分数×10），版本1，CRC32、序号及双备份。初赛用capacity-20/-19扇区，预留决赛用-22/-21，与现有姿态、主控参数、导航和工位记录分开。旧固件不会读取/覆盖该区域；本次未更新决赛源码。

实现为 `arm_speed.h` 和 `arm_speed.inc`，后者由现有 `arm_start_pose.c` 编译，复用原ArmTask/Flash互斥，无新任务、ISR、总线或堆分配。参数写入保持原任务所有权。正常5/6定位速度在最终原策略之后乘倍率，原指令加速度不联动。5号、6号启动及同绝对目标重发使用已接受的速度；舵机在目标开始时锁存倍率，同一目标的重发不会因并行阶段改变而换倍率；载物盘提前选槽使用其实际目的动作的速率组。
