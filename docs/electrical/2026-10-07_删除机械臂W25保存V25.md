# V25：机械臂取消W25零点和发车姿态保存

已删除DM软件零点存储模块、相关API和MDK编译项；发车姿态不再读取、写入、擦除或校验W25记录。旧记录（例如DM+135.798deg）不再参与启动或恢复目标。底盘导航/PID自己的W25参数功能保留，未擦除整片Flash。

## 默认发车目标

- ZDT5：相对最高零点-43.37deg。
- ZDT6：相对最内零点-279.44deg。
- DM：内部零点0deg。

前两个使用此前用户选定发车姿态的角度；DM按恢复内部零点的要求使用0deg。启动仅配置目标，不自动运动，也不重新设置任一电机的零点。零点参考仍必须正确。

直接沿用match reset、startpose 1|2、等待IMU、depart。depart先恢复这组姿态，WAIT_START_OK后新的OK才出库。出库后边去QR边展开到相机姿态。无需先arm start save，也不会因为没有W25姿态记录拒绝启动。

## 临时修改目标

```
&arm start set -43.37 -279.44 0
&arm start status
```

三个数依次是5号相对零点角度、6号相对零点角度、DM相对内部零点角度，单位deg。此指令只配置目标，不移动机构；要求空闲机械臂、底盘失能及有效零点。角度/换算范围无效时保留旧目标。

```
&arm start defaults
```

恢复默认三轴目标。若要移动到当前配置目标，使用arm start；或使用depart进入准备阶段。

arm start save保留为“临时录入当前姿态到RAM”，需要三轴静止、DM失能、新鲜位置反馈；成功显示RAM CAPTURED，不再显示SAVED/W25 verified。断电或程序重新初始化后丢失，恢复默认目标。状态source=0为启动默认、1为命令配置/defaults、2为RAM录入；configured=1仅表示有目标，不表示实际到位。

DM设置内部零点仍用dm off后，手动摆好机械零位并静止，再dm zero save；以后dm home回电机0deg。dm zero w25入口提示功能已删除，不写Flash。

保留30RPM升降、80RPM原生伸缩、编码器停稳确认、CAM2屏蔽和视觉/里程计流程。范围检查和旧目标/新零点一致性检查仍保留；若主动重建ZDT零点或方向/跨度，请在有效参考建立后重新defaults或set。

模拟测试验证：任意旧Flash内容不被读取，默认DM0目标恢复、RAM录入不写Flash、初始化恢复默认、set无效参数不替换目标、伸出/回缩脉冲符号仍正确。未实车烧录或测试机械尺寸。
