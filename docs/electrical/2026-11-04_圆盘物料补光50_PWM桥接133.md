# CAM1桥接1.3.3：圆盘/物料补光50%

保留A18接线，改用PWM6、20kHz。圆盘识别模式8、物料模式2（含取样）输出50%占空比；圆环模式3、泊车模式9及STOP/其他模式保持原100%亮度。只在模式导致占空比变化时更新PWM，不在每帧反复切换资源。

补光挂在相机桥接接收SET的位置，在新任务的图像上下文建立前切换。初始化100%；正常退出先占空比0、停PWM，再映射GPIOA18拉低，失败清理同样尝试关灯。CAM2不初始化补光，不改A16/A17 UART，不操作A19。补光故障仍沿用只记录错误、图传/串口继续的原策略。

[官方MaixCAM引脚表](https://github.com/sipeed/MaixCDK/blob/main/components/peripheral/port/maixcam/maix_pinmap.cpp)列出A18的PWM6功能；[官方PWM文档](https://wiki.sipeed.com/maixpy/doc/zh/peripheral/pwm.html)说明Wi-Fi使用SDIO1，MaixCAM/MaixCAM-Pro不建议使用PWM4～9。因此新包尚需实机确认Wi-Fi图传稳定性，不宣称已排除硬件资源冲突；旧1.3.2 GPIO常亮包保留可回退。

安装包：vision/maixcam_bridge/dist/maix-cam1_pc_bridge-v1.3.3.zip。需通过MaixVision安装并选择开机自启，单文件上传可使用同目录main.py。CAM2仍1.4.1，不需要更新。补光修改不需要单独烧录主控或重存W25。

7项假Maix外设检查通过，覆盖模式2/8的50%、模式3/9/STOP的100%、退出关灯、部分初始化失败、CAM2不触碰灯引脚、UART引脚不变；相机包语法/内容构建检查通过。未连接或安装到真实相机、未推送。
