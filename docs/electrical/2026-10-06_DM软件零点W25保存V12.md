# V12：DM软件零点保存到W25Q64

用户保持输出轴位置不动，断电再上电，p_m从0.1182036到0.1273264rad，相差0.0091228rad，约0.52deg。这个测试没有显示大幅上电坐标跳变，但只覆盖一个机械位置；不能保证所有上电位置的绝对定位精度，也不能判断输出轴磁编码器损坏。xout仍固定为-pi，不参与控制。

## 第一次记录机械零位

先烧录本包HEX。启动应显示CAMERA_DEPLOY_V12，`&dm diag`应显示compiled PMAX=18.500。

让底盘、机械臂失能，手动将DM输出轴摆到希望的机械零位。命令每行单独发送：

```
&dis
&arm stop
&dm off
```

确认电机已经松开并停止，再手动摆好机械零位，然后发送：

```
&dm zero w25 save
&dm zero w25 status
```

SAVE必须显示HAL=0、active=1、ref_valid=1。HAL=0为保存并校验成功，不是运动到位；此指令不回零、不使能、不改电机内部零点。它通过已修正PMAX=18.5的标准反馈读取当前位置，保存这个坐标作为软件零点。标准反馈与p_m使用同一位置坐标，16位反馈量化步距约0.032deg，不额外把固定xout当作位置。

保存前要求：机械臂空闲、底盘失能、ZDT5/6无使能请求、DM新鲜且静止的失能反馈、POS模式、W25读写正常。指令会主动确认DM失能。保存失败不替换运行中的零点，旧有效Flash记录保留。

## 以后使用

上电自动加载软件参考，不会自动使能/转动。发送：

```
&dm home
```

或者发送：

```
&arm camera
```

二者共用保存的零位。camera仍按DM回零并保持使能、升降回0%、伸缩到-300deg的顺序执行。home的HAL=0表示目标已排队；用`&dm query`确认arm_deg已接近0，不以串口OK认定到位。

首次验证建议：先在保存零点附近测试home，再在机构允许的不同角度断电上电测试。本版处理单圈±pi坐标边界，使能前选择当前连续位置坐标中的等效零点；保持原有±180deg机构限位及高度保护。不能恢复断电期间的输出轴多圈圈数。不要用任意旋转角度的最短路替代机构限位。

## 重新设置与清除

重新摆好机械零位后，再发`&dm zero w25 save`覆盖软件参考。

```
&dm zero w25 clear
```

clear要求相同的空闲/失能条件，写入“已清除”记录，恢复电机原始0rad作为软件零位，不移动电机。W25参考激活时，旧的`dm zero`（RAM零点）、`dm zero save/confirm`（电机内部零点）会拒绝混用；如果确实要改电机内部零点，先明确clear，再执行原指令，并重新记录W25零位。

## 存储与验证

W25实际容量末尾第三、第四个4KB扇区：8MB W25Q64地址0x7FD000、0x7FC000；最后两个扇区继续保留PID、导航参数。W25Q16按其实际容量计算对应地址。记录包含版本、序号、CRC32、零点、CAN IDs、PMAX、传动比与方向；轮换保存，写后回读校验。若没有有效记录且发现损坏/读写错误，上电不默认为零位，禁止回零并等待重新标定。

记录绑定当前CAN ID/机械配置，不包含电机唯一序列号。更换电机、修改电机内部零点、更新影响角度坐标的固件、修改机械安装后，必须重新标定。不要在保存期间从其他串口同时下发PID/导航Flash保存或擦除命令；当前项目的W25驱动仍使用同步SPI存储接口。

仅编译与模拟测试；尚未烧录、实际读写W25或实际控制电机。本版属于根据单点断电重复性制作的试验固件，尚未确认此前回零异常的根因。
