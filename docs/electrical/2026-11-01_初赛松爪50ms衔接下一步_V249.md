# V249 PRELIM：松爪50ms后衔接下一步，闭爪时序不改

按用户要求只更新初赛，决赛保持V245。上位机继续PC2.6.7，位置参数和W25数据格式不变，不需要重存。

## 行为

新松爪目标接受后开始计时，持续50ms即可衔接下一步，不再等待PWM到最终张开角度。舵机仍按原速度在后台渐变，不冻结或跳变输出。同一OPEN目标已经持续50ms时复用当前动作，不重复发OPEN或重新增加等待。

覆盖取料前张爪、圆环放料、载物盘放料、圆盘抓取后的放盘结果交接及随后回相机/等待姿态。原圆环放料200ms改为50ms；载物盘及取料前原先等待渐变完成/较长张爪时间的路径统一采用50ms。清除了后续抬升/旋转/回相机姿态中重复等待PWM结束的松爪条件，交接标志保留到渐变真正完成或目标改变，避免下一阶段把仍在执行的合法OPEN误报为夹爪状态异常。

闭爪保持原速度/缩放、PWM渐变完成和原有位置/下降完成条件；载物盘/圆环取料的闭爪最短等待仍为231ms，圆盘抓取仍用原伸出半程闭爪和伸出/PWM完成条件。夹取/转运顺序不变。机械臂三轴速度、目标、旋转区域、现有反馈/保持条件不变，未添加停机条件。

`ArmServo_GripIsOpen`仍表示PWM已稳定到张开目标，供原状态/速度选择使用；`ArmServo_GripOpenConfirmed`现在表示OPEN命令已持续50ms、可衔接动作，允许PWM仍在渐变。关闭/故障/停止请求或目标改变时不会返回就绪。计时从成功下达目标或启用对应PWM时开始，沿用非阻塞轮询。

50ms是松爪等待条件；实际下一步仍须满足原位置和反馈条件，并在下一次状态机轮询时执行。它不是夹爪物理到位传感器反馈。

## 使用与日志

使用 `比赛版本/初赛/固件/Engineering_Training_Project_V249_PRELIM.hex`，或编译初赛Keil工程。启动标记CAMERA_DEPLOY_V249_PRELIM含OPEN_COMMAND50MS_NEXT_ACTION；arm ui返回firmware=249、variant=PRELIM。

放料完成日志为 `[ARM RESULT] OPEN command >=50ms; next action NOW, PWM continues`，圆环/载物盘DONE也标明50ms。W25和舵机目标角不变，旧固件保留；决赛不更新。
