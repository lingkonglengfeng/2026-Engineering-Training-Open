# V303 PRELIM / PC2.6.35：手动障碍地图、夹取半宽105px

## 上位机操作

1. 烧录初赛V303，重开桌面上位机加载PC2.6.35，接入主控串口。
2. 在“工位地图”页点击“读取主控地图”，勾选“放置障碍物（点地图）”。
3. 点击实际障碍物在场地上的位置，等待回执完成再点下一处。最多两个，第三次点击替换最早一个；紫色圆圈和坐标是主控读回的手动障碍。
4. 应用第一个点后自动切入手动模式，关闭主控视觉障碍联动和PC的CAM2障碍检测/回传；二维码、图传、圆环与物料识别继续正常工作。
5. 正常准备、发车。准备/复位不会抹掉手动点位，各工位导航使用现有地图规划器绕行，圆弧仍按原设置及扫掠检查决定是否使用。标记不自动发车，也不改变原出库动作。

“删除最早一个”移除一处；“清除手动障碍”保持手动模式和视觉关闭；“恢复视觉避障”清除手动点位，恢复视觉联动及PC检测。底盘页重新开启视觉避障同样退出手动模式并清除手动点位。只能在流程空闲、行驶前修改；修改拒绝不停止或取消原任务。

手动点位是本次上电RAM参数，准备/复位保留，断电清除；串口重连后读取地图恢复显示及检测模式。地图页W25按钮明确标为保存/读取“工位坐标”，手动障碍不随工位偏移写入W25。

## 地图与协议

障碍中心使用场地毫米坐标，不做视觉候选点吸附。每个点沿用现有50mm半径障碍占用，再由280mm车身通行和旋转扫掠检查计算可行路线。固定黄区、台面、地图工位及速度参数不变。标记位置不准确、挡住起点或确实封路时仍可能无路，保留现有结果处理，不跳过任务。

- `manualobs set 1 x y`、`manualobs set 2 x1 y1 x2 y2`：原子替换手动图层，关闭视觉避障。
- `manualobs set 0`：清空点位，继续手动模式。
- `manualobs vision`：清空手动地图并恢复视觉。
- 回执`[MANUAL OBS] OK manual=... count=... avoid=...; RAM, no motion`，随后上位机读取`fieldmap status`。
- 工位地图头新增`manual_mode/manual_count`及`[FIELD MAP MANUAL] id=... x=... y=... radius=50`；VOBS状态新增`manual`标志。

PC接收真实模式，CAM2工作线程只停止圆柱检测和障碍上报，继续取图及扫码。恢复后重新开始三帧确认，不复用先前确认的障碍。手动标记保存在原手工障碍层，CAM2两路动态障碍清理不会删除它；普通视觉模式准备时仍清上一轮临时障碍。
