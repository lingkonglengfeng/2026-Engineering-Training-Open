# 取料同步伸出50mm与窗口上移 V66

在E:\Engineering_Training_Project主工程V65基础上更新。红色入窗后，同一轮动作中启动5号下降到原抓取位、6号从等待位目标向外伸出50mm、夹爪闭合305°；后续抬升及载物盘1号放置沿用现有流程。每轮有人取走槽1物料。

## 指令

```text
&arm material loop start
&arm material loop status
&arm material loop stop
```

上电默认连续不限轮数。先测试两轮可在停止状态发送：

```text
&arm material loop limit 2
&arm material loop start
```

恢复不限轮数使用`&arm material loop limit 0`。`arm stop`、全局STOP和任一机械臂电机/舵机失能均会取消流程。单独失能5号、6号或DM时，先停止升降和原生伸缩动作，再释放指定电机，避免独立的6号位置命令继续运行。

原单次`&arm material`仍执行一轮并恢复CAMERA；`&arm material auto on`仍只在圆盘纠偏成功后执行一轮，默认OFF。它们复用此次下降、伸出、闭爪动作。连续模式放置后直接返回等待位，重新张爪、发新SET/ACK并清旧观测，不恢复CAMERA作为中转。

## 默认窗口

```text
&arm material window 0 -20 20 20
```

新上电默认就是这组参数。参数依次为gx、gy、wx、wy：中心偏差(0,−20px)，横纵半宽各20px。按相机320×240、dx=u−160、dy=v−120计算，窗口中心是(160,100)，横向范围140..180，纵向80..120，边界包含在窗口内。

只修改电控接受窗口，视觉MAT_PX原点仍为(160,120)，不在相机端再叠加−20偏移。fresh默认150ms，confirm默认1个不同的新有效观测，jump默认0关闭。原窗口调参指令继续可用，参数只存RAM；每轮保留配置，重启恢复新默认。

## 姿态和动作

| 阶段 | 5号升降 | 6号伸缩 | DM/夹爪 |
| --- | --- | --- | --- |
| 等待 | 原抓取终点上方50mm，约−361.5644° | −185.1581° | DM−2.0217°，张开225° |
| 入窗取料 | 原终点−612.7679° | 等待位向外50mm，约−389.7929° | DM保持，闭合305° |
| 抬升 | 抬高50mm | 保持伸出后的实际位置 | 闭合保持 |
| 放置 | 现有PLACE姿态 | 现有PLACE目标−4° | 槽1舵机205°，DM+162.8250°，最后张开225° |

6号50mm换算使用当前178mm行程和完整行程编码器位移，不是每轮在上轮伸出位置继续累加50mm。5号原抓取高度没有改动。

5号使用现有百分比反馈定位；6号使用现有原生速度位置绝对命令mode01，80RPM、acc150，目标脉冲经当前零点/编码器坐标换算。三项请求在同一状态机轮询内发起，不等待升降完成才伸出；实际机械启动时刻受串口/CAN传输及驱动器响应影响。

抬升前必须同时确认：5号到位、夹爪闭合PWM稳定、6号实际到位并稳定。6号在目标容差内至少3个不同反馈且稳定200ms后请求STOP，随后再检查STOP之后接收的至少3个新反馈、保持200ms，才允许5号抬升。仅HAL=0、旧到位标志或停止前排队的反馈不代表完成。

6号反向超过原检查带、越过目标范围、未运动、反馈/电机故障、发送或STOP失败会取消全部当前动作。默认6号行程超时至少12秒，较慢手动速度按行程/速度比例增加，最多120秒。6号停止保持确认完成后结束其行程计时，等待较慢5号或夹爪时继续检查反馈和保持，不误报6号超时。不在失败后重复发送绝对位置命令。

## 回显与验证

触发时打印`[MAT REACH] ABS mode=01 goal_pulses=... wait=... grab=... extend=50mm speed=... timeout=...`及`[MAT] TRIGGER ... descend, reach +50mm, close grip together`。到位时打印STOP及新反馈保持确认；失败打印阶段和原因，结合`&arm status`/`&arm query 6`检查实际位置和驱动器标志。

生产C物料FSM2520项通过，覆盖三项同轮请求、50mm目标换算、多轮循环、窗口边界、停止后的新反馈、重复旧帧、反向/超程/不运动/超时/保持漂移、各请求失败、等待慢轴及停止退出。姿态370项和跨任务91项通过；机械臂真实驱动回归含单独失能取消两个ZDT动作。Keil结果见随包build.log。

相机协议保持CAM1 mode2/station1/target1红色/20Hz/flags0，MAT_PX02和心跳不变。联动使用统一相机main.py；独立阈值调试程序不打开UART，不能替代它。
