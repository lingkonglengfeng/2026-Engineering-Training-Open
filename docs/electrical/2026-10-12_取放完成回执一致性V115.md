# V115：取放完成回执和保持确认一致

## 本次故障

日志在第一轮TEMP（三号工位）放第三颗物料后停止：

```text
5号 target=85.64% actual=86.13%
[ARM RING] 4/4 open grip225deg
[ARM RING] DONE station=3
[ROUND] ... three-axis pick/place failed
```

三号圆环的动作已经执行到松爪，但代码先打印DONE，再在`ReadActionResult`用另一组严格实时位置条件重新计算成功。5号到位反馈已接近原0.5%误差边界，松爪后的微小保持漂移可能越界；原回执也对6号使用固定0.5%，与近零点动作的到位容差不一致。此路径可以模拟复现“DONE后马上失败”。

原日志缺少DONE瞬间全部三轴反馈，因此不能精确断定是哪一条实时条件返回了false；此次修正统一取放完成判定，避免这种不一致，也保留真实故障诊断。

## 行为

- 原运动目标和到位控制不变：升降真正到位后才能松爪/闭爪。
- 夹爪PWM完成后、打印DONE之前，再确认两台ZDT和DM的使能、新鲜反馈、零点参考、故障及最终保持位置。
- 取放结束时5/6号保持容差至少2mm，保留原到位容差更宽时的值；DM保持容差2°、速度不超过0.2rad/s。原实际高度/角度保护继续检查，不能通过此容差绕过150mm/±44°保护。
- 通过这一次确认后，记录完成事件并打印DONE。比赛流程读取的是这个已完成的取放结果，不会因为随后另一帧轻微漂移把已完成松爪事件翻成失败。
- 取消、STOP、新取放动作会清除旧完成记录。真实超限漂移、失能、堵转/保护、零点变化、反馈过期会在DONE之前失败，并打印具体条件及三轴诊断。
- START的实时到位判断、通用MOVE、CAMERA恢复保持原行为。后续新动作仍需有效的新鲜参考和保护条件。

V114未启动同ABS最多3次重试、V113完全闭合后升到半程再DM/6号并行均保留。所有抓取、放置高度、伸缩、DM角度和速度不变；夹爪仍1000µs/s。

## 使用和日志

只更新本包STM32 V115 HEX，摄像头程序不用改。指令仍为`&match reset`、`&prepare 1|2`，START准备成功后一次`&ok`。

启动标记`CAMERA_DEPLOY_V115`。正常末尾顺序：

```text
[ARM RESULT] grip settled, fresh axes/DM held; COMPLETE latched ...
[ARM RING] DONE station=3 ...
[ROUND] ... ring release complete ...
```

真实失败示例：

```text
[ARM START] FAILED: grip finish: lift drift beyond hold tolerance
[ARM START] ... DM actual/target/code/age ...
[ARM START] id=5 ... actual/target/raw/flags/age ...
[ARM START] id=6 ... actual/target/raw/flags/age ...
```

“完成”仍是电机反馈和舵机PWM动作确认，没有物料传感器，不代表传感器验证了物料成功释放或夹住。

## 验证

生产C模拟覆盖TEMP第三环松爪后5号漂移0.6%（1.44mm）、DM保持漂移1.5°仍完成，DONE后的轻微反馈变化不会翻转结果，STOP清除结果；3mm升降/伸缩漂移、保护、失能、旧反馈、原高度保护拒绝以及DM超限会在DONE前失败。两轮流程、转盘取料、半程转向、任务回执回归通过。Keil编译0错误、0警告；具体测试与SHA256在manifest。

没有连接硬件烧录或执行动作，仍需用户实测。
