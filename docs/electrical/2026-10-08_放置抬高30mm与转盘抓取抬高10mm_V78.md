# 放置抬高30mm与转盘抓取抬高10mm V78

合入用户本轮两项高度调整，以V77为基础。

## 最后张开夹爪时的放置终点提高30mm

仅调整最终放下、松爪前5号的位置，不额外提高TOP或转向前的清空高度，不改变手动PICK的抓取高度。

覆盖载物盘PLACE（手动arm place、material单次/连续/比赛内部PLACE）以及1/2/3号圆环放置和默认2号/confirm别名。

- 载物盘PLACE原本比PICK高2mm，再提高30mm后比PICK高32mm；默认5号约−530.8152°→−380.0931°。
- 三个圆环共享最后松爪高度，默认5号约−1017.5482°→−866.8261°。

各放置动作的DM/6号角度不改，确认最终5号到位后才张爪的门槛保持。

## 圆盘物料抓取终点提高10mm

只调整物料识别取料流程（arm material）的实际抓取终点5号：默认约−612.7679°→−562.5272°。

按用户后续明确要求，等待位不提高，保持原来的约−361.5644°（依据原示教抓取终点上方50mm计算，独立于此次抓取高度调整）。实际抓取终点提高10mm后，从原等待位下降40mm。不是再改手动PICK角度。

抓取仍按入窗后5号下降、6号外伸25mm、夹爪闭合同时启动；确认抓取动作后直升TOP。窗口保持(0,−30,40,40)，速度保持5号120RPM、6号60RPM、DM90°/秒；6号方向1和V77的Emm3200脉冲/圈配置保留。

所有毫米高度换算使用当前5号有效行程/有符号编码器行程，不直接把毫米当角度。上面的角度对应默认240mm、−219505计数行程。

## 测试

烧录V78后先测一轮：

```text
&arm material loop limit 1
&arm material loop start
```

状态及停止：

```text
&arm material loop status
&arm material loop stop
&arm place status
&arm ring status
```

默认回显应显示fixed wait约−361.5644°、grab UP10mm/drop40mm；载物盘放置最后下降目标约−380.0931°，随后张开。手动PICK仍使用原夹取高度。

生产姿态533项、物料3302项、跨任务91项通过；回归覆盖PLACE和三个圆环最后松爪端点、PICK不变、物料抓取新终点、原等待位不变及下降距离为40mm。Keil结果见build.log，未烧录或驱动实物。
