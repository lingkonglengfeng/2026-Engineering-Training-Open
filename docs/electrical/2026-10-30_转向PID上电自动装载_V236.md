## 1. 为什么会出现“我调了参数，运行时还是原来的值”

按可能性从高到低：

1. **旧固件上电不自动装载 W25 里的 PID**（这是本次要修的根因）。
   V235 及以前，`&save` 只负责把值写进 W25；上电/`&EN` 都不会读回，
   只有手动发 `&read` 才会装载。所以“页面里调好 → 保存 → 断电重启”之后，
   运行值又回到 `chassis_motor.h` 的宏默认 **kp=0.0450 / ki=0.0005 / kd=0.0035**。
   对照：导航参数和机械臂参数一直是上电自动装载的，玩家很容易以为 PID 也会。
2. **只改了输入框、没点“应用到RAM(&kp/&ki/&kd)”**：输入框只是本地预览，
   主控 RAM 不变，转向当然还是旧 PID。
3. **源码改了但没烧 HEX**：`CHASSIS_TURN_MAX_WHEEL_RPM` 之类的改动必须重新构建并烧录才生效，
   只重启电脑上位机不会改变主控固件。
4. 调整后没 `&save` 就重启：RAM 值丢失（即使 V236 也救不了没保存的值）。

## 2. 本次修复

### 固件

- 新增 `PID_Storage_ApplyBoot()`：在 `ZDT_Motor_Begin()` 里（导航参数装载之后）**上电自动读回 W25 保存的转向 PID**。
  没有有效记录时保持编译默认值，不报故障。
- 启动日志新增一行，直接说明当前值从哪来：
  ```text
  [PID] BOOT source=W25Q64 kp=0.0500 ki=0.0004 kd=0.0030 (saved turn PID active)
  [PID] BOOT source=DEFAULT kp=0.0450 ki=0.0005 kd=0.0035 (no valid W25 record)
  ```
- `&pid`、`&tstat` 增加**来源字段**：`source=` / `src=`，取值 `DEFAULT` / `W25Q64` / `MANUAL`
  - `&kp/&ki/&kd` 改过 → `MANUAL`（只在 RAM，未保存）
  - `&read` 成功、`&save` 成功、上电装载 → `W25Q64`
  - 从未保存过 → `DEFAULT`（编译默认值）
- `&save` 成功后会打印 `[PID] saved and verified; survives power cycle (auto-loaded at boot)` 并回读当前值；
  失败明确打印 `NOT saved`（RAM 值不变）。

### 上位机 2.6.0

- “转向PID”页状态行显示 **参数来源**（默认值 / W25 已保存 / RAM 手改未保存），读取 `&pid` 时提示来源。
- **未应用拦截**：改了输入框却没点“应用到RAM”就点转向，会弹提示并拒绝发送，
  不再“以为调了其实没发下去”。
- 仍不自动发任何指令；断开/换会话后来源与已知生效值复位。

## 3. 现场正确流程（V236）

1. 烧 V236，上电观察 `[PID] BOOT ...`（应有一行，说明当前来源）。
2. 上位机“转向PID”页 → **读取当前(&pid)**：看参数与来源。
3. 调 kp/ki/kd → **应用到RAM**（此时来源变 `MANUAL`，立即生效）→ 点转向验证波形。
4. 满意后 **保存到W25(&save)**（来源变 `W25Q64`）。
5. 断电重启 → 上电日志应为 `[PID] BOOT source=W25Q64 kp=...`，页面“读取当前”来源显示 W25 已保存。

> 若第 3 步后不保存就重启，PAGE 会显示 `DEFAULT`（或上次保存的旧值），这是预期行为，不是新故障。
