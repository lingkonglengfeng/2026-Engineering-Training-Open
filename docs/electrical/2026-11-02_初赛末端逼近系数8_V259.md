# V259 PRELIM：末端逼近系数4改为8

针对用户观察到的“速度已经很低、但仍在运动补最后几毫米”的拖尾，普通导航和出场脚本的 `NAV_ODOMETRY_APPROACH_GAIN` / `NAV_ODOMETRY_EXIT_APPROACH_GAIN` 均由4改为8。

末端速度仍取制动能力允许值和“剩余距离×逼近系数”两者较小值；改变的是后者，便于更快接近停车触发点。原巡航速度、加速度、普通/转向减速度、距离系数、2mm停车触发、位置稳定100ms、段末复核及转向入口条件保持。没有加入30RPM提前转向，没有修改原地转向PID、直行航向Kp或视觉纠偏。
