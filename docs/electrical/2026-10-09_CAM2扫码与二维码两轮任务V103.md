# CAM2扫码与二维码两轮任务 V103

## 安装与首次启动

主控烧录 `Engineering_Training_Project_V103.hex`。第二台MaixCAM安装 `CAM2/maix-cam2_qr-v1.0.0.zip`，应用ID为cam2_qr；也可以单独运行CAM2/main.py。第一台MaixCAM继续使用当前程序。

第二台相机倒装：每帧先旋转180°，同一张纠正后的图像用于扫码和预览；屏幕文字后绘制，正常正向显示。程序启动显示WAIT SET6，等待主控扫码请求。识别后的任务原码保留在屏幕上。

| CAM2引脚 | STM32主控 |
| --- | --- |
| A16 / UART0_TX | PA3 / USART2_RX |
| A17 / UART0_RX | PA2 / USART2_TX |
| GND | GND |

串口115200、8N1、3.3V逻辑。CAM2按既有方式供电，避免两台相机的TX并到同一路主控RX。

停车扫码调试可发送 `&qrscan start`，此指令不移动底盘。用 `&qrscan status`、`&camstat`查看结果与通信状态。V103上电默认已开启CAM2扫码功能。

## 正常流程

空载物盘、设置机械零点并摆好车后，发送：

```text
&match reset
&prepare 1
```

2号发车位改用 `&prepare 2`。等待START姿态READY后发送一次新的 `&ok`，后续无需再次OK：

1. 出库，机械臂展开与底盘运行并行。
2. 自动规划至扫码点(2000,1200)mm，车头朝世界0°（东侧二维码区域）。等待机械臂READY及相机会话同步。
3. CAM2新SET/ACK后扫码；连续3帧同一合法任务由相机确认，主控收到完整四组并确认CAM2 STOP ACK。
4. CAM1圆盘模式确认后自动前往RAW。每批按照二维码颜色顺序，逐颗抓入载物盘1、2、3号槽。
5. ROUGH按照本批二维码位置组，将槽内物料依次放到指定圆环；全部放完后按原搬运顺序取回，各自返回原载物盘槽。
6. 第一批TEMP按照第一批位置组放置。第二批TEMP根据颜色查找第一层圆环，在同色物料上码垛；第二层松爪点仍比地面抬高72mm。
7. 两轮完成后沿既有路线返回所选发车区外侧待停车位置。最终视觉入库停车沿用此前未完成状态，本次没有新增入库动作。

槽号表示本批抓取顺序，圆环号来自任务码，两者可以不同。第二批粗加工位置也可以和第一批不同，而第二批TEMP必须按颜色匹配第一层。

例：`156+123+516+231`，第一批红/黑/浅蓝到环1/2/3；第二批黑/红/浅蓝在ROUGH到环2/3/1，在TEMP分别叠到第一层环2/1/3。

## 编码与打印

依据工程内 `docs/electrical/rules.pdf`第5—8页，二维码是四组三位数，以加号连接：第一批颜色、第一批位置、第二批颜色、第二批位置。规则编号1红、2黄、3蓝、4绿、5黑、6浅蓝；每批三色各不相同，两批使用同三种颜色，位置组为123排列。

线上工程颜色编号5浅蓝、6黑，只在颜色组互换5/6，位置组不互换。屏幕和串口原码显示规则编号。主控正常任务还检查两批颜色集合相同，以保证同色码垛成立。

`二维码8张`文件夹包含8张随机任务PNG和manifest。A4_landscape_80mm子目录内是A4横向SVG打印模板，中央二维码含静区总尺寸80×80mm。按100%原尺寸打印，关闭适应页面；PNG也写入80mm对应的DPI。每张码均有4模块白色静区。

## 关键回显

```text
[QR] LOCK raw=...; wire colors=... positions=...; waiting STOP ACK
[QR] task latched; CAM2 STOP ACK confirmed.
[ROUND PLAN] round=2 station=3 tray=1 color=... -> ring=... rise=72.0mm
```

`&arm round1 status`查看两轮库存和任务阶段。控制器以位置反馈与舵机PWM完成判断动作，没有实物抓取传感器；软件完成不等于确认物料实际被夹住。

扫码SET/ACK、完整任务或STOP确认超时会明确报故障，不使用旧任务继续。颜色未进入抓取窗口时仍等待新鲜观测，不盲抓。`&qrscan off`保留为临时固定红/蓝测试退路，正常比赛保持默认开启。

V102的ROUGH定位(1140,380)、RAW行驶点(1250,2100)、视觉纠偏后航向基准更新，以及V100圆环平面试调继续保留。
