# V119：转盘物料到位后闭爪

转盘取料改为以下非阻塞流程，适用于单次测试、连续取料及正常比赛流程的两轮全部颜色和三个载物盘槽位：

1. 等待位置保持夹爪张开225°。
2. 新鲜目标进入视觉窗口后，5号下降与6号伸出并行，夹爪继续张开。
3. 5号实际抓取高度到位、6号实际抓取目标到位并完成原有STOP保持确认后，才发送夹爪305°闭合目标。
4. 从闭爪命令发出起等待至少500ms，并要求PWM斜坡完成、轴保持有效，再开始抬升。
5. 保留原来的抓取后抬升到半程开始DM/伸缩动作、放置及后续自动流程。

500ms从闭爪开始计算，不是在约300ms的PWM斜坡结束后再额外等待500ms。若PWM仍在运动则继续等待。没有夹持传感器，完成指执行位置及闭合PWM，不代表已检测到物料。

转盘等待高度、抓取高度、伸缩25mm、视觉窗口及V118的ROUGH/TEMP圆环修正均不改变。载物盘PICK及圆环PICK继续使用V117的300ms闭合最短时间；这次500ms只用于转盘取料。

串口阶段：`TRIGGER ... grip stays OPEN until actual arrival` → `GRAB ARRIVED ... NOW close ... wait500ms` → `grip close500ms complete ... raise TOP`。这些信息可判断是否卡在下降、伸缩、闭合或抬升。

视觉任务已与用户确认最终补光需求：圆环模式PWM25%，其他模式50%，退出关灯；不修改ISP画面亮度、曝光或串口协议。配套CAM1安装包为`maix-v1-v1.1.11.zip`，需安装到CAM1；HEX刷入STM32，CAM2不变。CAM1的197项回归和单文件安装包验证通过，详细记录见包内`CAM1_tests.log`和`CAM1_validation.json`。

验证：生产物料FSM4487检查、两轮流程6790检查、自动任务邮箱132检查全部通过。覆盖下降中不闭合、闭爪499ms不抬升、500ms后可抬升、PWM未完成仍等待、闭合等待时STOP及命令失败。其他未变化机械臂/驱动功能沿用V118/V117验证。Keil编译0错误、0警告；未烧录或实机测试。

刷入V119 HEX，上电标记`CAMERA_DEPLOY_V119`。继续使用原来的比赛指令，或`&arm material loop start`单独测试转盘取料；`&arm material stop`停止。
