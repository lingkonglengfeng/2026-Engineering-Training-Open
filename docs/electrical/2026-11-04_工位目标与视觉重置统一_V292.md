# V292 PRELIM / PC2.6.25：工位导航目标与视觉重置统一

用户要求把视觉成功后重定义当前位置的坐标与上位机设定的工位导航目标同步。原代码使用不同基准：RAW目标1250/2100、锚点1250/2090；ROUGH目标1200/380、锚点1190/360；TEMP目标350/1200、锚点380/1280，共用偏移但有固定差值。

## 修改

新增唯一读取入口StationMap_TargetMm(station,x,y)，用工位目标基准+W25/RAM工位偏移计算车心地图坐标。QR/RAW/ROUGH/TEMP导航动作以及VisionAlign_StationPoseMm（station1/2/3）统一调用该入口，删除另一套视觉基准数组。FIELD MAP POINT的anchor_x/anchor_y兼容字段也从同一个基准计算，正常回报与x/y一致；BEGIN新增shared_target=1。

代码基准：QR2125/1130，RAW1250/2100，ROUGH1200/380，TEMP350/1200。例如旧RAW偏移(-3,-22)保留后，导航目标与视觉成功重定义均为(1247,2078)，不再是(1247,2068)。工位参数记录版本/地址/CRC格式不变，原W25仅保存偏移值，可直接加载，无需清空/迁移/重存。

实际视觉纠偏的目标像素、动作和容差不改；这里只统一成功后的地图车位坐标。QR仍只扫码，不新增视觉位置重置。TEMP2静止2秒跳过纠偏仍使用原里程估计，不伪造视觉成功锚点。

PC2.6.25的默认值、预览目标/重置点与说明文字同步，读取声明shared_target=1的主控时检查坐标一致。旧固件缺少标志时仍按实际回报显示独立锚点并明确提示未声明统一，不伪造相同坐标。地图编辑不发送运动命令。
