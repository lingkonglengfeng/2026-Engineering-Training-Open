# 载物盘夹取测试 V36

本版上电后夹爪PD12/TIM4_CH1自动输出张开60°（833us），载物盘PD13/TIM4_CH2仍保持失能。夹爪默认close为130°（1222us）。角度为PWM换算，没有舵机实际位置反馈。

## 测试指令

在比赛流程停止、底盘静止时发送：

```text
&arm pick
```

若比赛状态仍在运行，可先 `&match reset`，再发送测试指令。

自动顺序：
1. 张开夹爪60°，等待PWM斜坡结束，且至少500ms后再运行机械臂。
2. 5号升到TOP，然后DM到+180.7459°、6号到−136.9501°（原生绝对位置模式）。
3. 5号下降到−495.9943°。
4. 实际轴反馈到达后闭合夹爪130°，等待PWM斜坡完成且至少500ms，打印 `[ARM PICK] DONE`。DONE不代表有夹持传感器确认。

保持既有5号30RPM、6号80RPM。DM正向范围上限从180°放宽到185°以容纳实测目标。下降超过100mm时DM限制在±20°的保护保留；本次5号目标约下降98.73mm（基于现有240mm行程换算）。

```text
&arm pick status
&arm status
&arm query 5
&arm query 6
&arm query dm
```

pick status显示是否运行、阶段及目标；故障日志提供详细轴目标、实际值、反馈年龄。停止：`&arm stop`。中断或运动失败不会继续发出最终闭合动作。

本指令不会转动载物盘舵机，不覆盖start/camera姿态，不自动插入比赛取料流程。要选择盘号仍单独发 `&arm table enable` 后 `&arm table go 1|2|3`（120/210/300°）。测试结束不自动抬升，保持夹取姿态和夹爪闭合。

所有角度基于已有零点。DM使用电机内部零点；5/6号使用当前记录的参考零点。执行测试前不要在这个下降姿态重新记录TOP零点。

## 验证

姿态顺序回归98项：张开等待、到位后闭合、取消/转向失败不闭合、保留start配置；相关机械臂、自动展开及比赛流程回归通过。Keil构建0错误0警告。
