# V272 PRELIM / PC2.6.15：直线纠偏与转向衔接参数

初赛新增五项上位机调节与W25保存，默认行为保持V271。决赛仍V245。未推送、未烧录；桌面原“视觉上位机”入口重开后加载PC2.6.15，主控需配套V272。

## 当前值与含义

| 指令key | 参数 | 默认参考 | 可设置范围 |
| --- | --- | --- | --- |
| hold_kp | 编码器直行航向Kp | 0.03 / ° | 0～0.2 |
| hold_cap | 直行旋转修正幅值 | ±0.05 | 0～1 |
| hold_dead | 直行航向死区 | ±0.20° | 0～5° |
| turn_band | 转向衔接误差范围 | ±1° | ±0.1～15° |
| turn_stable | 范围内连续保持时间 | 100ms | 0～2000ms |

自动编码器直行中，误差绝对值不大于死区则旋转修正为0；超出死区时输出`clamp(误差×Kp, -限幅, +限幅)`。omega是归一化旋转指令，不是rad/s。当前参考下1°误差输出0.03，约1.67°以上达到0.05限幅。距离逼近系数8和原有12°航向超差条件保持。本次不改变视觉纠偏自身控制参数和旧时间模式的独立修正限幅。

转向到下一段直行/圆弧时，以规划目标航向判断误差，必须连续保持在设定范围内达到设定时间；越界立即重新计时。仍需现有新的四轮反馈作为下一段里程起点。没有额外添加等待零角速度、停机保护或刹车阶段。设置时间按整毫秒执行。

## 上位机操作

1. 烧录V272，重开桌面上位机，接入串口，进入“底盘参数”。
2. 点底部“读取当前值”，切换至“直线纠偏 / 转向衔接（V272起）”子页。
3. 修改所需项，点“应用此项”；也可点“全部应用到RAM”。当前值列按主控读回更新，固定参考列始终保留上述默认值。
4. 验证后点“保存当前RAM到W25”。上位机等待SAVE OK并读回；后续上电会优先加载保存值。
5. “从W25读回”恢复已存值；“参考值填入输入框”只填数，不应用、不保存。

原来的速度/加减速在同一页面的另一子页，继续共用底部读/应用/保存按钮。全部应用分为原九项和新增五项两条短指令，按回执顺序执行，避免超过串口行长度。两条应用均不写Flash，保存按钮才写入。仅空闲或原有允许的准备完成状态可修改；运行中沿用原底盘参数指令拒绝规则。

## 串口示例

```text
motion status
motion set hold_kp 0.03
motion set hold_cap 0.05
motion set hold_dead 0.2
motion set turn_band 1
motion set turn_stable 100
motion heading 0.03 0.05 0.2 1 100
motion save
motion load
```

可带`&`前缀。批量heading的五项依次为Kp、限幅、死区、衔接容差、保持毫秒。
