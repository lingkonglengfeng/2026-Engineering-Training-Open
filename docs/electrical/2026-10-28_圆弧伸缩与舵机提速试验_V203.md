# V203：圆弧、伸缩及舵机提速试验

按用户要求，以V202参数为基准：外侧连续圆弧速度提高1.2倍，伸缩默认速度提高1.1倍，载物盘和夹爪PWM目标变化速度提高1.3倍。只更新主控固件，上位机2.5.4、相机桥和W25保存参数继续使用。

## 参数变化

| 项目 | V202 | V203 |
| --- | ---: | ---: |
| 外侧圆弧默认速度上限 | 213.08mm/s | 255.696mm/s |
| 圆弧相对当前直线速度的比例上限 | 0.50 | 0.60 |
| 圆弧侧向加速度限值 | 320mm/s² | 460.8mm/s² |
| 伸缩默认载料/空载RPM | 72 / 84 | 79 / 92 |
| 载物盘PWM斜坡 | 750μs/s | 975μs/s |
| 夹爪PWM斜坡 | 1500μs/s | 1950μs/s |
| 载物盘最短等待 | 534ms | 411ms |
| 抓取闭爪最短时间 | 300ms | 231ms |
| 张爪/释放及张爪确认最短时间 | 500ms | 385ms |

RPM字段是整数，79与92分别是72×1.1、84×1.1取最接近整数；实际约1.097倍、1.095倍。用户显式设置的RAM伸缩速度仍可覆盖默认值，原有空载倍率及速度上限校验继续生效。故障恢复、低速修正和寻端点参数保持原值。

舵机等待取原值除以1.3再向上取整。所有相关分支仍要求PWM爬坡完成；大角度运动所需时间长于最低等待时，继续等实际PWM完成。默认225→308度闭爪，输出斜坡由约307ms缩短为约237ms，10ms更新周期下约240ms完成。这是输出命令时序，不是位置传感器实测。

## 圆弧限速同步

外侧转弯同时受默认速度上限、直线速度比例、`sqrt(侧向加速度×半径)`和角速度上限限制。仅提高默认值会被原限制压住，因此比例0.5→0.6，侧向加速度限值按速度倍率平方调整：`320×1.2²=460.8`。在原165mm半径下，默认255.696mm/s不会被这两项旧限值削低。

半径165mm及100°/s角速度上限保留，直线速度、普通原地转向和视觉角度纠偏速度不随本次圆弧试验提高。转弯几何、轮廓检查、航向修正、入口/出口衔接与原有失败处理保留。短行程、减速段或自定义半径仍会受到相应运动限制，不能把整个动作耗时都理解为精确除以1.2。

`outerarc speed`的RAM可调范围由80～250扩至80～300mm/s，以容纳新默认值；`outerarc status`显示实际比例和侧向限值。设置值仍会被实际轨迹限速约束。

## 保留的动作和问题状态

- 视觉展开/纠偏及车载物盘放料最终抬升至真实顶部，载料半程并行仍保留；地面圆环转运为顶部下40mm。
- W25启动优先、圆环共用三轴取放与微调、234档升降加减速、同步XY/角度纠偏及分段累计时间不变。
- 圆盘下降与伸出20mm并行，仍按两轴曲线估时后闭爪；预计时间读取当前选用RPM，会跟随伸缩配置。20mm等短行程可能在达到速度上限前就减速，因此本次不承诺这类动作耗时也缩短1.1倍。
- V202记录的TEMP同步纠偏阶段超时及偶发漏下降，仍保留诊断日志和原有策略，本次提速不作为这些异常已修复的结论。没有新增停机条件。
