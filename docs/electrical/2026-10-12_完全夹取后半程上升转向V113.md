# V113：完全夹取后抬升，升到半程开始转向

这是对V112时序的更正。请使用本包V113 HEX，替换V112。

## 现在的顺序

1. 到原来的抓取终点，等待夹爪完全闭合。
2. 5号开始升到TOP。
3. 根据5号实际反馈，当剩余下降高度小于或等于本次升顶起点的50%时，开始DM转向和6号伸缩；5号继续上升。
4. 仍须升顶到位、DM实际到位、6号STOP后的新反馈保持到位，才开始最后下降、松爪。

例如夹取时距顶部100mm，升到距顶部50mm时开始转向。此门槛按每次真实起点算，不按固定延时，也不移动原抓取和放置角度。

覆盖转盘取料后放回载物盘、载物盘取料后放到圆环、圆环取回后放到载物盘。载物盘取料/圆环取回的独立PICK完成回显仍在实际抓取高度；后续放置流程负责升顶和半程转向。

## 保留与撤回

- 保留夹爪1000µs/s的提速，225°张开、305°闭合不变，完整闭合PWM斜坡约0.44秒。载物盘舵机仍500µs/s。
- 撤回V112“夹爪闭合一半就抬升”。夹爪完整闭合后才升。
- 5号150RPM、6号60RPM、DM112.5°/s，其他V111点位、底盘0.4、第二轮TEMP±10px/3帧等保留。
- 初始START准备、空爪动作、CAMERA恢复不使用带料半程门槛。
- 原来的堵转重试、反馈和150mm高度转向保护保留。
- 载物盘最后下降仍等待其舵机完成原有到位时间；半程接管不会重复发送升顶指令。

## 回显与使用

原指令不变：`&match reset`、`&prepare 1`或`&prepare 2`，准备成功后一次`&ok`。单独测试可用`&arm pick`、`&arm material`及原放置指令。

启动标记：`CAMERA_DEPLOY_V113`。关键回显：

```text
[MAT] grab axes held and grip fully closed; raise TOP, start turn/reach at actual half-rise
[ARM PLACE] adopt existing TOP raise; grip fully closed; DM/reach wait actual half-rise
[ARM TRANSFER] actual half-rise crossed: ...; lift continues TOP, start parallel DM/reach
[ARM TRANSFER] lift TOP confirmed during turn/reach; final descent still waits both held
```

半程按ZDT实际位置反馈判断；夹爪完全闭合仍是PWM输出确认，没有物料传感器。实测请关注转向开始时夹持和机构是否稳定。

## 验证

生产C模拟测试覆盖完整闭合前不抬升、半程前不转向、跨半程后升降仍在运行时DM/6号启动、最后下降等待TOP及到位保持、已有升顶任务接管不重发、非升顶任务不能接管、STOP/升降失败取消，两轮完整路线与库存回归。Keil编译0错误、0警告。新测试日志和HEX哈希见包内manifest。

只更新STM32；摄像头程序和通信协议未改。尚未烧录或执行实物测试。
