# V231：圆环夹住后升高30mm提前回缩

[电控版本索引](README.md) · [上一版V230](2026-10-30_相机近目标保持漂移纠正_V230.md)

按用户确认，修改**自动圆环取回后返回载物盘**的流程：以夹住后实测的升降位置为起点，5号实际升高30mm即可启动6号回缩；DM仍在原实际上升半程时开始旋转。不是下降到距顶部30mm，也不是靠固定延时估计升高量。

## 动作衔接

1. 圆环取料闭爪及原下降收尾完成，记录实际抓取高度，5号继续原回真正TOP的动作。
2. 实测升高30mm后，提前接管返盘姿态并使能6号；收到原新鲜位置/使能反馈后，发送原载物盘槽位对应的绝对伸缩目标。仅提前6号，不替换仍在执行的5号上升，不重新闭爪。
3. 6号在剩余起升期间回缩，DM保留原半程高度门槛。跨过半程时只启动DM，6号保持已经发送的同一动作，不重复发新目标、不重新计时。
4. 仍须5号回到真正TOP、伸缩满足原条件及DM距目标≤5°才下降放盘；最终高度与DM到位后才张爪。原载物盘舵机选择/等待保持。

两轮圆环取回、三个来源环和三个目的载物盘槽共用。普通圆盘抓取后的返盘及其他来源的起升接管保留原半程流程；手动独立`arm place`未改为新提前模式。

对于教点导致的很短起升，工位层不晚于原半程交接，所以DM原门槛不延后；6号仍等实测30mm。若起点离顶不足30mm，则实际TOP到位后沿用原流程，不要求无法达到的额外起升距离。

## 原确认与重发保持

V229的回缩ACK/实测启动前10ms同绝对目标最多50次发送，也在提前回缩阶段生效；正确进度后停止补发。跨半程不重置本次6号原生到位期限。原错向/过冲/超时及堵转恢复保持，反馈等待暂停也覆盖提前使能计时；沿用原使能、到位和超时数值，没有新增停机规则。

新增日志：

```text
[ARM RING RETURN] actual rise=30.xxmm; enable reach NOW, DM still waits original half-rise
[ARM RING RETURN] reach target issued during rise; retain same job/ACK/deadline through later DM start
[ARM TRANSFER] actual half-rise crossed: ...; start DM, keep earlier reach job
[ARM RING RETURN] actual half-rise crossed; start DM, keep earlier reach job without duplicate command
```

其中“enable reach”与实际目标下发之间仍保留原使能反馈确认，日志并不宣称30mm瞬间机械轴已开始移动。升降/DM/伸缩速度、加速度、坐标、25mm圆盘伸出、半程闭爪、PC2.5.7两帧和W25格式保持。V230相机近目标保持漂移修复继续包含。
