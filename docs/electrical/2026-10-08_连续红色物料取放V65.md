# 连续红色物料取放 V65

在V64单次取料上新增串口控制的连续模式。默认抓红色，放载物盘1号槽。用户已确认每轮有人取走槽1物料，因此循环默认不限轮数；程序没有槽位占用传感器，不会自行确认槽1已经清空。

## 开始、停止与状态

底盘停在圆盘工作位、机械臂空闲后发送：

```text
&arm material loop start
```

每轮为：张爪225°并到等待姿态 → 等新鲜红色进入配置窗口 → 下降时立即闭爪305° → 实际到位后抬高50mm → 载物盘205°选择1号槽 → PLACE姿态放下、松爪 → 张爪并返回取料等待姿态 → 等下一颗红色。

每轮放置后不恢复CAMERA姿态，不需要再发start或OK。等待红色期间不设盲抓定时器；只有新的有效红色坐标入窗口才会抓。

```text
&arm material loop status
&arm material loop stop
```

`arm material status`也能查看循环状态；`arm material stop`、`arm stop`和全局`STOP`也会取消循环。取消后不继续放置或自动重启。单独失能任一机械臂电机或夹爪/载物盘舵机也会中止当前动作，其他轴按原停止逻辑处理。

状态字段：`phase`阶段、`active`动作是否运行、`loop`是否循环、`rounds`本次已完成放置次数、`limit`轮数上限（0为连续）、故障原因以及窗口配置。轮数只代表完成动作及松爪PWM，不表示传感器确认抓到了物料。

## 有限轮数测试

轮数上限在停止状态修改，参数只存RAM，重启恢复0：

```text
&arm material loop limit 2
&arm material loop start
```

完成两轮后显示`[MAT LOOP] DONE rounds=2 limit=2`，保持放置后的姿态，不再返回等待位。每轮仍需槽1有空间；轮数上限不能检测物料是否被取走。

恢复不限轮数：

```text
&arm material loop limit 0
&arm material loop start
```

limit范围0..1000，不能在循环中修改。新start重置rounds，保留窗口等参数。循环中再次start只回报BUSY，不打断或清零当前任务。

## 姿态与窗口

| 位置 | 5号 | 6号 | DM |
| --- | --- | --- | --- |
| 等待位 | 约−361.5644°（终点上方50mm） | −185.1581° | −2.0217° |
| 抓取终点 | −612.7679° | −185.1581° | −2.0217° |
| 载物盘放置 | 现有PLACE，约−530.8152° | −4° | +162.8250° |

50mm使用当前5号行程标定换算；5号60RPM、6号80RPM沿用当前机械臂配置。下降和闭爪在触发时同一次轮询下发，实际机械到位仍有延迟。本版不做持续转盘速度预测。

沿用V64窗口参数，空闲或WAIT_RED阶段可修改：

```text
&arm material window 0 0 12 12
&arm material fresh 150
&arm material confirm 1
&arm material jump 0
```

window参数是目标dx、dy和横纵半宽（像素）。320×240图像中心(160,120)对应dx=dy=0，默认±12px。fresh是本机接收年龄，50..200ms；confirm是1或2个不同的新观测；jump=0关闭跳变筛选。参数保留到下轮，重启恢复默认。

## 相机会话与退出

每轮重新发送CAM1 SET（mode2/station1/target1红色/20Hz/flags0），即使旧模式相同也需要新请求SEQ对应ACK。等待姿态和张爪输出准备好后，清除接收队列及旧观测、记录本轮边界；旧帧、重复观测、无效、错色、窗口外或超过fresh的坐标不能触发。一次触发先锁存动作阶段，再启动下降和闭爪、请求相机STOP。

STOP后相机仍需发心跳；循环在下降、抬升、选槽和放置期间也检查相机在线状态。相机在线超时按现有3500ms边界，ZDT反馈/DM反馈超时、驱动器故障、失能、舵机故障或底盘产生运动需求都会取消循环。定位阶段使用原姿态状态机和SET/ACK故障退出。机械阶段沿用120秒超时，选槽PWM等待最多5秒；没有新增毫米级姿态保护。

正常底盘运动指令在循环期间会被拒绝，STOP保留。若其他来源已经产生运动需求，ArmTask下一次轮询中止物料任务。启动循环与原单次相同，只允许底盘停止、比赛WAIT_OK或空闲时使用，不接管正在进行的比赛自动取料任务。

## 兼容与相机端

原`&arm material`/`&arm material red`仍只执行一轮并恢复机械臂CAMERA；原`&arm material auto on`仍在圆盘纠偏成功后自动执行一轮，默认自动接入仍OFF。loop start只启动串口手动连续模式，不修改auto开关。有限轮数完成或停止循环后，如要回相机姿态，空闲时另发`&arm camera`。

统一相机v19协议保持：MAT_PX 0x02，ID1红色，小端int16×10，dx右正/dy下正。视觉端已确认：新SET清跟踪及待发坐标并ACK，STOP模式继续0.5秒心跳，红色不存在时发ID1/VALID0，位置SEQ随提交递增并模16回绕。无需为循环修改相机二进制协议。

独立MaixVision阈值调试程序不打开UART，不能用于本固件联动；测试循环前需停止该程序并运行统一相机main.py。手动Color切换六色用于阈值调试，循环当前仍请求target1红色。
