# V301 PRELIM / PC2.6.33：ROUGH与TEMP圆环参数共用开关

机械臂控制的“ROUGH / TEMP三点微调”页新增“ROUGH / TEMP共用参数”开关和“保存当前RAM到W25Q64”按钮。该模式控制三点的升降、伸缩、DM角度微调，预览、独立调试及自动取放使用同一选择；原速度倍率及动作时序保持。

- 勾选：两工位使用ROUGH的三点参数，在ROUGH或TEMP页应用微调均修改共用组。
- 取消：分别保存和使用ROUGH、TEMP两组三点参数。首次取消时，将当时的共用组复制给TEMP作为起点。
- 再次勾选：以ROUGH作为共用参数，保留此前独立TEMP组；之后取消可继续使用该组。开关切换不发运动命令。

自动ROUGH放料、ROUGH圆环取料使用ROUGH组，自动TEMP放料使用TEMP有效组。第二轮TEMP在选中组的目标高度上仍使用原72mm叠层抬高。原夹爪、载物盘角度、四姿态、地图、视觉纠偏及速度参数不因这个开关改变。只修改初赛源码，决赛独立目录未同步。

## 操作

1. 烧录初赛V301，重开桌面上位机加载PC2.6.33，读取状态和圆环目标。
2. 机械臂空闲时选择是否共用。上位机等待主控确认，然后重新读取六点和状态。
3. 选择ROUGH/TEMP及1/2/3号点，调整滑块，点击“应用所选点微调到主控RAM”。预览滑块尚未应用时不会写入保存记录。
4. 点击“保存当前RAM到W25Q64”，同时保存模式、两组三点和原舵机预置。上电自动加载，继续使用已保存模式。

旧固件仍能读取原参数，但本开关在PC上禁用，需V301支持。已有主控动作未结束时沿用空闲修改要求，不新增停机流程。

## 指令与保存兼容

`arm ring shared 1`共用，`arm ring shared 0`独立，`arm ring shared status`查询。回执`[ARM RING MODE] HAL=0 shared=... temp_saved=...`；`arm ui`的`shared_ring`动态报告真实模式，`arm points`返回当前模式下有效的六点。`arm trim rough|temp N dl dr dd`仍为绝对微调赋值。`arm params save/load`保存/读取全部圆环与舵机参数。

保留原108字节记录、CRC、双备份及初赛8/7扇区。旧版本1/2记录按原规则加载为共用，使用ROUGH，首次独立复制当前组，不恢复历史未使用的TEMP字节。新记录的版本字段使用0x0100格式标记及共用、独立TEMP已建立、原初赛备份就绪标志；两组及模式均可重启恢复。V300及以下不识别新保存的记录，回退旧固件前需记录当前参数。现有决赛参数扇区及其它参数区不改。
