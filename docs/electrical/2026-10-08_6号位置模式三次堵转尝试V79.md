# 6号位置模式三次堵转尝试 V79

用户确认总共3次尝试：首次位置命令为第1次，堵转后最多再尝试2次，第3次失败停止流程。

## 位置控制和自动恢复

自动等待位、取料伸出、PICK/PLACE/圆环和CAMERA的6号原生绝对位置命令继续使用mode01 ABS。不是把25mm等距离重复累加。新增恢复状态机缓存该次原始目标脉冲、速度、加速度及方向配置。

当有效6号状态回报堵转时：

1. 请求停止6号，保留当前任务目标；
2. 非阻塞等待150ms，发送清堵转指令；
3. 等新的状态反馈确认堵转已清除；
4. 重新使能，等更新的状态反馈确认；
5. 重新发送同一个绝对目标，等待实际位置到位。

如果第2次仍堵转，进行第3次。第3次再次堵转，或堵转清除/使能持续失败耗尽恢复尝试，退出任务并请求停止。不能清除的堵转不会盲发位置运动命令；清除/使能失败也算当前恢复尝试失败。

恢复期间，不用旧位置/旧状态或ACK证明完成。原到位/STOP后保持检查重新计数，之后才允许抬升或下降放料/松爪。6号恢复可以与5号已有下降任务并存，不把6号清堵转错误地阻塞在5号动作完成之后。

## 不进行堵转重试的情况

通信失效、驱动器其他保护、发送失败、方向配置在动作中被修改，或其他机械臂电机故障会直接退出，不强行凑满3次。STOP和任一机械臂电机失能会取消待处理重试，后续迟到反馈不能重新启动旧运动。

普通流程失败沿用停止全部动作和保持夹爪现状的处理；CAMERA失败沿用原本健康DM零点保持策略，不因新增重试去重设零点或自动松爪。

该重试针对6号原生绝对位置命令。原手动百分比速度控制、相对脉冲命令及已有小残差编码器修正没有改成新的自动重试模式。

## 直接指定6号位置

机械臂停止、零点和反馈有效时：

```text
&arm enable 6
&arm pos 6 -185.1581
```

单位为相对机械臂记录零点的度，负角度按当前机械臂坐标表示外伸。该指令是原生绝对位置，不累加到当前位置；堵转自动按上述总共3次尝试。HAL=0代表排队，不代表实际已到位。

```text
&arm query 6
&arm status
&arm stop
```

自动物料流程无需新开关，原指令即可：

```text
&arm material loop limit 1
&arm material loop start
```

`loop limit`是取放轮数，和每个6号位置任务的3次尝试是两件事。单个目标失败后整个循环退出，不自动开始下一轮。

## 串口回显

```text
[REACH RETRY] stall -> attempt=2/3 STOP/clear/enable; SAME ABS target=...
[REACH RETRY] attempt=2/3 SAME ABS target=... resent; wait actual position
[REACH RETRY] stall -> attempt=3/3 STOP/clear/enable; SAME ABS target=...
[REACH RETRY] FAILED attempts=3/3: ...; reach STOP requested; owner stops flow
```

无需人工连续发start。堵转真实原因仍需通过位置、驱动器状态和现场机构观察判断，本功能不宣称已经修复机械卡阻。
