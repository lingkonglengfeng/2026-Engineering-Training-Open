# PC2.6.23 上位机补光亮度控制（CAM1桥1.3.4）

## 版本
- 上位机：PC2.6.23。
- CAM1电脑视觉桥接：1.3.4（新增9004亮度控制端口）。
- 主控固件、W25 参数、地图偏移、CAM2桥接均无需更改。

## 功能
上位机 CAM1 页左侧新增“CAM1补光亮度”：
- 滑条 0～100%：设置 A18/PWM6 的占空比；点“应用亮度”后下发到相机。
- “自动”：恢复按识别模式的默认值——圆盘模式8/物料模式2 为50%，圆环模式3及其他模式为100%。
- 状态文字显示当前值（自动 / 手动 xx%）、发送中、失败原因；连接相机后自动应用上次保存值（`config.json` 的 `fill_light`，null=自动）。
- CAM2 页不显示该面板；CAM1桥1.3.3及更早没有9004端口，会提示“补光连接失败…（需CAM1桥1.3.4）”，图传/视觉不受影响。

## 协议（相机桥9004端口）
- 连接方式与9000/9001/9003相同，普通TCP；逐行UTF-8 JSON，每行一条命令，回复一行JSON。
- `{"light": 0..100}`：设为手动占空比（自动取整并限幅0～100）。
- `{"light": null}` 或 `{"light": "auto"}`：恢复模式默认（圆盘/物料50%，圆环100%）。
- `{"status": true}`：只读回显，不改亮度。
- 回复：`{"ok":true,"percent":55,"manual":55,"mode":2}` 或 `{"ok":false,"error":"..."}`。
- 手动值只保存在相机RAM，相机桥重启后恢复“自动”并在首次模式请求时按默认值输出；上位机重连后会再次应用已保存的 `fill_light`。
- 9004 与图传9000/控制9001/标注回显9003、UART协议8完全独立；端口被占用只打印日志，不影响图传、串口和识别。相机桥的 hello/发现报文同时带上 `light_port`（CAM1）。
- 实机亮度是灯板PWM占空比，不是标定后的流明值；过低占空比可能闪烁或相机曝光不足，需现场核对。

## 操作
1. 相机安装 `vision/maixcam_bridge/dist/maix-cam1_pc_bridge-v1.3.4.zip`（CAM1桥1.3.4）并运行“工训CAM1电脑视觉桥接”。
2. 电脑运行 `视觉上位机.cmd`（PC2.6.23），连接CAM1后，在左侧“CAM1补光亮度”调节并点“应用亮度”；点“自动”恢复模式默认。
3. 设置保存到该页自己的 `config.json`：`fill_light`（null或0～100整数）、`light_port`（默认9004）；下次启动连接后自动应用。
4. 不需要重烧主控、不修改W25和相机标定；相机桥可回退1.3.3包（回退后亮度只能按模式50%/100%）。

## 验证
- 相机桥：`tools/tests/test_camera_fill_light.py` 11项通过（含手动覆盖模式、自动恢复、非法命令、限幅、9004只对CAM1启动、hello回报、socket命令回环）。
- 上位机：`tools/tests/test_light_control.py` 6项通过（TCP回环、自动/手动、取整限幅、旧桥/坏回执、配置校验）；`tools/tests/test_pc_vision.py` 增加GUI面板与保存项测试。
- 未连接实体相机/小车，无线实时性和灯板亮度效果需现场实测。
