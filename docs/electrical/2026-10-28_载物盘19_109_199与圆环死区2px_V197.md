# V197：载物盘三槽角度与普通圆环 ±2px

> 本文记录该版本行为。当前 V198 的启动优先级、共用放置参数和纠偏策略见 [V198说明](2026-10-28_W25启动优先与共用放置纠偏_V198.md)。

本版承接 V196，PC 上位机 2.5.3 保留 2.5.2 的单轴使能握手修复。

## 载物盘

| 槽位 | 新默认角度 | PWM 目标 |
| --- | ---: | ---: |
| 1号 | 19° | 606 μs |
| 2号 | 109° | 1106 μs |
| 3号 | 199° | 1606 μs |

自动物料槽和手动 `arm table go 1/2/3` 的出厂默认采用这组值。开机仍按原流程选择 2 号槽，对应 109°；舵机角度跨度、PWM 周期、旋转速度和等待时间使用原设置。上位机离线初始槽位字段也同步为 19/109/199，连接后仍以主控实际参数为准。

W25 参数先通过原有 CRC/版本校验；如果保存的三槽值恰好是原出厂 `205/295/25`，加载时在 RAM 中改为 `19/109/199`。只替换这个旧默认组合，保留自定义三槽值、夹爪预置和六个圆环点的微调；不自动擦写 Flash。需要持久化升级值时点击“保存主控参数到 W25Q64”。已有其它自定义三槽值时，在面板填入 19/109/199，点击应用并保存即可。

现有 V196 也可用 `arm table presets 19 109 199` 更新自动物料槽，随后 `arm params save` 保存；这两条参数指令本身不转动舵机。普通圆环死区的修改需要更新 V197 主控。

## 位置纠偏死区

| 模式 | V196 | V197 |
| --- | ---: | ---: |
| RAW 圆盘 | ±16 px | ±16 px |
| ROUGH 普通圆环 | ±5 px | **±2 px** |
| TEMP 普通圆环 | ±5 px | **±2 px** |
| TEMP 第二轮叠层 | ±10 px | ±10 px |

普通圆环只有 X、Y 误差均不超过 2 px，并满足原有连续新帧及稳定时间条件才报告到位。2.1 px 仍应输出纠偏，不直接判到位。第二轮 TEMP 叠层沿用原有专用 10 px 容差和 3 帧确认，不受普通圆环默认 2 px 覆盖；阶段配置拷贝不改变其它轮次的基础参数。

角度纠偏策略和 0.8° 末端复核、位置纠偏速度、PID、搜索、稳定时间、运动时间预算及故障处理均沿用原设置。只缩小用户指定的普通圆环位置死区，没有新增停机保护。像素阈值不是毫米定位精度；最终效果取决于真实图像抖动、标定和底盘运动，需要现场核对。
