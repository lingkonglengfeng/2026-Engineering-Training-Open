# V298 PRELIM / PC2.6.29：载物盘5mm松爪、近障碍斜坡停车

## 放回载物盘

圆盘抓取后放回载物盘、圆环夹取后放回载物盘及独立`arm place`共用的载物盘放料动作，5号实际高度进入目标±5mm后即可开始松爪。DM仍须最终到位，6号仍须通过原放料到位检查；两轴门限和闭爪时序不变。地面圆环放料的升降到位门限不变。

原生升降控制器在这一个放料阶段交出软件定位任务，保留驱动器的原ABS目标，不发到位STOP，5号可以继续收敛。松爪命令经过原50ms后允许后续流程接管，不等待PWM渐变结束，也不再等待原0.5mm稳定采样。后续升降动作按原流程覆盖旧目标。日志新增`id=5 TRAY RELEASE within5mm`及`[ARM PLACE] OPEN lift_err=... <=5mm`，可以确认实际触发位置。

## 近障碍停车

原近障碍暂停调用`ChassisMotor_StopImmediate`，直接发驱动器FE停车。现改为`ChassisMotor_Stop`，像普通目标末端一样使用现有软件速度斜坡降到零，经原四轮同步速度输出下发。减速度沿用上位机“底盘参数→速度/加减速→普通减速度”，单位RPM/s；不额外乘倍数，不改巡航速度，也不改该值及W25记录格式。人工急停、故障停止的原立即停车行为保留。

原800mm观察减速、420mm停车触发、接近最低15RPM保持不变。触发后立即停止旧路线继续给速，持续查询四轮位置；四轮软件输出归零且实测轮位连续100ms停稳后，才更新停车位置、障碍落图并重新规划。减速期间的位移计入原编码器位置更新，圆弧保留其原航向积分。原路线请求及目标保留，原NO_PATH暂停/人工重试方式保留，没有新增故障门限或定时停机。

这是依据编码器测量更新停车位置，不能直接测出轮子相对地面的滑移，也不把车位强行吸附到理想坐标。减少急停有助于降低滑移；实际效果仍须实车验证。

日志新增`[VOBS BRAKE] RAMP decel=...RPM/s`；`navswitch status`增加`stop_mode=RAMP`。上位机读回后显示“按普通减速度斜坡停车，实测停稳后重规划”，旧固件无字段时保持原显示。重开桌面上位机加载PC2.6.29，烧录初赛V298后运动行为生效，参数无需重新保存。
