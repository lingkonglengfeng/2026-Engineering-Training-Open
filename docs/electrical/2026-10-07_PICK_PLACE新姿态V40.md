# PICK / PLACE新姿态 V40

共用目标更新为用户实测角度：5号−504.5197°（raw −91845）、6号+0.4669°（raw +85）、DM +158.8785°。角度基于当前零点，目标设置不会重新记录零点。

5号默认60RPM、6号80RPM。按用户最终选择，最高点下降保护阈值150mm；下降超过该值时DM仍限制±20°。本次5号目标按当前标定约下降100.42mm。

## 抓取测试

`&arm pick`

张开夹爪60° -> 5号升TOP -> DM转向与6号伸缩同时启动 -> 两者都确认到位 -> 5号下降 -> 夹紧130°。

## 放置测试

`&arm place`

先检查夹爪已使能并在闭合PWM预设停稳 -> 5号升TOP -> DM与6号同时运动 -> 两者都确认到位 -> 5号下降 -> 张开60°。

本版替代V39中PLACE的5/6号同时运动：最终为DM/6号同时运动，5号在高位等待二者完成后才下降。start/camera动作及目标保持原有配置。

## 查询和停止

```text
&arm pick status
&arm place status
&arm status
&arm query 5
&arm query 6
&arm query dm
&arm stop
```

使用测试指令前底盘须静止、比赛流程停止。测试完成保持当前姿态，不自动抬升。上电夹爪默认张开60°。

6号+0.4669°为零点附近小幅正角度，原生绝对脉冲换算接口允许既有3mm零点容差范围内的小负百分比；较大越界仍拒绝。沿用现有到位容差，不能将输出角度当作精确到0.0001°的控制精度。若6号已在零点附近到位带内，不会为了0.4669°反复补走。

夹爪闭合/张开以PWM状态判断，没有舵机实际位置和夹持反馈。

软件验证包含DM未到位期间6号启动、两者未都到位时升降等待、升降完成前不松爪、闭合前提、停止及故障不继续夹取、原start姿态不被覆盖。未烧录、未实机运行。
