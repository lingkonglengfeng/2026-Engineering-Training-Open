> 适用赛事：第十届中国大学生工程实践与创新能力大赛 · 智能+工程创新赛道 · **智能搬运赛项**

## 1. 项目概述

### 1.1 赛项任务

智能搬运赛项要求小车在限定场地内自主完成如下全流程任务：

1. 从启停区一键启动出发；
2. 行驶至二维码板，读取并显示**任务码**（4 组三位数，如 `156+123+516+231`）；
3. 在原料区按任务码指定的顺序，每次抓取 1 个物料并放上载物台；
4. 运至粗加工区，按任务码位置放入对应编号圆环；
5. 将粗加工区物料搬运至暂存区，按位置放置；
6. 返回原料区，进行第二批 3 个物料的相同流程；
7. 第二批在暂存区完成**码垛**（第二批码在第一批上，且颜色必须一致）；
8. 返回启停区，显示完成统计（抓取 / 放置正确次数）。

贯穿全程的约束：灰色车道导航 + 黑色障碍物（φ50×100 mm）避障；车体铅垂投影 ≤ 300×300 mm、高度 ≤ 400 mm；全程使用同一内部电源，不得更换；一次性启动，不得自动重复运行。

### 1.2 电控设计目标

- **可靠性**：任务可稳定、可重复完成，通信超时、急停、掉料、越界等故障均可收敛到安全态；
- **实时性**：控制闭环与安全任务高优先级运行，不被通信与显示阻塞；
- **可维护性**：分层解耦，应用层不直接访问 HAL，接口冻结、参数集中；
- **可追溯性**：引脚表、协议、故障码、参数表与代码版本一一对应。

## 2. 总体方案

### 2.1 系统组成

整车电控系统由以下功能模块组成：

| 子系统 | 器件 / 方案 | 接口 |
|---|---|---|
| 主控 | STM32H723ZGT6 | — |
| 底盘驱动 | 4 × 张大头 X42S 闭环步进电机 | FDCAN2（500 kbit/s） |
| 机械臂旋转轴 | 达妙 DM 关节电机 | FDCAN1（经典 CAN，1 Mbit/s） |
| 机械臂升降 / 前后 | 2 × 张大头 35 闭环步进 | FDCAN2（与底盘同总线） |
| 抓取 / 转盘 | DS3218 抓取舵机 + 360° 转盘舵机 | TIM4 PWM |
| 视觉 | 2 × MaxiCAM（二维码识别 / 视觉避障） | USART1 / USART2 |
| 姿态传感器 | HWT101（TTL） | USART10 |
| 显示 | 陶晶驰串口屏 / IPS200 | USART3 / SPI2 |
| 补光 | LED 补光灯（软件 PWM） | PD1 / PD2 |
| 参数存储 | W25Q64 SPI Flash | SPI1 |
| 调试 | USB-TTL | UART4 |

### 2.2 分层架构

电控软件采用四层结构，自顶向下为：

```text
应用层 Application
  match_fsm         比赛流程状态机、动作编排、得分统计
  mission_parser    任务码解析与合法性校验
  safety_manager    急停、超时、心跳、故障锁存
  display_service   任务码 / 统计 / 故障显示

领域层 Domain
  motion_manager    底盘导航、圆环定位、避障策略
  manipulator       转盘取料、载物台放料、粗加工/暂存区放置、码垛
  perception        二维码 / 颜色 / 圆环 / 障碍物结果模型
  scoring           抓取、放置、码垛和回站统计

设备抽象层 BSP / Drivers
  zdt_motor / dm_motor / vision / servo / light / ips200 / w25q64 / pid_storage ...

STM32 HAL / CMSIS / FreeRTOS
```

设计原则：

1. **分层隔离**：应用层禁止包含 `stm32h7xx_hal_*.h`，只通过设备抽象接口 `open/send/read/stop/health` 操作外设；
2. **消息驱动**：任务间通过队列、事件组、通知交换数据，禁止无保护地共享可变结构；
3. **非阻塞**：流程等待用状态机 + 超时，不用 `HAL_Delay`；
4. **实时优先**：1 kHz 控制节拍由硬件定时器产生，控制任务只消费节拍通知；
5. **故障收敛**：任何通信超时、急停、掉料、越界、看门狗异常均能进入安全态。

## 3. 主控选型与资源配置

### 3.1 主控选型

选择 **STM32H723ZGT6** 作为主控，理由：

- ARM Cortex-M7 @ 550 MHz，算力满足 1 kHz 控制闭环 + 多路通信解析 + 状态机；
- 1 MB Flash、564 KB RAM，可容纳 FreeRTOS + 参数表 + 视觉协议缓冲；
- 3 × FDCAN、8 × USART、3 × SPI、4 × I2C，外设资源充足；
- 与往年学长工程（省赛 CtrBoard 同为 H7，国赛为 F407）相比，本方案单主控完成全部电控任务，不需要上位机分算，硬件更紧凑。

### 3.2 时钟配置

| 项目 | 数值 | 说明 |
|---|---|---|
| HSE | 25 MHz | 外部晶振（`HSE_VALUE = 25000000`） |
| PLL 输入 | 12.5 MHz | HSE / PLLM = 25 / 2 |
| PLL 倍频 | ×44 | PLLN = 44 |
| SYSCLK | **550 MHz** | PLLP 分频 1 |
| AHB (HCLK) | 275 MHz | SYSCLK / 2 |
| APB1 / APB2 | 137.5 MHz | AHB / 2 |
| FDCAN 内核时钟 | 80 MHz | PLL2（`RCC_FDCANCLKSOURCE_PLL2`） |
| SPI1/2/3 时钟 | ≈183.3 MHz | PLL |

> 注：README 中"HSE 8 MHz"为早期描述，实际 `.ioc` 与 `stm32h7xx_hal_conf.h` 均为 **25 MHz**，本报告以代码与 CubeMX 生成为准。

## 4. 电源与供电设计

### 4.1 电源拓扑

采用**单电源**方案，6S 航模锂电池（标称 22.2 V，满电 25.2 V）全程供电：

```text
6S 锂电池 (22.2 V)
├── 电机驱动域 (22.2 V 直接)
│   ├── 底盘电机驱动 ×4（张大头 X42S）
│   └── 机械臂电机驱动（达妙 + 张大头 35）
├── DC-DC 22.2 V → 12 V   → 补光灯
├── DC-DC 22.2 V → 5 V    → 主控 / 视觉 / 显示（URB4805YMD-10WR3）
│   └── LDO AMS1117-3.3   → 主控核心 / 传感器（3.3 V）
└── 舵机独立 7.4 V 电源模块（带 EN 使能脚，SAFE_STOP 可切断动力）
```

### 4.2 电源域划分

| 电源域 | 电压 | 用途 | 隔离原因 |
|---|---|---|---|
| 电机驱动域 | 22.2 V | 全部电机驱动 | 大电流、启停尖峰与噪声隔离 |
| 补光灯域 | 12 V | LED 补光 | 独立供电，避免拉低数字轨 |
| 数字电路域 | 5 V / 3.3 V | 主控、视觉、显示、传感器 | 稳定电压 |
| 舵机电源域 | 7.4 V 独立 | DS3218 / 转盘舵机 | 舵机堵转电流大，独立带 EN |

关键保护与约定：

- TVS 采用 **SMBJ26A**（6S 满电 25.2 V 贴近 24A 档击穿下限）；
- 所有外设与主控共地，舵机功率地与逻辑地**单点汇接**；
- 舵机严禁取 MCU 3.3 V，必须独立供电；
- 上电顺序：先低压后高压；断电顺序：先高压后低压。

## 5. 通信接口设计

### 5.1 CAN 总线

| 总线 | 引脚 | 连接对象 | 波特率 / 帧格式 | 消息 RAM |
|---|---|---|---|---|
| FDCAN1 | PA11/PA12 | 达妙关节电机 | **经典 CAN，1 Mbit/s** | 偏移 128 word 起 |
| FDCAN2 | PB12/PB13 | 张大头步进 ×6 | 500 kbit/s 经典 CAN | word 0~127 |

达妙电机控制协议（`dm_motor.c`，2026-09-14 按官方例程与参考工程核对后修正）：

- 控制帧 ID = ESC_ID + 模式基址（MIT 0x000 / POS 0x100 / SPD 0x200 / PSI 0x300）；本车用 **POS 模式 → 0x101**；
- 反馈帧 ID = MST_ID（达妙上位机配置）；本车实测 **0x11**（ESC 0x01）；
- 支持使能（FF..FC）、失能（FF..FD）、清故障（FF..FB）、保存零点（FF..FE）；
- 反馈解析：位置、速度、扭矩、MOS 温度、线圈温度、状态/故障码、在线心跳与帧计数；
- ⚠ 反馈帧**没有电流字段**，POS 模式拿不到电流（只有 PSI 模式才有，而 PSI 需 CAN FD）；温度字段在老固件上可能为 0；
- ⚠ 本车是**经典 CAN**，不是 FD：此前"FD 1M/2.5M"的写法有误，PSI 模式不可用。详见
  [达妙转盘移植说明](../hardware/达妙转盘移植说明_2026-09-14.md)。

张大头步进协议（`zdt_motor.c`）：

- 扩展 ID `(地址 << 8) | 包序号`，带校验和；
- 提供使能 / 失能 / 停机 / 速度控制与总线健康监测（TX/RX 计数、掉帧、bus-off、CAN error）。

> 说明：底盘 4 + 机械臂 2 共 6 台步进全部挂 FDCAN2，达妙独占 FDCAN1，两条总线报文 ID 互不冲突；任一驱动故障统一映射为"在线 / 超时 / 堵转 / 过流 / 过热 / 急停"健康状态。

### 5.2 UART 串口

所有 UART 默认 115200 8N1，TTL 按 3.3 V 电平核对：

| 外设 | 引脚 | 连接对象 | 接收方式 |
|---|---|---|---|
| USART1 | PB14/PB15 | MaxiCAM #1（二维码） | DMA 循环 + IDLE 断帧 |
| USART2 | PA2/PA3 | MaxiCAM #2（避障） | DMA 循环 + IDLE 断帧 |
| USART3 | PB10/PB11 | 陶晶驰串口屏 | — |
| UART4 | PC10/PC11 | 调试串口 | DMA 循环 |
| USART10 | PE2/PE3 | HWT101 | DMA 循环 + 逐字节解析 |

4 路 RX 均配置 DMA 循环接收（`UART4_RX / USART1_RX / USART2_RX / USART10_RX`），由 IDLE / 半满 / 全满事件摘取新字节喂解析器，降低 CPU 中断负载。

### 5.3 SPI / I2C

| 外设 | 引脚 | 用途 |
|---|---|---|
| SPI1 | PA5(SCK)/PA6(MISO)/PA7(MOSI)/PA4(CS) | W25Q64 SPI Flash（PID 参数持久化） |
| SPI2 | PA9(SCK)/PC1(MOSI)/PC2_C(MISO)/PC6(CS)/PC7(DC)/PC8(RST) | IPS200 屏（不接 MISO） |
| I2C1 | PB6(SCL)/PB7(SDA) | 通用 I2C 扩展（非 HWT101） |

## 6. 执行器控制设计

### 6.1 底盘电机（张大头 X42S）

- 4 台闭环步进构成底盘，统一由 FDCAN2 总线命令，保证四轮扭矩 / 速度一致；
- 设备层向上提供 `enable / set_velocity / set_position / stop_immediate / read_status` 语义；
- 上位状态机不直接操作 FDCAN 寄存器，速度 / 加速度 / 轮径 / 轮距等参数集中管理；
- 底盘运动学（麦轮 / 轮式解算、脉冲换算）复用往年学长已验证的 `wheel_solution()` 思路，参数重新标定。

### 6.2 机械臂关节电机（达妙）

- 旋转轴使用达妙 DM 关节电机，FDCAN1 总线，支持 MIT / POS / SPD / PSI 四种模式
  （本车实测为 **经典 CAN 1 Mbit/s + POS 模式**，PSI 需 CAN FD，当前不可用）；
- 初始化仅配置总线与解析，**不使能电机、不发控制帧**，符合"上电不运动"安全约定；
- 状态机按需调用 `Enable / Set 系列`，安全态调用 `ClearCtrl / Disable`；
- 2026-09-14 起驱动改为**句柄式** `DM_Motor_*(dm_motor_t *motor, ...)`，
  机构层在 `arm_task.c`（`ArmTask_*`），并由 `armTask`（10 ms）周期服务；
- **失去控制即松劲**：反馈超时 200 ms 自动 `DM_Motor_Disable()` 并在调试串口打印。

### 6.3 舵机（抓取 / 转盘）

- 物料抓取舵机 DS3218（270°）→ PD12 / TIM4_CH1；
- 转盘舵机 → PD13 / TIM4_CH2；
- 50 Hz 标准舵机协议（500~2500 μs 脉宽对应 0~270° 行程）；
- 采用**限速斜坡**（`Servo_Update()` 周期调用，5~20 ms），非阻塞；
- 急停场景 ISR 只调用 `Servo_RequestSafeStop()` 置标志，PWM 停止由任务上下文完成。

### 6.4 补光灯

- PD1 / PD2 转为补光灯调光输出（H723 上两脚无可用硬件 PWM 复用）；
- 采用 **TIM6 16 kHz 更新中断 + GPIO 翻转** 的软件 PWM，灰度 16 级 → 1 kHz 调光频率；
- 3.3 V 直驱，占空比 0~100% 可调，`Light_Init / SetDuty / On / Off` 接口。

## 7. 传感器与视觉接口

### 7.1 HWT101 姿态传感器

- USART10，115200 8N1，DMA 循环接收 + 逐字节解析；
- 解析 Yaw（0x53 帧）与 Z 轴角速度（0x52 帧），带 8 位校验和；
- 上电静止建立初始基准，之后累计 Yaw 相对变化量，并对 ±180° 角度差做折返处理，保证累计角连续，用于底盘航向闭环与原地自旋到位判定。

### 7.2 MaxiCAM 视觉协议

视觉帧统一协议：`@TYPE,field=value,...,seq=NN*CS\r\n`

- 最大 128 字节，超长整帧丢弃并计数；
- CS = `@` 后到 `*` 前所有字节的 XOR-8，两位大写十六进制；
- 四类帧：`QR`（二维码任务码）/ `RING`（圆环坐标）/ `COLOR`（物料颜色）/ `OBS`（障碍物距离）。

| 帧类型 | 内容 |
|---|---|
| QR | 规范化任务码字符串（≤15 字符，如 `156+123+516+231`） |
| RING | 圆环编号、相对坐标 (x, y)、角度 theta、置信度 |
| COLOR | 物料编号、颜色编号、置信度 |
| OBS | 前 / 左 / 右距离（9999 表示无效测距） |

电控只做字符串解析与数据模型封装，不接触图像与视觉算法，与视觉组通过本协议解耦。

### 7.3 任务码解析规则

- 任务码 = 4 组三位数，以 `+` 连接；
- 颜色编号：红 1、黄 2、蓝 3、绿 4、黑 5、浅蓝 6（每种 2 个）；
- 第 1 组：第一批 3 个物料的颜色与搬运顺序；
- 第 2 组：第一批在粗加工区 / 暂存区的放置位置（圆环编号）；
- 第 3 组：第二批 3 个物料的颜色与顺序；
- 第 4 组：第二批在粗加工区的放置位置。

## 8. 软件架构设计

### 8.1 FreeRTOS 任务模型

优先级数值越大越优先；栈大小为初始值，需用 `uxTaskGetStackHighWaterMark()` 实测收敛：

| 任务 | 周期 / 触发 | 建议优先级 | 主要职责 |
|---|---:|---:|---|
| SafetyTask | 事件 + 10 ms | 48（Realtime） | 急停、心跳、故障锁存、统一停机 |
| ControlTask | 1 kHz 通知 | 40（High） | 底盘 / 机械臂控制计算、输出最新目标 |
| MotionTask | 10 ms | 32（AboveNormal） | 导航、圆环 PID 外环、避障降速 |
| MatchTask | 事件驱动 | 24（Normal） | 比赛状态机、动作原语编排 |
| PerceptionTask | UART/CAN 事件 | 24（Normal） | 解析视觉、二维码、障碍物帧 |
| ActuatorTask | 事件 / 10 ms | 24（Normal） | 舵机、转盘、机械臂动作序列 |
| CommsTask | UART/CAN 事件 | 16（BelowNormal） | 统一发送队列、重试、链路统计 |
| DisplayTask | 100 ms + 事件 | 8（Low） | 屏幕刷新，故障态优先 |
| TelemetryTask | 100 ms | 8（Low） | 调试日志、运行计数、参数快照 |

当前工程已具备 FreeRTOS 骨架（`freertos.c`），创建了 `defaultTask` 与 `zdtMotorTask`，并接入了栈溢出钩子（记录溢出任务与 `g_boot_error=5`）。业务任务规划迁移进 `App/Src/freertos_app.c`，避免 CubeMX 重新生成代码时丢失。

### 8.2 RTOS 对象契约

| 对象 | 类型 | 生产者 → 消费者 | 约束 |
|---|---|---|---|
| q_vision_rx | Queue | UART ISR → PerceptionTask | 满队列丢旧帧并计数 |
| q_cmd_motion | Queue | Match/Motion → ControlTask | 只保留最新目标或显式序号 |
| q_actuator | Queue | MatchTask → ActuatorTask | 动作带超时、取消令牌 |
| q_display | Queue | 各服务 → DisplayTask | 低优先级，可合并刷新 |
| q_can_tx | Queue | 领域层 → CommsTask | 同一总线发送入口单一所有权 |
| eg_system | EventGroup | ISR/任务 → Safety/Match | START/STOP/FAULT/READY/ESTOP |
| sem_control_tick | 通知 / 计数信号量 | TIMx ISR → ControlTask | ISR 只发节拍，不做浮点与总线访问 |

### 8.3 比赛状态机

状态机按重构蓝图流程编排，主线为：

```text
IDLE → 读码 → 显示任务码 → 原料区第一批抓取 → 粗加工区放置
     → 暂存区放置 → 返回原料区 → 第二批抓取 → 粗加工区放置
     → 暂存区码垛(颜色一致) → 回启停区 → 显示完成统计
```

每个状态均支持 `start / poll / cancel / timeout / result` 语义，等待一律使用非阻塞超时，不阻塞高优先级控制链路。

## 9. 安全与故障处理设计

### 9.1 安全优先级

```text
急停 > 故障锁存 > 超时恢复 > 正常动作
```

- 所有运动命令必须能被 SAFE_STOP 取消；
- 上电自检后必须等待 START 按键，断电重启后不得自动运动（`start_consumed` 锁存）；
- 急停 ISR 只置事件位，实际停机在任务上下文完成；
- 进入 SAFE_STOP 顺序：清除运动目标 → 底盘 / 执行器发送停止 → 禁止新危险动作 → 上屏 + 日志 → 等待人工确认复位。

### 9.2 故障码（节选）

| 故障码 | 含义 | 可自动恢复 |
|---|---|---|
| CAN_TX_TIMEOUT | 总线发送超时 | 是 |
| MOTOR_OFFLINE | 电机心跳超时 | 是（重连后） |
| MOTOR_OVER_TEMP / OVER_CURRENT | 过热 / 过流 | 否（须人工复位） |
| SERVO_SAFE_STOP | 舵机安全停锁存 | 否（须人工复位） |
| TASK_PARSE_ERROR | QR 帧非法 | 是 |
| WATCHDOG_NOT_READY | 喂狗前置条件未满足 | 受控复位 |

### 9.3 看门狗与故障快照

- 独立看门狗由空闲钩子按前置条件喂狗，异常时记录最后安全快照后受控复位前先尝试停机；
- `configASSERT`、栈溢出钩子、Malloc 失败钩子均接入故障显示；
- 故障码与关键快照通过 UART4 日志输出，便于赛后复现。

### 10.3 复用与重写

**复用（与规则无关的算法 / 驱动经验）**：

- PID 实现与参数整定经验；
- Mahony 姿态解算与 HWT101 协议解析；
- 底盘运动学 `wheel_solution()`、脉冲换算；
- 达妙 / 张大头 / 舵机 / 串口屏底层驱动；
- 转盘抓取颜色识别思路（3 色扩展为 6 色）。

**重写（规则绑定）**：

- 任务码解析（条码 → 二维码 4 组三位数）；
- 主状态机（地面抓取 → 粗加工区 ↔ 暂存区二次搬运）；
- 导航 + 黑色障碍物避障；
- 圆环放置定位 PID 与 6 色识别；
- 码垛逻辑（新增颜色一致校验）；
- 显示装置驱动（任务码 + 完成统计）。

### 10.4 关键改进点

1. **架构升级**：由往年裸机阻塞式状态机升级为 FreeRTOS 分层消息驱动，消除 `HAL_Delay` 阻塞；
2. **单主控收敛**：不依赖上位机分算（国赛 F407 + RK3588），H723 单主控完成全部电控任务；
3. **通信可靠性**：UART 全部 DMA + IDLE 环形接收，CAN 双总线分组，统一发送队列；
4. **安全机制**：新增急停锁存、上电不运动、故障码、看门狗、舵机安全停；
5. **参数集中**：速度 / PID / 坐标 / 颜色映射进参数表，禁止硬编码进状态机分支。
