# V253 PRELIM：转向在±3°内连续100ms再行驶

按现场要求，将V251的“进入±3°就衔接行驶”改为连续保持100ms才放行，类似按键消抖。直行航向超差停机门限继续使用V252的12°。

## 判定

1. 首次检测到绝对航向误差≤3°时开始计时，暂不启动下一段行驶。
2. 后续持续在±3°内，满100ms并取得原有四轮完整、新鲜里程基准后，衔接直行或原路线的圆弧入口；99ms时仍不放行。
3. 期间任何一次检测到误差>3°，计时清零。重新进入容差带后必须重新连续等待100ms，不能累加多次短暂进入的时间。

等待采用非阻塞时间戳，原转向PID继续控制，不新增接近目标时的提前减速。导航段内转向与固定路线 `TURN → NAV` 均覆盖；原PID提前结束也不能绕过这100ms。新动作或取消时清除旧计时，避免带入上一段状态；初始已对向的行驶入口也要完成本次资格判定。若静止等待姿态漂出容差，重新交给原转向对准逻辑，固定路线原超时不变。

保留手动精确转向、工位最终朝向的原规则。速度、加速度、PID参数、直行纠偏输出和既有轮速渐变不改；没有新增角速度归零或轮速归零门限。IMU、里程反馈及原超时检查保持。

日志可搜索 `within3deg100ms`，表示已通过连续100ms判定，不表示第一次经过3°就开始行驶。历史行为见[V251](2026-11-02_初赛视觉方位基准与3度转向衔接_V251.md)，12°门限见[V252](2026-11-02_初赛直行航向门限12度_V252.md)。
