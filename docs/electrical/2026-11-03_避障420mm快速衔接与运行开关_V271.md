# V271 PRELIM / PC2.6.14：避障末端快速衔接与运行开关

只更新初赛`codex/arm-control-panel`。决赛保留V245。按用户要求暂不推送；未烧录或运行实车。桌面“视觉上位机”入口指向初赛源码，重开后加载PC2.6.14；主控需配套烧录V271，相机桥无需更新。

## 避障末端不再慢爬

最新完整一轮run001中，P02附近和P09附近接近400mm时速度降到约1.5RPM，最后十几毫米耗时明显；真正停稳、落图重规划仅约0.15～0.17秒。修改如下：

- 800mm开始的相关障碍距离比例减速保持，普通运行速度、加减速参数保持。
- 临近停车线的轮速下限由1.5RPM改为15RPM，约64mm/s；使用`min(当前运动请求, 避障限速)`，不强行加速原本更慢的动作。
- 在估计车头净距不大于420mm时立即进入原有快速停车流程，给目标约400mm的停点留20mm余量。串口新观测和已有目标的编码器接近采用同一门限，不再慢爬等到400mm。
- 保留既有四轮新反馈和连续100ms停稳确认，再按已选吸附候选落图、立即重规划，继续原目标。两障碍上限、邻格合并、背景自动截图、NO_PATH人工处理保持。

420mm是停车指令触发距离，不是保证实测停点恰为400mm；最终停点取决于距离估计、驱动器和地面，实车可从`VOBS COMMIT/MAP`以及截图核对。没有新增MATCH故障条件。

## 上位机开关操作

在“底盘参数”页顶部新增“运行功能开关”。

1. 接入主控串口，小车处于空闲，或准备完成但未发车。
2. 点“读取开关”，上位机查询主控版本与实际开关状态。
3. 分别勾选“启用圆弧转弯”和“启用视觉避障”，点“应用两个开关”。主控确认后更新实际状态文字。
4. 按正常准备/发车流程运行。准备、复位、跑完一轮均保留本次上电的开关选择。

勾选本身不会发送指令。运行或避障暂停过程中修改会被拒绝，两个开关都保持原值，不发送停车或启动运动。开关存放RAM，断电后默认都开启；“保存当前RAM到W25”只保存原底盘数值，不包含这两个开关。

关闭圆弧后，后续弯道采用原有停车转向流程；不改变原地转向PID。关闭视觉避障后，主控不再根据CAM2观测减速、停车或新增障碍，已有临时障碍和观测会清除，场地固定禁行区不变。电脑仍可显示圆柱识别画面；上位机有关闭状态提示。重新开启后在下一次正常准备/发车时接入新的观测会话。

原`vobs on/off`是临时会话接入/退出，不等于本次新增的持久于准备流程的功能选择。功能关闭时`vobs on`会提示先启用功能。

## 串口指令

```text
navswitch status      # 读取实际状态
navswitch set 1 1     # 圆弧开、避障开
navswitch set 0 1     # 圆弧关、避障开
navswitch set 1 0     # 圆弧开、避障关
navswitch set 0 0     # 两项都关
```

控制台可带`&`前缀；不要发送示例中的`#`注释。主控回报`[NAV SWITCH] v=1 firmware=271 variant=PRELIM arc=... avoid=... armed=... trigger_mm=420 min_rpm=15 source=RAM`。`VOBS STATE`同时包含`enabled/arc`，便于查实际运行选择。
