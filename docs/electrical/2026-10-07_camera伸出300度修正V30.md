# V30：camera伸缩目标恢复为-300度

camera的6号目标改为相对最内零点的-300度。其余采用上一版实测角度：

| 姿态 | 5号 | 6号 | DM |
| --- | --- | --- | --- |
| camera | -0.6647° | -300.0000° | -0.0162° |
| start | -0.7526° | -186.8170° | +134.6173° |

`&arm camera`与出库后自动展开都使用新的camera目标。`&arm camera defaults`也恢复这组值。`&arm start`和`&prepare 1|2`仍使用上述start。等准备READY后发`&OK`才出库。

这是从最内零点算的绝对目标；从start的-186.817度切换到camera时，实际再伸出约113.183度，到达-300度。重复发送camera不会每次额外伸出300度。

5号30RPM、6号80RPM，沿用当前零点，不写DM零点或W25。手动临时设置指令为：

```
&arm camera set -0.6647 -300 -0.0162
```

启动标记CAMERA_DEPLOY_V30。构建、原有长行程回归及实测start到camera方向/到位验证通过后提供固件；仅编译和模拟，未实车烧录。
