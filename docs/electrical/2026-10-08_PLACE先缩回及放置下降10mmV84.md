# PLACE先缩回及放置下降10mm V84

## 本版调整

根据用户确认，所有载物盘PLACE改为先缩回6号再转DM；按此前“所有PLACE”的范围，载物盘及三个圆环的最终松爪位置统一比V83下降10mm。抓取点、等待位、圆环取回原示教高度不变。

正常第一轮仍是：圆盘抓三颗红色装槽1/2/3 → OK → 三个圆环全部放下，再全部取回同号槽 → OK → 3号点TEMP三个圆环全部放下、不取回 → OK结束第一轮。

## PLACE顺序

适用于独立`arm place`、圆盘取料后放载物盘、圆环取回后放载物盘，槽位1/2/3共用：

1. 确认夹爪闭合；先升到TOP，若已在TOP则保持、不重复上升。
2. DM使能保持当前实际角度，6号以正常60RPM缩回到−4°。
3. 等6号实际到位，执行STOP并确认之后的新静止反馈。
4. DM再以原90°/秒转到载物盘角度+162.825°。
5. 等DM实际到位，再下降到新的PLACE终点、张开225°。

日志应看到：

```text
[ARM PLACE] ... TOP -> reach retract/hold FIRST -> DM turn -> lower/open
[ARM PLACE] retract reach FIRST; DM holds source angle until actual STOP/hold
[ARM PLACE] reach actual STOP/hold confirmed; NOW rotate DM to tray; lift/grip wait
```

即使6号一开始就在−4°附近，也要确认新的停止保持反馈，再转DM，不能用缓存帧跳过。STOP/失能取消待转向目标，之后收到位置帧不会重新启动。

PICK仍按原并行动作；圆环放置沿用原TOP→DM→6号→下降松爪顺序。本版不改变6号方向、脉冲/圈或最终伸缩角度。

## 堵转恢复及串口说明

保留V83总共3次位置尝试：正常60RPM，第2次不超过30RPM，第3次不超过15RPM，重复发送相同ABS目标。串行PLACE在整个缩回/重试期间都保持DM源角度；6号停止到位后才转向。三次失败仍停机、不自动张开夹爪。

用户补充曾有串口线被勾掉后插回。若是电脑调试串口，这能解释部分回显缺失；已有0x85记录仍表明6号驱动器曾报告堵转，不能仅凭后来的0x83把原任务视为成功。若被拉扯的实际是相机、供电或电机线，则需按现场对应线路核对。本版未把断线假设当成已确认的物理根因。

## 使用

启动应显示`CAMERA_DEPLOY_V84`。本版沿用现有CAM1统一程序，不需要上传新相机程序，不自动重设零点，也不增加W25机械臂保存。

新试跑前取走夹爪和载物盘残留物料，恢复正确初始参考位置：

```text
&match reset
&prepare 1
```

2号位改为`&prepare 2`。等待READY后发`&OK`出库。QR、圆盘、ROUGH、TEMP各站都在`WAIT_OK`之后发新的OK；站内动作自动执行。

如失败，保留完整`REACH RETRY phase=...`、`last_failure/at_fault`日志，再查询：

```text
&arm query 6
&arm status
&arm round1 status
&arm camera status
&match status
```
