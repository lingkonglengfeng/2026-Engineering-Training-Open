# PC2.6.24 补光自动分档（CAM1桥1.3.5：物料25%/圆盘70%/圆环30%）

## 版本
- CAM1电脑视觉桥接：**1.3.5**（自动亮度分档调整）。
- 上位机：**PC2.6.24**（显示新的自动档位说明）。
- 主控固件、W25、地图偏移、CAM2桥接均无需更改。

## 改动
CAM1相机桥的自动补光（未设手动值时）由原来的“物料/圆盘50%、圆环100%”改为按识别模式分档：

| 识别模式 | 模式号 | 自动占空比 |
| --- | ---: | ---: |
| 物料识别 | 2 | **25%** |
| 圆盘切点/圆盘纠偏 | 8 | **70%** |
| 圆环（空环/带料环） | 3 | **30%** |
| 其他（原始画面、模式9泊车等） | 其他 | 100% |

- 启动仍是100%，收到第一次模式SET后按上表输出；退出时停止PWM并把GPIO拉低。
- 9004端口的手动亮度、`{"light":"auto"}`恢复自动、`{"status":true}`回显、hello/发现报文的`light_port`与1.3.4相同；手动值依旧只存相机RAM。
- 上位机滑条和“应用亮度/自动”按钮逻辑不变，只是“自动”的默认档位值和状态文字改为新分档；`config.json`的`fill_light`（null=自动）兼容旧配置。

## 操作
1. CAM1安装 `vision/maixcam_bridge/dist/maix-cam1_pc_bridge-v1.3.5.zip`，运行“工训CAM1电脑视觉桥接”。
2. 电脑重开 `视觉上位机.cmd`（PC2.6.24）；不手动设亮度时，各识别模式按上表自动切换。
3. 如需临时覆盖，仍可在“CAM1补光亮度”里设0～100%并点“应用亮度”；点“自动”回到分档默认。
4. 不需要重烧主控，不修改W25和相机标定；旧1.3.4/1.3.3包保留回退（回退后为旧的50%/100%分档）。

## 验证
- `tools/tests/test_camera_fill_light.py`：11项通过（覆盖模式8→70%、模式2→25%、模式3→30%、模式9/0→100%、手动覆盖与恢复自动、9004命令、CAM2无补光）。
- `tools/tests/test_light_control.py`、`tools/tests/test_pc_vision.py`：上位机补光客户端/GUI回归通过（PC2.6.24文字与自动恢复）。
