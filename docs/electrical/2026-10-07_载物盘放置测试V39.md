# 载物盘放置测试 V39

新增测试指令 `&arm place`，不自动插入比赛流程。需要底盘静止、比赛流程停止、机械臂无其他动作。

执行条件：夹爪已使能、无故障、PWM斜坡结束，当前PWM与记录的闭合位置一致。默认闭合130°。没有夹爪实际位置/夹持反馈，不能确认是否夹住物料。

操作顺序：
1. 确认闭合状态，保持夹持。
2. 5号先升TOP，再将DM转到+180.7459°。
3. 5号下降到−495.9943°与6号到−212°同时启动，分别检查到位。5号60RPM、6号80RPM。
4. 两轴都确认完成后张开夹爪60°，等待PWM斜坡完成且至少500ms，打印 `[ARM PLACE] DONE`。

结束保持下降姿态，不自动抬升。5/6同时启动并不代表同时到达。

```text
&arm place
&arm place status
&arm status
&arm stop
```

若夹爪尚未闭合，可以通过 `&arm grip test 130` 手动闭合，等 `&arm grip status` 的ramping=0后再发place。若手上没有物料，仍会执行放置测试；系统没有夹持检测。

`&arm pick` 仍采用先伸缩、后下降、最后闭合130°的顺序；start/camera姿态不变。载物盘舵机1/2/3号位置120/210/300°也不变，place不转动载物盘舵机。上电默认张开60°。

保留反馈超时、电机保护、以及下降超过100mm时DM±20°限制。放置姿态不修改零点。

软件测试包含：未闭合/未停稳拒绝、并行启动、升降未完成不张开、原抓取流程及start配置保留。编译0错误0警告。未烧录、未实机验证。
