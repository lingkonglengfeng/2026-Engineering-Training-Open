# 新6号Emm默认脉冲换算 V77

## 为什么5号不下降

用户回显6号等待目标−185.158°，实际先到−255.355°，下一次从外侧重试仍往−284.464°移动。姿态程序因此报告native reach overshoot / wrong direction，在6号实际到位前保持5号高位，不进入等待高度的下降动作。

用户补充新驱动为V2.0。厂家《ZDT_X42S第二代闭环步进电机用户手册V1.0.5_260527》第57页说明Emm位置模式：默认1.8°电机、16细分为3200脉冲/圈；00/01/02分别相对上一目标/绝对坐标零点/相对实时位置。第58页的V2.0.0新增F1/FC快速位置模式沿用该脉冲解释。因此不是只凭V2.0就改协议格式。

旧工程6400脉冲/圈来自旧电机当时“命令300°只转150°”的实测补偿，不能直接沿用新电机。若新机按手册出厂1.8°/16细分，6400换算将目标距离算成两倍：−185.158°算3292脉冲，电机内部实际目标约−370.35°，能解释超过−255°仍向外走。

## 本版配置与假设

V77按 **Emm固件、1.8°步距角、16细分** 的出厂配置，将6号原生位置换算恢复3200脉冲/圈。等待位−185.158°约1646脉冲，CAMERA−300°约2667脉冲，物料抓取伸出25mm对应终点约−287.4755°、约2555脉冲。底层发送时按dir=1反转脉冲方向，目标打印的脉冲是反转前的逻辑值。

此配置假设仍需实机确认。V2.0这个版本号本身不能证明当前是Emm还是X固件，也不能证明实际细分/步距角；若电机是X模式或已修改细分，必须按实际模式和参数调整。本版没有声称通用于所有V2.0驱动。

新6号运动方向继续dir=1；原始反馈角度符号保持，不改零点、行程或驱动器Flash。保留原生位置模式及反馈到位检查，不更换为纯编码器速度定位，也不放宽过冲/方向/堵转保护。

## 相机ACK顺序

原第一遍在等待位移动中因camera ACK timeout取消。V77先张爪准备并请求CAM1 MATERIAL模式，确认新ACK/session后才启动三轴等待位定位；ACK缺失/拒绝时不再让5号先升高、6号先走半段。定位完成且张爪就绪后仍清旧观测，再接受新红色入窗。

相机实际ACK故障仍会报告并退出，不通过忽略ACK继续抓取。相机在线、会话及旧帧/重复帧限制继续生效。

## 测试指令

烧录V77，上电回显应有 `Emm3200steps/rev`。确认在已建立的零点参考附近后，先用一轮测试：

```text
&arm material loop limit 1
&arm material loop start
```

应先出现 `CAM1 ACK/session confirmed; NOW move wait pose`；6号等待目标goal_pulses约1646，原日志3292不应再出现。6号实际到位保持后5号才下降到等待高度，显示WAIT_RED。后续25mm伸出、闭爪、直升TOP、DM/6号并行放置保持。

```text
&arm material loop status
&arm material loop stop
&arm query 6
&arm status
```

## 验证

真实C驱动回归各变体通过，新方向/新物理3200脉冲模型629项覆盖等待目标1646脉冲、从日志−284°起点向内回目标及未改反馈符号。姿态533项、物料3300项、跨任务91项通过；新增相机ACK缺失/拒绝不启动等待位三轴、ACK成功后只启动一次、运动中会话丢失退出。3200脉冲分辨率量化在仿真端按实际每脉冲20.48编码器计数处理，控制到位容差没有放宽。
