## 零点

上电后把5号放在最高位置附近、6号放在最内位置附近；DM摆在你认定的旋转零点。每条零点命令执行完成，再执行下一条。

| 指令 | 作用和完成回显 |
| --- | --- |
| `&arm zero 5` | 记录当前升降位置为顶部和工作零点；等待UPPER RECORDED |
| `&arm zero 6` | 记录当前伸缩位置为工作零点；等待WORK ZERO RECORDED |
| `&arm zero dm` | 自动查询失能与静止状态，发送一次内部FE零点保存并验证；等待ZERO SAVE OK，保持失能 |
| `&dm zero save` | 与arm zero dm相同的内部零点操作 |
| `&dm off` | 确认DM失能，便于手动摆到准确零位 |

初次校准DM：先dm off，手动摆好，再arm zero dm。查询应接近0度。等待保存成功后，让电机保持同一物理位置，给电机电源断电再上电，先查询角度；确认接近0度后再home。若保存后当次接近0但断电后角度明显改变，保留保存前、保存成功和断电后查询回显，这涉及实际驱动器保存/启动角度，不应反复用home代替保存。零点附近的上电摆放本身不会主动写零点。

5/6零点是RAM参考，主控重启后需重新记录；DM采用电机内部零点。没有机械臂W25读写。重新记录5/6零点后，start相对角度目标自动绑定新参考，无需另发start defaults。

## 角度与独立控制

| 指令 | 作用 |
| --- | --- |
| `&arm query 5` / `&arm query 6` | 当前相对角度、编码器原始计数、零点计数、反馈年龄及状态；取最近实际回包，并请求刷新 |
| `&arm query dm` / `&dm query` | 主动读取新DM角度，显示raw和arm角度、年龄、使能和状态码 |
| `&arm enable 5` / `&arm disable 5` | 独立使能/失能5号 |
| `&arm enable 6` / `&arm disable 6` | 独立使能/失能6号 |
| `&arm enable dm` / `&arm disable dm` | 独立使能/失能DM；dm on/off同样可用 |
| `&dm home` | 使能并回内部0度，到位后保持；用query核对到位 |
| `&arm status` | 三轴反馈与故障详细诊断 |
| `&arm stop` | 中止机械臂整体动作 |

零点5/6查询如果当前反馈缺失，会请求刷新并明确提示等待/重试；不会把旧值当成新测量。组合姿态动作中单独失能某轴，会取消组合动作、停止其他轴运动并保留其他健康轴的保持力矩，再失能指定轴。必要的真实故障/高度保护仍可触发停止。

显式DM enable/home能用新的失能正常回包和新的使能回包恢复历史软件超时状态；新回包有硬件故障时仍拒绝，不在此路径自动发送硬件清错FB。真实保护需检查后使用dm clear。

## 两个姿态

非比赛运行时，可直接切换start/camera；正在执行另一个手动姿态时，新姿态命令会取消旧动作再切换。相同动作重发不重启动作。

| 指令 | 作用 |
| --- | --- |
| `&arm start` | 回发车姿态，等ARM START READY |
| `&arm camera` | 回摄像头姿态，等ARM CAMERA READY |
| `&arm start status` / `&arm camera status` | 显示目标和阶段 |
| `&arm start set -43.37 -279.44 0` | 设置start：5号角度、6号角度、DM角度；只设置目标 |
| `&arm camera set 0 -300 0` | 设置camera：同一参数顺序；只设置目标 |
| `&arm start defaults` / `&arm camera defaults` | 恢复默认目标 |
| `&arm start save` | 静止时记录当前三轴为临时start目标；仍仅RAM |

默认start为5=-43.37度、6=-279.44度、DM=0度；camera为5=0度、6=-300度、DM=0度。设置与临时记录均在RAM，重启恢复默认；不写W25。5号30RPM，6号80RPM。三轴目标按当前零点解释，先升到TOP，再处理DM和伸缩，最后移动到设定的升降高度。camera可设置非零升降/DM目标，但下降超过100mm时DM最终角度必须在允许扇区内。

## 发车

摆好车后只需一条：

```
&prepare 1
```

或：

```
&prepare 2
```

区域1=右下角、区域2=右上角，沿用当前已验证车头/地图绑定。该命令重置比赛流程、绑定摆放区域和航向、保持底盘停止，等待IMU约3秒完成，再自动恢复机械臂start。会显示WAIT_START_OK和launch pose READY，此时发送新的：

```
&OK
```

收到之后才使能底盘并出库。提前发送OK不会缓存成自动发车许可。出库完成后，机械臂camera展开与驶向QR并行，到QR需要识别时等待机械臂展开完成。路线、里程计、速度、点位视觉和CAM2暂时屏蔽设置沿用当前版本。

## 容差、诊断与验证

顶部参考允许10mm误差，在容差内按TOP处理；超过100mm下降仍限制DM扇区。指令缺少真实反馈、驱动器堵转/保护、通信持续丢失、明显反向运动仍中止，不伪造READY。反向运动检测保留，本次日志首次native reach wrong direction的物理原因不能仅凭没有实际计数的那一行确定。
