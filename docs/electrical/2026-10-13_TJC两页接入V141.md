# V141：TJC page0显示与page1障碍配置

依据用户提供的两份page0/page1文档接入。屏幕型号TJC3224T128_011R。USART3/PB10 TX、PB11 RX，与屏交叉连接并共地，统一9600、8N1。采用page1文档所述屏幕当前波特率；USART1/2相机、UART4控制台、USART10 IMU参数不变，CubeMX IOC也同步9600。

## 操作

1. 烧录 `Engineering_Training_Project_V141.hex`。屏幕保持9600，若此前改成115200，需在屏幕工程恢复9600。不要用 `FF FF FF` 替代page1的换行。
2. page0的Name和类型按原文档保持：文本 `tCode1/tCode2/tState`，数字 `nPick/nPlace`。扫码确认后任务码分两行显示，例如 `156+123` 与 `516+231`；字体使用英文状态文字。
3. page1点好障碍后点击发送。它发 `&clear&obs x y...\n`；收到完整、有效的一批后才提交地图。赛前IDLE或起手姿态READY、尚未发送首个OK时可修改；行驶、转向、机械臂任务或比赛正在执行时拒绝，不排到稍后偷偷执行。
4. 已应用时控制台打印 `[SCREEN] obstacle batch applied, old plan invalidated`。可停车赛前用原 `&grid` 查看配置，再按原 `&prepare 1`、READY后新 `&ok` 启动。屏上的“清空”仅清屏幕，按原协议还须发送空的 `&clear\n` 才清MCU运行期障碍。

屏幕页切换不会被主控强制打断。每秒发送一次 `sendme` 查询页号，识别标准 `66 PAGE FF FF FF` 返回；只有确认当前page0才发局部控件更新。返回page0后刷新缓存，数据变化时刷新，每两秒也重新同步全部五字段，覆盖短暂切页/控件初始化。可在屏幕page0/page1前初始化事件额外写 `sendme` 加快刷新；没有添加也会主动查询。

本次未修改或上传屏幕HMI工程。控件Name、类型、页号和波特率应与以上约定一致；尚未接实屏验证。

## 显示含义

状态为WAIT QR、SCAN OK、RUNNING、DONE、ERROR，对应比赛流程与已确认扫码。任务码使用原规则字符串，保留颜色5/6的正确显示语义，不显示转过映射的工程编号。新扫码/比赛重置清任务码，故障或停止保留已读码；计数由ARM任务在比赛重置/准备新轮时复位。

抓取/放置次数是**软件确认完成次数**：转盘物料下降/伸缩及闭爪确认且开始提升记一次抓取；载物盘/圆环抓放在成功动作结果锁存时记一次。启动舵机、半途失败、等待状态和重复读取结果不增加。载物盘与圆环之间的往返都计入，普通完整两轮约24次抓取、24次放置；没有物体传感器，不能把它当成实物正确率。夹爪上电打开和载物盘默认2号位不计数。

## 障碍数据

- 单批最多19个点、消息缓冲384字节；必须以 `&clear` 开头，再跟连续 `&obs x y`，最后LF，兼容末尾CRLF。
- 所有点明确是毫米格心：25～2375，数值模50为25。调用现有毫米转换，所以 `(25,25)` 正确映射到格 `(0,47)`，不走旧命令的小数值格号推断。
- 全批格式、范围、数量验证后，再由底盘唯一任务一次清运行期障碍、设全部点、重建地图一次、作废旧规划；静态黄色禁区和台面保留。
- 修复原示例 `p=end+1` 后再寻找下一 `&` 导致隔条漏命令的问题。不是每收到一条obs就立即清图或修改。
- 截断、超时、过长、未知命令、UART错误和接收溢出拒绝对应批次，保持旧地图。仅支持上述原ASCII协议，没有额外增加屏端校验码。

## 实现与验证

新screenTask低优先级、1536字节任务栈，10ms服务；UART3发送使用IT，整条正文和三个FF一次排入固定缓冲，不在ISR或运动回调中阻塞发屏。RX ISR只入512字节固定环形队列，解析和页面刷新在任务里；接收/发送错误有界恢复。没有动态String或动态消息缓存。

1455项屏幕运行端检查通过：页面0/1、离页缓存/返回刷新、TX缓冲生命周期、UART超时和FFF重同步、RX溢出、解析完成但发布前再溢出的并发情形、错误恢复。综合路径/扫码/新协议及地图任务所有权120397断言通过；START/PLACE2520、物料4854、两轮6790、机械臂驱动7组及自动展开143检查通过。

相机/IMU传输868断言通过，包括新UART3回调分派和原UART1/2/10回归。

Keil0错误、0警告；Code272282、RO52094、RW6412、ZI309172 bytes。检查是Cortex-M离线模拟和编译，不代表已测实机时序或屏幕响应。未烧录/未安装屏幕。

保持V140载物盘上电2号295°、固定QR(2125,1150)到点转向、CAM2 1.0.3、既有圆弧和机械臂600ms阈值。包内回退V140。

官方波特率/解析设置参考：[淘晶驰资料中心](https://wiki.tjc1688.com/QA/baudrate.html)。字段和双向消息格式以用户原始文档为依据。
