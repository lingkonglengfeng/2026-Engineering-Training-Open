# 带料柔和旋转与并行缩回 V69

针对用户反馈DM突然转向将物料甩出，在V68基础上增加带料转向的软件速度斜坡。保留DM旋转与6号缩回同时启动，等两者实际到位并保持后再下降放置。

## 转向参数

原姿态动作直接发送最终角度、90°/秒速度上限。现在当夹爪PWM已在闭合预设305°时，姿态动作转向使用：

- 起始速度上限5°/秒；
- 最高速度上限30°/秒；
- 速度上限变化斜率20°/秒²；
- 依据实际角度距目标的剩余距离降低速度上限，接近目标减速到5°/秒。

仍使用DM原来的位置速度模式，发送同一个最终角度并平滑更新速度上限。不是写DM固件参数，也不是修改零点。这里的斜率约束主控下发速度上限，不代表实测电机加速度严格等于20°/秒²；物料保持还需实机验证。

主控按50ms以上间隔更新速度，单次计算时间跨度最多100ms，串口/任务延迟不会使下一次速度上限骤然跨越。每次更新沿用位置范围、反馈、使能及高度检查，失败会取消动作。DM转向等待期限增加到20秒，兼容较慢的带料转向，仍按真实角度及速度确认到位。

夹爪张开时保留原空载转向速度。带料START/通用转移/PICK后PLACE/圆环放置等由姿态状态机发起的转向都会应用柔和参数；本次不改变独立手动dm pos、arm rotate或CAMERA自己的转向实现。

## 并行放置

抓取确认后直接升到TOP → 同时启动DM向载物盘转向、6号缩回至PLACE目标−4° → 6号先到会保持等待DM → 两轴实际到位稳定 → 5号下降到PLACE高度 → 张爪225°。

“同时”指并行启动和共同到位门槛，不强求两台不同电机在完全相同的时刻结束。DM降速后通常是6号先到并保持，不再额外串行等待才开始缩回。圆环原有顺序保持。

5号升降120RPM、抓取后直升TOP、6号伸出50mm、视觉窗口(0,−20,20,20)、1号载物盘205°和各目标角度均保持V68。

## 指令

烧录V69，小车静止后先测一轮：

```text
&arm material loop limit 1
&arm material loop start
```

开始带料转向会打印：`[ARM DM] loaded SOFT turn: max30deg/s accel20deg/s2, brake near target; reach retract runs concurrently`。同时仍应出现PLACE的DM和reach并行回显。

```text
&arm material loop status
&arm material loop stop
```

连续模式在停止状态设置 `&arm material loop limit 0` 后start；每轮仍需取走1号槽物料。相机程序/协议无需改动。

## 软件验证

生产姿态FSM565项通过，新增按100ms模拟的正反向约165°带料转向，检查速度上限不超过30°/秒、每步速度变化不超过2°/秒、目标前减速、并行伸缩、实际到位后才下降，以及速度更新失败停止动作。物料FSM2944项、跨任务91项、机械臂驱动各变体通过；明确速度接口的映射和非法值拒绝均验证。
