# V250 PRELIM / PC2.6.8：底盘参数、参考值与W25保存

仅更新初赛 `codex/arm-control-panel`，决赛仍V245/PC2.6.7。原机械臂、DM零点、舵机预置及取料顺序保持；V249松爪50ms和圆弧修复继续使用。

## 操作

1. 烧录初赛V250，关闭旧上位机后，从 `比赛版本/初赛/启动初赛上位机.cmd` 打开PC2.6.8。原根目录仍属决赛，未同步本页。
2. 接入串口，车辆/机械臂空闲时打开“底盘参数”，点击“读取当前值”。页面分别显示主控当前值、输入值、单位和固定参考值。
3. 修改输入，点“应用此项”或“全部应用到RAM”；收到成功回执后自动读回，确认数值。
4. 点击“保存当前RAM到W25”，看到 `[MOTION SAVE] OK` 才算保存成功。未应用的输入值不保存。
5. 下次上电自动读取初赛专用参数；“从W25读回”覆盖RAM未保存修改。“参考值填入输入框”只填界面，不发送或保存。

页面不会因启动、连接或填参考值自动下发参数。读取时先查询arm ui核对固件；旧固件会提示需V250。运行中不接受本页读写，返回REJECTED，不触发新增停机。

## 数值与指令

所有指令可直接在串口框输入；也支持`&motion`前缀。参考值不会随调参改变。

| 项目/key | 固定参考 | 单位 | 单项指令示例 |
| --- | --- | --- | --- |
| 直线速度/spd | 0.650 | 250RPM基准比例 | `motion set spd 0.65` |
| 圆弧目标速度/arc | 306.8352 | mm/s | `motion set arc 306.8352` |
| 轮速加速度/accel | 600 | RPM/s | `motion set accel 600` |
| 普通减速度/decel | 292 | RPM/s | `motion set decel 292` |
| 转向轮速减速度/turn_decel | 900 | RPM/s | `motion set turn_decel 900` |
| 平移目标距离系数/straight | 1.03 | 倍 | `motion set straight 1.03` |
| 场地轮速输出上限/wheel | 500 | RPM | `motion set wheel 500` |
| 圆弧角速度上限/yaw | 300 | °/s | `motion set yaw 300` |
| 旧时间标定/t1000 | 1930 | ms | `motion set t1000 1930` |

读取`motion status`，保存`motion save`，读回`motion load`。整组原子应用：

```text
motion apply 0.65 306.8352 600 292 900 1.03 500 300 1930
```

先校验整组9项再修改，不会只应用前半组。格式错误、非有限值或超出页面/协议范围时拒绝，保留原值。裸串口行容量扩为127字节，支持9项完整小数；蓝牙单项命令仍可使用。

spd0.65约162.5RPM/0.693m/s；600RPM/s约2.56m/s²，292RPM/s约1.24m/s²。距离系数1.03使1000mm目标变为1030mm，不改变编码器单位。圆弧实际速度仍受速度比例0.72、半径165mm、侧向加速度663.552mm/s²等原约束共同限制；提高输入上限不等于立即达到该速度。入弯减速保持。t1000只用于旧时间模式，当前编码器模式不靠它到位。

## 存储与兼容

本套9项使用W25Q64倒数16/15扇区（8MB地址0x7F0000/0x7F1000），CRC、序号、双银行交替写入并回读校验。此区此前未使用，与初赛四姿态14/13、决赛区域、PID和旧导航区分开。

上电先加载旧导航参数，再优先加载有效的新底盘快照。新区域没有有效记录时，spd/t1000继承旧导航值，其余7项沿用原代码默认值；不会自动写Flash。启动时若与机械臂加载争用SPI存储锁，会让出CPU等待锁可用，不把BUSY当成无有效记录。旧共享导航记录的结构/版本保持，不影响旧决赛读取。新记录加载失败不会覆盖当前RAM。

旧`spd`/`t1000`或`outerarc speed`仍可修改同一份RAM，读取本页能看到变化；但完整9项须用本页或`motion save`保存。旧`save/read`仍管理旧NAV/PID，不等价于新的底盘保存。已有专用快照时，启动优先使用专用值。

动态参数已接入真实底盘渐变、里程减速、短距离规划、圆弧速度/角速度、场地混控输出上限及平移/圆弧切线目标距离，非仅显示。保存/读取不启动车辆；本次没有代为写入设备。
