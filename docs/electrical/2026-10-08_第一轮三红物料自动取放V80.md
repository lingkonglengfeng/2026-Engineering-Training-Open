# 第一轮三红物料自动取放 V80

本版把已经测试的单次取料/放置接入现有比赛路线。暂时三颗都识别红色，按载物盘槽位编号对应圆环编号。3号点使用现有 TEMP_BATCH1，不修改路线几何或视觉纠偏参数。

## 试跑指令

沿用已测试的机械臂零点和CAM1统一程序。上电不自动重设DM零点；本版也不恢复W25机械臂姿态保存。载物盘三槽应为空，场地上的目标圆环先清空。`match reset`和新`prepare`会把软件库存重置为空，不能用软件复位代替实际清空。

摆到发车位后：

```text
&match reset
&prepare 1
```

2号发车位改为`&prepare 2`。等待`[MATCH] WAIT_START_OK` / `launch pose READY`，再发送：

```text
&OK
```

自动出库，机械臂CAMERA展开与驶往QR并行。QR阶段沿用当前流程（CAM2仍按现有配置屏蔽）；出现`WAIT_OK QR`后发`&OK`前往圆盘。

之后每站只在任务全部完成、出现`WAIT_OK`后发送一次`&OK`：

| 到达站点 | 站内自动动作 | 完成后的OK |
| --- | --- | --- |
| RAW_BATCH1 圆盘 | 视觉纠偏完成→等待新红色进入窗口→抓一颗到槽1→重新SET/ACK和新观察→抓一颗到槽2→再抓到槽3→恢复CAMERA | 去ROUGH_BATCH1圆环 |
| ROUGH_BATCH1 圆环 | 槽1取出放环1→槽2放环2→槽3放环3；三颗全部放完后，环1取回槽1→环2取回槽2→环3取回槽3→恢复CAMERA | 去3号点TEMP_BATCH1 |
| TEMP_BATCH1 3号点 | 槽1取出放环1→槽2放环2→槽3放环3→恢复CAMERA；不取回 | 标记FINISHED并留在3号点；不进入第二轮，也不自动返程 |

站内不需要发`arm material`、`arm pick`、`arm place`或`arm ring`。无需启用`arm material auto on`；第一轮站点任务默认接入。站内或途中提前发的OK不会保留到下一站。

## 槽位、抓取与高度

- 载物盘实测槽位：1号205°、2号295°、3号25°。使用独立的物料槽位选择接口，旧手动`arm table go`预设不变。
- 圆盘等待位5号−361.5644°，6号−185.1581°，DM−2.0217°。等待位不提高。
- 红色进入窗口后，5号下降到−562.5272°，6号从等待位外伸25mm，同时闭爪305°；实际到位且闭合PWM完成后，直接升TOP，再放进本轮对应槽。
- 红色窗口中心误差(0,−30)，半宽/半高40像素，局部新鲜度150ms，默认1帧确认。每颗物料重新建立相机会话，清除旧观察；不做盲定时抓取。
- 从槽中PICK的5号终点−540.8633°，6号−4°，DM+162.8250°；槽内PLACE最终松爪高度−380.0931°，保留之前提高30mm的设置。
- 圆环松爪高度统一为5号−866.8261°；取回统一用原示教高度−1017.5482°，比当前松爪点低30mm。圆环取回时先张开，TOP定位后下降到原示教点，闭合完成后升TOP，再转载物盘并放回同号槽。
- 环1：6号−532.9303°、DM+40.9044°；环2：6号约−162.9795°、DM+2.6040°；环3：6号−249.5599°、DM−42.5218°。ROUGH与TEMP复用已示教的相对机械臂点位。
- 张开225°、闭合305°；5号120RPM及原加减速处理，6号60RPM原生ABS位置模式，DM90°/秒。PLACE的DM和6号并行，下降前等两者实际到位；已到TOP不重复上升。
- 6号沿用dir1、3200脉冲/圈、总共3次堵转尝试。每次重试发送同一个绝对目标，停止/失能取消重试。通信超时及其他真实保护仍会退出。

## 串口诊断与停止

```text
&match status
&arm round1 status
&arm material status
&arm status
&arm query 5
&arm query 6
&arm query dm
```

`[ROUND1]`输出station、phase、slot、return、tray/rough/temp掩码和held槽号。掩码bit0/1/2分别代表1/2/3号，例如`0x7`代表三个都已完成，`0x0`为空；这些记录基于动作到位和舵机PWM完成，没有物料传感器，不能证明实际抓住。

阶段phase：0空闲，1圆盘取料，2取回后升高，3载物盘选择，4槽内PICK，5圆环放置，6圆环取回，7回槽PLACE，8恢复CAMERA，9站点完成，10失败。只有phase9且MATCH进入WAIT_OK才允许去下一站。

```text
&STOP
```

会停止比赛流程和当前站点机械臂任务。`&arm stop`也会停止机械臂任务，随后比赛报告站点失败。任一机械臂电机/舵机失能先取消当前动作。失败不自动跳站；保留库存记录用于判断，排查后重新摆车/清理物料，再`match reset`、`prepare N`。

独立单次/连续取红物料测试指令仍可在流程停止时使用；旧连续测试仍只放槽1。正常三槽流程不再要求每轮人为清空槽1，请保留三颗物料供后续圆环任务使用。

## 视觉兼容与验证范围

继续使用已交付CAM1统一程序v20，mode2/station1/target1、20Hz；检测仍为原找颜色算法，屏幕窗口显示保持现有配置。运行中修改MCU窗口不会自动同步相机本地显示框。

本版完成真实C状态机模拟、串口/路由/相机会话回归和Keil构建；没有烧录主板、上传相机或进行实机三颗连续搬运。圆环原示教高度与三槽实际取放位置需在首次试跑核对。所有程序包均附构建日志、测试日志和SHA256清单。
