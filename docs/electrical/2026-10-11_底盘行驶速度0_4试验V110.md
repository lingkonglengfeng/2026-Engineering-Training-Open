# 底盘行驶速度0.40试验 V110

默认行驶速度比例由0.35调整为0.40，约提高14.3%。长直道/正常行驶采用新值，原有末段减速、低速接线、视觉纠偏、转向PID和加速度参数保留。

当前板也可以先用串口测试，无需等待烧录：

```text
&spd 0.4
&save
```

`&nav`查看当前速度；正常长直道日志应显示 `vmax=0.400`。若只临时测试，可先仅发spd，不保存。

V110源码默认和navreset默认也改为0.40。W25记录保持原数据布局，保存版本改为v8：兼容读取旧v4/v5/v6/v7；旧v7若速度为原默认0.35，会在RAM中升级到0.40，其他自定义速度/参数保留。新版v8保存的0.35也可正常读回，避免试验恢复值再次被误升级。加载过程不自动擦写Flash。

同版固件恢复原速度可发：

```text
&spd 0.35
&save
```

若之后退回只支持v7的旧固件，需重新设置并保存其导航参数，因为旧版不读取v8记录。

只需烧录 `Engineering_Training_Project_V110.hex`，确认CAMERA_DEPLOY_V110。相机程序无需因本次修改更新。扫码点(2125,1150)、转向选路估值1.7/2.8秒、视觉末端0.8°容差以及圆环松爪提高4mm继续使用。

回归检查包含实际路线/里程计控制，以及旧Flash速度迁移、新版显式0.35回读、自定义值保留。编译0错误、0警告；尚未烧录或实车验证本次速度试验。
