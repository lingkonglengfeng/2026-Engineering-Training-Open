# V244 FINAL / PC2.6.5：准备不定起点，发车时才绑定位置

## 新操作流程

1. 双路视觉和串口接入后，点击统一的 **“准备：只归位与零漂”**（`&prepare`）。底盘保持停止，校准陀螺零漂，再将机械臂恢复发车START姿态。准备时保持车静止。
2. 等待`WAIT_START_OK`。此时还没有确认当前位置是哪个启停区，可以在准备后把车摆到实际要用的区，摆正、放稳。
3. 发车时才选择起点并建立坐标：

| 输入 | 动作 |
| --- | --- |
| PD1短按后松开（不足1000ms） | 确认当前位置为1号启停区并发车 |
| PD1按住至少1000ms再松开 | 确认当前位置为2号启停区并发车 |
| 上位机“1号启停区发车”／`&OK 1` | 1号区发车 |
| 上位机“2号启停区发车”／`&OK 2` | 2号区发车 |
| 裸`&OK` | 默认1号区发车 |

1号区映射为地图右下中心(2250,150)，车头+y；2号区为右上中心(2250,2250)，车头−y。确认是把当时的物理位置/朝向作为该区参考，不会自动检测地面框或挪动车辆找起点。

## 准备与发车的边界

准备会清除位置已确认标志，比赛准备的区号为0（UNBOUND），不调用原选区坐标绑定。旧`prepare 1/2`在新版中仅兼容为统一准备，参数不再提前锁定起点。

机械臂和IMU原就绪条件保持。接受一次新的OK后，重新建立当前航向参考，设置启停区坐标和车头方向，然后进入LEAVING。**发车时不调用零漂重置，不重新等待3秒校准。** 已进入后续工位的OK继续原有含义，不会再次绑定启停区。

按键仍为PD1内部上拉、低电平有效、EXTI1双边沿，任务中30ms消抖；没有恢复GPIO软件轮询。两个手势均在稳定松开后确认，按下时不会先按1号区发车。保持原按下边沿时间判断READY新鲜度：开机按住、准备期间按住、READY之前的旧按键，都不能在松开后变成有效发车。

日志打印SHORT/LONG、按住时长和区号，成功绑定打印`[MATCH] LAUNCH_BIND zone=...`；零漂、CAN、机械臂或航向重绑定未满足原条件时不进入发车。初始化的默认地图位置仍仅是假定值，不代表准备已确认了它。

## 更新与兼容

烧录V244 FINAL，重启上位机到PC2.6.5；启动标记`CAMERA_DEPLOY_V244_FINAL: PREPARE_UNBOUND_LAUNCH_BIND_SHORT1_LONG2`。两路相机桥和W25参数格式/分区不变，不需要重存机械臂参数。

本次更新决赛分支；包内保留的原初赛V237仍使用旧`prepare 1/2 → READY → OK`流程，不支持新版无区号准备。若运行旧固件，可在常用指令框手工输入旧指令；新按钮流程需配套V244。手动调试用的`startpose`等旧入口保留，统一准备会重新清除位置确认。
