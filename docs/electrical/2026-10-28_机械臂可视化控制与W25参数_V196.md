# V196：机械臂可视化控制与 W25 参数

> 本文记录该版本行为。当前 V198 的启动优先级、共用放置参数和纠偏策略见 [V198说明](2026-10-28_W25启动优先与共用放置纠偏_V198.md)。

配套 PC 上位机 **2.5.0**。在“主控串口日志”接入 UART4 调试口后，切换到新增的“机械臂控制”页。两台相机桥保持 CAM1 1.3.0 / CAM2 1.4.0；无需因本功能重新安装相机桥。

### PC 2.5.1 状态解析修复

真实主控的 `ZDT>` 提示符不以换行结束，可能与第一条异步状态回复拼成 `ZDT> [ARM UI BEGIN]`。2.5.0 未识别这类开头，导致日志里有完整数据，面板却一直等待状态。2.5.1 只在内部解析时去掉行首提示符，兼容重复提示符，并保持原始日志；动作链回执使用相同处理。主控仍使用 V196，关闭旧上位机并重新打开即可加载修复。

### PC 2.5.2 单轴使能链路修复

V196 对 5/6 号轴分别维护软件使能请求，驱动器反馈 `enabled=1` 并不表示这个请求已建立。原按钮直接下发 `arm pct 5` / `arm pos 6`，会被 `enable_req=0` 拒绝；DM 未启用、角度反馈过旧时，原前端又在启用前拦住旋转请求。

2.5.2 的单轴发送先调用现有 `arm enable 5|6|dm`，等成功回执后读取新 UI 状态，再验证目标并发送；旋转仍须取得真实角度。低位下降先只读查询 DM，继续遵守现有高度/扇区限制。使能失败、反馈未更新或目标违规时，不发送目标并说明原因。刷新按钮只查询位置和参数，不隐式启用电机；不轮询重发动作、不改速度、零点或固件保护。

动作链使用完整回复行到达时间判断新回执；保留串口原始首字节时间，避免较早收到的无换行提示符导致正常使能回执被误判为旧数据。参数保存和视觉流程沿用原方式。此修复无需重新烧录 V196。

## 三个子页

| 子页 | 功能 |
| --- | --- |
| 三轴与舵机 | 5号升降、6号伸缩、DM 旋转的滑块和数值输入；夹爪与载物盘独立角度；实际反馈与高度限制图 |
| ROUGH / TEMP 三点微调 | 两个工位各三个地面圆环；原目标、已应用目标、当前预览的图形对照；三轴角度增量与毫米位移换算 |
| 一键动作 / 参数保存 | 从载物盘夹取、放回当前槽、CAMERA/发车姿态、独立位置与角度纠偏、夹爪/载物盘预置及 W25 保存读取 |

**升降和伸缩显示的是电机编码器角度**，不是虚构的俯仰关节。主控提供两轴实际行程和有符号编码器跨度，面板换算下降/伸出毫米数；DM 显示旋转关节角度。俯视图半径按伸缩比例绘制，用于相对目标对照，不代表已标定的末端绝对 XYZ。

绿色反馈点只在反馈有效时显示，舵机数字是 PWM 估计，舵机没有实际角度传感器。切断串口后反馈标为未知；重新连接后重新读取主控参数。

## 滑块与旋转限制

1. 点击“读取主控状态 / 六点目标”，确认主控 V196、三轴反馈和标定有效。
2. “用实际角度填充滑块”把有效实测值填入预览。拖动滑块默认不发运动。
3. “发送此轴”发送所选轴的目标；也可勾选“松开滑块发送单轴目标”，在松开时发送一次，不按鼠标拖动帧率灌入命令。
4. 2.5.2 的独立升降/伸缩/旋转按钮会先完成对应轴使能握手；舵机“发送角度”复用已有 `test` 指令，可在请求角度直接使能。三轴整体移动复用原有抬升、旋转/伸缩、下降序列。单轴显示“主控接受”只代表目标已接受，实际到位看反馈。

面板读取**当前主控实际联锁配置**，不重设其参数。默认下降超过 **150 mm** 后只允许 **[-44°, +44°]** 扇区；低位禁转部分标红。直接旋转和直接下降会先检查当前高度/角度及目标；三轴整体移动检查最终目标，由主控沿已有先抬升路径执行。无效目标只拒绝该次面板请求，不下发额外全车停机指令。

原有高度旋转联锁、驱动保护、V195 原生升降和速度参数继续使用；没有新增图像丢失或串口断开造成整车停机的保护。

## 调整 ROUGH / TEMP 三个圆环

1. 选择工位和圆环 1/2/3，“读取所选点已应用微调”把当前 RAM 增量填入滑块。
2. 用三个增量滑块调整升降电机角度、伸缩电机角度与 DM 角度。界面同时显示相对原点的下降毫米、伸出毫米和旋转度数。
3. 点击“应用所选点微调到主控 RAM”：只改参数，不运动。增量相对原有 V195 分工位目标，反复应用同一组数值不会累加漂移。
4. “移动到预览点”执行三轴姿态，保持夹爪；“应用微调并放置此圆环”先等待微调成功回执，再执行放料；“夹取后放置此圆环”还会等待真实夹取完成回执。
5. 确认效果后，在参数页点击“保存主控参数到 W25Q64”。清零增量本身只清预览，需再次应用、保存才改变主控与掉电参数。

六组增量互相独立，也会用于后续自动放料；TEMP 第二轮原有 72 mm 抬高量仍独立叠加。原料台抓取、从地面取回、发车姿态和相机姿态不随圆环放料微调改变。

主控原有“完成 PICK 且夹爪闭合”条件继续适用于放料。载物盘的槽位与地面圆环编号是两类位置；“从载物盘当前槽夹取 / 放回载物盘当前槽”保持当前载物盘角度，请先把实际有料槽对准机械臂。

## 独立 ROUGH / TEMP 位置与角度纠偏

先将小车摆在所选工位附近，确保供电、IMU 和视觉可用，再按对应按钮。面板把相机接入主控联动，按“空圆环 / 带物料圆环”选择识别模式，然后发送一次独立纠偏请求。

主控异步恢复 CAMERA 观察姿态，完成后启动已有 CAM1 确认、XY 纠偏、圆环轴角纠偏、最终复核和里程锚定；完成后输出 `[MANUAL ALIGN] DONE` 并结束。本次不推进 MATCH，也不自动开始抓放。

**TEMP 的角度纠偏只在此独立请求中启用**；比赛自动流程保持原有 ROUGH 角度纠偏、TEMP XY 策略。活动比赛/导航或机械臂任务占用时拒绝独立请求，不抢占原任务。需要取消时点击面板“停止当前动作”，发送现有 `&STOP`。

按钮链依赖主控完成回执，不使用固定延时推断夹取完成。主控失败/拒绝、串口会话改变或等待回执超时会取消尚未发送的后续步骤；不自动重发运动，也不因上位机断线自动发送停机。

## W25Q64 保存内容

- ROUGH 和 TEMP 的三个圆环点各自的升降、伸缩、旋转增量。
- 夹爪张开、闭合预置角度。
- 自动载物盘三个物料槽的角度，默认 205° / 295° / 25°；与旧 `arm table go` 的历史 120° / 210° / 300° 预置分开。

参数页先“应用”预置到主控 RAM，再“保存”。保存读取均等待机械臂和底盘空闲，只更新参数，不改变当前运动目标或电机零点。三轴手动滑块的临时位置不作为上电自动运动目标保存。

参数使用按实际 Flash 容量计算的**倒数第 8、7 个 4 KB 扇区**，与导航/PID 的倒数第 2、1 扇区分开，也避开历史机械臂零点/姿态区域。每条记录包含标识、版本、大小、序号和 CRC32；保存时更新另一份记录并读回校验，失败时保留上一份有效记录。存储事务与导航/PID 访问共享非阻塞互斥，忙时报告失败供稍后重试，不停机。

启动时在导航 Flash 加载完成后加载有效机械臂参数；空白、损坏或不适用的记录保留当前默认参数并打印原因，不产生新故障。**读取函数本身不发 PWM/CAN 运动**；工程原有开机夹爪张开、载物盘转到 2 号槽的初始化动作仍在参数加载前执行，未改成“上电静止”。后续抓放使用加载后的预置。

本功能不恢复已删除的发车姿态 W25 保存，也不把 DM 内部零点迁移到 W25。

## 新指令

普通 ASCII 指令继续由原调试串口解析；一条一行，以下长指令不加 `&` 前缀。

```text
arm ui                              读取一组主控 UI 状态、标定和实际联锁
arm points                          读取两工位六点的基准与已应用增量
arm move <lift> <reach> <dm>          保留 START 配置，按原序列移动三轴
arm trim rough|temp <1..3> <dl> <dr> <dd>
                                    相对原目标的角度增量，RAM 参数，不运动
arm ring rough|temp <1..3>           放料到指定工位圆环，需完成 PICK
arm grip preset <open> <close>       夹爪预置，RAM 参数，不运动
arm table presets <slot1> <slot2> <slot3>
                                    自动物料槽角度，RAM 参数，不运动
arm params status|save|load          状态 / 保存到 W25 / 从 W25 加载
valign run rough|temp                独立 CAMERA + XY + yaw 纠偏
```

`lift/reach/dm`、`dl/dr/dd` 单位均为度，前两项使用现有有符号电机坐标。直接单轴和舵机仍使用原有 `arm pct 5`、`arm pos 6`、`arm rotate`、`arm grip/table test`。

## 验证与部署

部署时更新 V196 主控 HEX、重启 PC 上位机；两台相机桥不变。使用 V195 主控时仍能用原串口文本指令，但新增面板状态、微调保存和独立纠偏需要 V196。
