# 本地V266 PRELIM：圆弧半径148.5mm与避障后逐弯圆弧

默认圆弧半径从165mm缩小10%至148.5mm。直线/圆弧速度配置、加减速、航向PID、直行修正±0.05及800/400mm避障阈值不变；实际弯道速度仍受原曲率、横向加速度、轮速及角速度限制。

## 半径调节

已有串口命令可在空闲状态调整，不触发运动：

```text
&outerarc status
&outerarc radius 148.5
```

范围80～200mm，单位是车体中心路径半径，不是轮距或电机角度。此命令只改RAM，重启恢复固件默认值；不写W25。本版默认148.5mm，桌面上位机PC2.6.10无需更新，可在串口日志页手工发送指令。

## 避障之后为何原来没有圆弧

V265主导航入口存在 `!zdt_vobs_nav_active` 条件，避障路线不尝试圆弧。V266去掉这个整体禁止，改为在同一目标的两段正交路线之间尝试圆角；当前动态障碍图、车体完整扫掠、现有位置/航向偏差检查都通过才执行。

- 绕行路线的端点是检查过的精确毫米坐标，圆弧不再额外套用普通路线的距离补偿，避免改变已检查路线的终点。
- 绕行路线可使用外环和中央等内部正交拐角；几何模块负责生成圆弧，运动拥有者负责当前地图的整车扫掠检查。短腿、非直角、朝向不合或车体检查不通过时仍按原停车转向路线执行，不新增故障停机。
- 普通任务路线仍按原外环适用范围与原距离补偿执行，只改变默认半径；绕行曲线不跨越原工位任务边界，不吞掉下一工位的朝向或动作。
- 倒车退出、短横移重入保持独立；这些临时段不做圆弧。绕行圆弧结束后才消费本目标的两段路线，实际终点与任务完成时机保持原检查。
- 圆弧中的CAM2障碍接入、减速、停车落图重规划以及同障碍关联更新继续保留。

## 关于“已经经过的地方标为确认区域”

可以用占据栅格保存已观测/已通行证据，再对路线进行圆角或其他平滑处理。历史通行只覆盖实际车体经过的区域：两条直线走过，不代表切角弧线内侧额外扫过的区域也经过；新障碍观测也不能被旧通行记录覆盖。

本版复用当前地图与整车扫掠检查恢复圆弧，没有新增历史通行栅格，也不依据历史通行直接跳过检查。相关工程思路可参考 [Nav2障碍层的车体清空与自由空间处理](https://github.com/ros-navigation/navigation2/blob/main/nav2_costmap_2d/plugins/obstacle_layer.cpp) 和 [Nav2约束平滑器](https://docs.nav2.org/rolling/configuration_and_development/configuration_guide/smoother_plugins/constrained_smoother/configuring_constrained_smoother/)，本工程未引入ROS/Nav2依赖。
