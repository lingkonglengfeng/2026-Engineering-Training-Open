# V15：arm start与camera速度统一

用户要求arm start与相机展开速度一致，并将5号设为30RPM。

本版5号默认速度30RPM；arm start和arm camera均使用30RPM上限、三倍距离接近速度、60RPM/s加速斜率。接近目标仍减速和停稳确认，因此短距离动作不会全程固定30RPM；手动arm speed设得更低时仍服从更低的上限。

arm start的6号由普通百分比外部速度控制改为与camera相同的Emm原生速度位置指令，最大80RPM、加速档位150、6400有效脉冲/圈换算。伸出/回缩使用与camera一致的逻辑符号，不把负编码器位移直接当作负电机脉冲。通过新鲜实测编码器数据确认位置及稳定，识别方向错误、较大过冲和超时；通信发送成功不等于到位。

原保存的W25姿态记录格式不变，不需要重新录入；调用仍是`&arm start`，等待READY。记录、查询仍为`&arm start save`、`&arm start status`。原有先升高、再DM/伸缩、最后恢复记录高度的顺序不变。出库后去QR与展开并行、QR识别前等待READY的联动保持。

保持W25软件零点、三轴记录目标和机构保护。改变的是速度路径，未通过工具烧录或运行实车；实际驱动器原生位置模式的目标到位与速度需要实车验证。
