# V234：转向 PID 调参与波形显示

日期：2026-10-30，基于 V233。配套 PC 上位机 **2.5.8（转向PID调参与波形）**。
本版只增加**转向调参/观测手段**，不改底盘转向控制律、目标、速度、判据和比赛流程。

## 1. 当前转向 PID 是多少（90° 与 180° 共用同一组）

`Core/Inc/chassis_motor.h:95-97` 的编译默认值，也是上电后的实际生效值：

| 参数 | 值 | 说明 |
| --- | ---: | --- |
| Kp | **0.045** | `CHASSIS_TURN_KP` |
| Ki | **0.0005** | `CHASSIS_TURN_KI`，仅误差 ≤5° 时累积，积分限幅 ±5 |
| Kd | **0.0035** | `CHASSIS_TURN_KD` |
| 输出限幅 | 1.00 | `CHASSIS_TURN_MAX_OUTPUT` |

**90°、180° 没有各自独立的 kp/kd**：两者都走 `ChassisMotor_TurnRelative()` → 精确档
`chassis_turn_profile_precise`（`Core/Src/chassis_motor.c:67-80`），同一套增益、同一套判据：

| 精确档参数 | 值 |
| --- | ---: |
| 轮速上限 | 90 RPM |
| 主判据 / 连续时间 | ≤0.01°，200 ms（且角速度 ≤2 dps） |
| 稳定带 / 驻留 | ≤0.05°，500 ms（带内且 ≤0.3 dps 时 200 ms 即可收工） |
| 摩擦补偿门槛 / 推力 | 误差 >0.06° 且输出 <0.05 时补 0.05 |
| 无进展兜底 | 0.20° 内 900 ms 压不下去 → 收工（日志标 `ST`） |
| 总超时 | 8000 ms |

导航段前对准用的是另一档 `chassis_turn_profile_fast`（120 RPM、0.5°/200 ms），
**增益仍是同一组** kp/ki/kd。所以“90° 和 180° 的 kp、kd”答案相同：0.045 / 0.0035。

> 后续版本：V235 已把上表“轮速上限”由 **90 RPM 改为 180 RPM（2×，现场要求）**，
> 快速档 120 RPM、PID 增益与全部判据不变；`&tstat` 同时新增 `rpm` 字段供上位机显示。
> V236 起上电会**自动装载 W25 里 `&save` 过的 PID**（本版及以前需手动 `&read`），
> 并新增 `[PID] BOOT source=` 启动日志与参数来源显示。
> 本页其余内容（命令、波形、调参流程）继续有效，详见
> [V235 说明](2026-10-30_转向轮速上限2倍_V235.md) 与
> [V236 说明](2026-10-30_转向PID上电自动装载_V236.md)。

> 注意 Flash 行为：`&save` 只是把当前值写进 W25；**当前版本上电/`&EN` 不会自动装载**，
> 只有 `&read` 才把 Flash 值装回 RAM。所以“改过并保存”之后，重启仍需 `&read`
> （本版上位机“从W25读回(&read)”就是做这件事）。`&pid` 读的是 RAM 当前生效值，
> `&show` 读的是 Flash 里存的值，两者可能不同。

## 2. 新增命令（固件 V234）

| 命令 | 作用 | 回执示例 |
| --- | --- | --- |
| `&pid` | 查询当前生效（RAM）转向 PID | `[PID] kp=0.0450 ki=0.0005 kd=0.0035` |
| `&tstat` | 查询转向/使能/IMU/波形状态 | `[TURN] status enabled=1 active=0 imu=1 trace=0 tgt=+0.00 act=+12.34 err=+0.000 out=+0.000 kp=0.0450 ki=0.0005 kd=0.0035` |
| `&ttrace 1` / `&ttrace 0` | 打开/关闭转向波形（默认关） | `[TURN] trace on period=25ms` / `[TURN] trace off` |
| `&kp0.045` `&ki0.0005` `&kd0.0035` | 分别写 RAM（沿用旧命令，不能带空格） | `[PID] kp updated; …` 并打印当前值 |
| `&save` / `&read` | 存 W25 / 从 W25 读回 RAM | `[PID] saved and verified` / `[PID] loaded from W25Q64` |
| `&L90` `&R90` `&L180` `&R180`（任意 `&L1..&L360`） | 精确档原地转（沿用旧命令） | 起转/结束日志见下 |
| `&en` `&stop` `&zero` | 使能底盘 / 停止 / 重新对航向零（需静止约 3 s） | 沿用原回执 |

波形打开后，转向过程中每 25 ms 打一行（约 40 Hz）：

```text
[TURN] start tgt=+90.00 act=+0.32 profile=PRECISE
[TURNW] t=25 tgt=+90.00 act=+1.87 err=+88.13 out=+0.650
[TURNW] t=50 tgt=+90.00 act=+7.20 err=+82.80 out=+0.650
...
[TURN] done 1180ms target=+90.00 err=+0.008 overshoot=0.014 peak_o=1.00
```

- `tgt` 是**绝对目标角**（内部连续绕组，左转为正，不回绕），`act` 是当前航向，
  `err=目标−实际`，`out` 是归一化 PID 输出（1.0 = 吃满轮速上限）。
- `[TURN] start` 与 `[TURNW]` 只在 `&ttrace 1` 时输出；`[TURN] done` 每次转向结束都输出（旧行为不变）。
- 带宽：一行约 60 字节 × 40 Hz ≈ 2.4 KB/s，约为 115200 的 21%，只在转向那 1～2 s 内占用；
  **比赛流程不要开**（上电默认关闭，且不会被 `&save` 持久化）。

## 3. 上位机 2.5.8 新增“转向PID”页

位置：`主控串口日志` 接入串口后，切到 **转向PID** 页（第 5 页，在“机械臂控制”之后）。

- **参数区**：kp/ki/kd 输入框（默认 0.045/0.0005/0.0035）；
  `读取当前(&pid)`、`应用到RAM(&kp/&ki/&kd)`、`保存到W25(&save)`、`从W25读回(&read)`、`读取转向状态(&tstat)`。
- **转向区**：`左转90`、`右转90`、`左转180`、`右转180`、自定义 1～360° 左/右转；
  `使能底盘(&en)`、`停止(&stop)`、`航向归零(&zero)`。执行中按钮禁用，收到 `[TURN] done`
  或 8 s 超时后恢复；主控拒绝时显示 `[TURN] rejected` 原因。
- **波形区**：绿虚线 = 目标角度（阶跃），青实线 = 实际角度；窗口最近 10 s，Y 轴自动缩放；
  右上角实时显示 目标/实际/误差/输出/耗时/档位，附“清空波形”。
  `波形记录(&ttrace)` 复选框默认勾选只是“意愿”，只有用户勾选/取消才真正发 `&ttrace 1/0`。
- 面板不自动发任何查询或运动指令；串口仍由“主控串口日志”页独占。

调参建议（仅方向性，最终以实车为准）：
超调大 → 先降 kp 或加大 kd；末端原地抖动/长时间磨 → 看 `overshoot` 与 `peak_o`，
结合 `ST/FB` 标记判断是摩擦死区还是增益过大；稳态偏一侧 → 先 `&zero` 重对航向零，
再排查 IMU 零漂与轮胎打滑，不要用 Pi 积分硬顶。
