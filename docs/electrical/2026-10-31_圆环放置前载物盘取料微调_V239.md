# V239 FINAL：圆环放置前的载物盘取料微调

配套PC2.6.3，继续在`codex/final-gripper-control`决赛分支维护；初赛V237分支不变。本次增加的是**从载物盘夹起物料、随后放到圆环**的取料姿态，不是圆盘取料终点，也不是地面圆环取回姿态。

## 怎么用

1. 烧录V239 FINAL，并关闭旧上位机后重新打开`视觉上位机.cmd`，确认界面版本2.6.3、主控状态V239。
2. 打开“机械臂控制 → 决赛圆盘 / 圆环取放”，点击“读取姿态参数”。
3. “微调姿态”选择 **载物盘取料（圆环放置前）**。
4. 调整5号升降、6号伸缩、DM旋转增量；图中显示原目标、已应用目标和预览目标，并换算相对毫米数。也可用“用当前三轴角度作为目标”。
5. 点击“应用所选微调到RAM”。“移动到预览姿态”和“到载物盘取料姿态”只移动三轴、保持夹爪；**“从载物盘夹取（闭爪）”会真正执行取料并闭爪**。
6. 调好后点击“保存姿态到W25Q64”，看到`[ARM DISC PARAMS] SAVED HAL=0`才算成功。它保存四套已应用参数；尚未应用的滑块预览值不保存。

自动圆环放置前的`arm pick`、圆环页面的“夹取后放置此圆环”及上位机单独取料按钮，共用新载物盘取料目标。三个盘槽共用这套三轴姿态，盘舵机仍负责选槽。

## 与原参数的关系

现在共有四项：等待物料、圆盘夹取物料、放回载物盘、载物盘取料（圆环放置前）。新增取料姿态的基准沿用V238：升降由原`Pose_PickLiftBaseDeg`计算，伸缩−4°、DM162.825°；默认增量全为0。

只修改新取料增量不会改变前三项，也不改变ROUGH/TEMP三个地面圆环的放置/取回坐标、发车START姿态或圆盘纠偏后的RAM等待姿态。原DM±15°提前下降、旋转最终到位及高度3mm闭爪流程、速度/加速度、半程转运和到位/超时逻辑保持，没有新增自动停机条件。载物盘取料和放盘沿用原回缩零位3mm参考容差。

## W25兼容

继续使用决赛专用的倒数10/9个扇区，记录升级为version2，保存四套角度增量，含原magic/长度/序号/CRC和双银行交替校验。

V239能读取V238的version1三姿态记录：在RAM中保留原三套值，新取料增量补0；上电读取不写Flash。用户下一次保存才写version2四姿态记录。最新损坏时可以回退另一份有效记录，包括旧version1记录。

初赛圆环/舵机、导航和PID扇区保持。**旧V238不识别version2四姿态记录**，不要把降回V238理解为仍能读取新格式；回初赛可用包内V237，它忽略决赛记录。新夹爪仍需实车核对，本次未代为烧录、操作机器人或重启上位机。

## 指令

```text
arm disc points
arm disc trim traypick 0 -5 0
arm disc pose traypick
arm pick status
arm pick
arm disc params save
arm disc params load
```

微调顺序为5号、6号、DM电机角度增量。`arm disc pose traypick`保持夹爪；`arm pick`会按已应用姿态取料并闭爪。
