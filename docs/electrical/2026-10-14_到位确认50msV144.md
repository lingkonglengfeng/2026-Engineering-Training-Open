# V144 机械臂到位确认50ms试验

基于V143，减少DM及5/6号常规运动到位后的重复确认等待。

| 路径 | 原条件 | V144 |
|---|---|---|
| DM取放/START转向到位 | 3次新反馈、200ms | 2次新反馈、50ms |
| DM恢复CAMERA到位/最终READY | 3次新反馈、200ms | 2次新反馈、50ms |
| 6号常规取放native到位 | STOP前3次/200ms、STOP后3次/200ms | 满足目标后发送STOP，取消STOP前重复等待；STOP后2次/50ms |
| 6号encoder修正后、CAMERA正常native到位 | 3次新反馈、200ms | 2次新反馈、50ms |
| 5/6号百分比运动STOP后 | 2次稳定新位置，再次到位确认 | 至少1次STOP后的新位置且至少50ms，取消重复计数 |
| CAMERA已在TOP，跳过重复上升 | 3次新位置、200ms | 至少1次STOP后的新位置且至少50ms |
| 堵转反向2mm后的保持 | 3次新反馈、200ms | 2次新反馈、50ms |

共享参数在arm_calibration.h：ARM_MOTION_SETTLE_MS=50、ARM_MOTION_SETTLE_SAMPLES=2、ARM_LINEAR_POST_STOP_SAMPLES=1。50ms为最短窗口，主控查询周期或位置仍在漂移时实际等待可能更长；不会把发送命令成功直接当成已经到位。

DM仍检查实际角度误差1°以内、速度0.05rad/s以内、启用状态与新鲜反馈。线性轴仍检查实际目标、漂移、STOP结果、启用、堵转及保护。6号放置±4°容差和动态读取修正继续保留。

保留零点/示教确认，故障滤波、REACHED但编码器偏差较大时的500ms诊断等待、舵机PWM斜坡及既有夹爪/载物盘动作时间。本版只压缩常规机械臂到位确认；底盘行驶到位与圆盘纠偏确认不改。

保留V142/V143：载物盘取料额外下降3mm、升降180RPM、圆弧165mm、圆盘±16像素/3帧（视觉稳定窗口200ms）。

## 检查和使用

生产C机械臂驱动7组、START/PICK/PLACE、圆盘取料FSM、两轮FSM及自动展开回归通过。边界检查覆盖49ms不完成、50ms收到新反馈才完成、缓存反馈不累计、不提前释放，以及已有故障/保护/漂移路径。Keil0错误、0警告。尚未实车运行、烧录或推送。

烧录Engineering_Training_Project_V144.hex。启动标记CAMERA_DEPLOY_V144包含motion settle50ms/2samples。按 &match reset、&prepare 1、READY后第一次 &ok 测试。观察取放下降开始时DM是否仍摆动、6号停止后是否漂移；记录完整日志用于核对动作间隔。

如需回退，烧录包内rollback_V143.hex。
