# 载物盘385度试验 V44

仅载物盘手动 `test` 入口增加到385°：

```text
&arm table test 385
```

按原500+2000×角度/360换算，385°输出约2639us，50Hz。没有取模成25°，也没有把0..360°重新缩放。默认500us/s斜坡保留；通道失能时第一脉冲直接为请求值，通道已使能则渐变过去。

建议在机构无阻挡时短时观察，可先在360°附近小幅逐步测试370°、385°。若到头、异响或堵转，立即：

```text
&arm table disable
```

查询 `&arm table status`：target约2639us，target_angle约385°，该角度由PWM推算，没有真实舵机反馈。

测试结束返回普通位置，例如 `&arm table test 25`。此操作是否走远路由舵机实际机构和驱动决定，代码不自动保证跨圈最短路径。

正常angle/pulse/go/save范围仍为500..2500us及0..360°；扩展试验值不能保存到1/2/3号预设。夹爪不支持385°，载物盘test超过385°也拒绝。扩展入口要求原始500..2500us、360°、非反向映射，避免改过span后错误外推。

2639us超出原2500us上限。此次只是允许输出试验脉宽，不代表舵机一定支持385°、多圈定位或跨圈路径。尚未烧录或操作实物。

回归包含385°PWM输出、超范围拒绝、夹爪范围保持、原预设换算和返回普通位置；蓝牙143条可达指令检查通过。Keil构建0错误0警告。
