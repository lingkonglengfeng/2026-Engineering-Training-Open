# V245 PRELIM / FINAL，PC2.6.7：统一功能，保留参数和取料顺序

按用户确认，两套代码统一使用决赛功能，仍提供初赛和决赛两个独立固件。两分支公共代码一致，仅 `Core/Inc/competition_profile.h` 中 `COMPETITION_PRELIMINARY` 默认值不同：初赛1，决赛0。

## 现在相同的行为

- 统一 `&prepare`：机械臂回START、陀螺去零漂，不确定启停区。等 `WAIT_START_OK` 后，PD1短按松开选1号、按住至少1000ms松开选2号并发车；`&OK 1/2`同义，裸OK默认1号。当前位置和朝向在接受发车时绑定。
- 上位机PC2.6.7统一准备和1/2号发车按钮，通用“圆盘 / 圆环取放”页，连接状态显示实际主控初赛/决赛参数区。
- 等待物料、圆盘夹取、放回载物盘、载物盘取料四姿态均可微调、应用到RAM、保存W25，上电加载并用于自动流程。
- 圆盘进框后：升降或DM目标不同时直接接近夹取姿态，不插入TOP/转运抬升；随后伸缩到本版本目标，实测半程闭爪。等待与夹取升降/DM相同时直接伸缩。
- 直行里程段的航向超差停机门限统一5°；其他原有检查保持。
- 圆盘独立纠偏、纠偏后到RAM等待姿态、三轴与舵机调试、载物盘参考行程容差、相机小屏标注回显均相同。

本次不调整速度、加速度、抓取框、识别阈值、半程闭爪、命令重发或低位旋转限制，不新增自动停机条件。

## 仍然分开的内容

| 内容 | 初赛PRELIM | 决赛FINAL |
| --- | --- | --- |
| 圆环放料时从载物盘取料 | 1→2→3 | 3→2→1 |
| 圆环/舵机参数区 | 倒数8/7扇区，保留V237格式 | 倒数12/11扇区，保留V243/V244记录 |
| 四姿态参数区 | 新增倒数14/13扇区，8MB地址0x7F2000/0x7F3000 | 原倒数10/9扇区，0x7F6000/0x7F7000 |
| 默认与已保存姿态 | 四姿态无记录时增量0，基准还原V237；有效初赛圆环/舵机记录优先 | 原四姿态及圆环/舵机记录继续读取 |

原料台装盘顺序、ROUGH从地面取回载物盘的顺序仍为1→2→3。颜色到目标环的映射和第二轮同色叠层保持。PID/导航区域仍共用。

初赛不会读取或迁移决赛四姿态区域；初赛保存不会写决赛区域。决赛原首次迁移和初赛准备标志保持；决赛准备初赛时不改初赛新增四姿态区域。

## 升级与调参

1. 若还没有执行过W25初赛参数准备，先运行V245 FINAL和PC2.6.7，在空闲时选择初赛参数并准备，看到 `[ARM PROFILE] READY target=PRELIM active=FINAL HAL=0` 后再刷初赛。已有准备标志时保留之后保存的初赛微调。
2. 从 `比赛版本/初赛/固件/` 选择V245_PRELIM，或从决赛目录选择V245_FINAL；旧V237/V244归档仍保留，但不包含本次统一功能。
3. 两套都使用自己的“启动初赛/决赛上位机.cmd”，界面版本PC2.6.7。读取状态应显示V245和PRELIM/FINAL。
4. 初赛首次使用四姿态时没有独立保存记录，使用原初赛基准加零增量；在“圆盘 / 圆环取放”读取参数、分别应用微调到RAM，再保存姿态到W25。圆环/舵机仍使用普通主控参数保存按钮。
5. 切换参数按钮选当前版本时读取本版本；选另一版本时保存当前已应用参数并准备/核对目标区，不把另一套参数载入当前RAM。它不切换代码，仍须烧录另一套固件。

初赛中选择“决赛参数”会保存初赛并核对已存在的决赛圆环区；不会初始化或覆盖决赛记录。目标区未就绪时返回FAILED，机械动作流程没有新增停机判断。
