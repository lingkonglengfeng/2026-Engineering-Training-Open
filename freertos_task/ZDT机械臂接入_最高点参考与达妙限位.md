# ZDT机械臂接入：最高点参考与达妙软件限位

本版已接入三轴驱动/标定模块至Keil和ArmTask，串口arm/dm请求统一交给ArmTask处理。5号升降、6号伸缩支持手动控制、参考点记录、绝对行程百分比闭环控制及旋转限位；尚未实现自动夹取/放置状态机。初始化只发读查询，不使能轴或启动舵机PWM。

## 当前约定

- ID5升降，正逻辑方向为上，负方向为下；ID6伸缩，正为伸出，负为缩回。5号默认dir=0，6号默认dir=1（按本次伸出负计数记录）；实际方向通过arm dir确认，不默认电机CW必定是机构向上。
- 每次启动，用户手动放到最高点，先使能保持，再用arm top 5记录稳定新反馈。最高点是0mm；状态中的down_from_top为下降量。
- **从最高点下降超过100mm：达妙目标角仅允许软件零点的[-20°, +20°]。** 当前按这个方向实现；高于这个阈值使用整体旋转范围，初始化为[-180°, +180°]，可在失能时配置。
- 参考/比例缺失或5号反馈过期时，只允许目标±20°，不会把未知高度当成安全高位。已使能的越界目标/角度会取消并请求停止升降；不自动把转盘甩回0°。
- 实际角度检查额外留0.5°量化/稳定余量，目标值仍严格±20°。参考最高点且反馈新鲜时不允许再向上运动；已标定控制比例时也检查向上目标是否超过最高点。
- 零点、比例和参数目前留RAM，掉电后需重新建立最高点参考。记最高点不写电机Flash、不发送自动寻顶动作。

源码默认阈值在`Core/Inc/arm_task.h`：`ARM_TOP_DROP_LIMIT_MM`、`ARM_LOW_ROTATION_MIN_DEG`和`ARM_LOW_ROTATION_MAX_DEG`。调试时直接用`arm guardtop`修改，无需重新编译。

软件零点应设在机械上允许避让的转盘方向，20°围绕这个arm零点解释，不能随意重定义物理方向后仍把它当原有避让区。旧dm zerohere/Flash-zero、MIT/速度/raw控制在统一入口被拒绝，以免绕过限位；常规用arm zero dm、arm rotate/by。dm pos仍可用，但目标须通过同一高度/角度判断。

## 首次标定流程

### 已记录的整行程数据（2026-10-04）

用户确认本次测量过程为：升降机构放到最高点上电，失能后手动降到最低点；最低点日志为`id=5 raw=-219505`。按用户要求，将该值记录为5号轴上下整段行程，采用最高点相对计数为0的参考。

6号前后伸缩轴：用户提供“到最外端为-728.5°”，本记录按最内端为0°、最外端为-728.5°解释。此轴计数是根据角度换算的近似值，不是直接读取的端点计数。

| 最高点/最内端相对计数 | 0（本次采用的最高点参考） | 0（本次采用的最内端参考） |
| 最低点/最外端相对计数 | -219505 | 约-132619（由角度换算） |

这些整行程和毫米值已写入固件默认参数，但不会自动假设当前处于零点。原日志`zero5=0`、`TOP5 valid=0`，没有记录运行时最高点；运行时仍用`arm top 5`建立实际参考，最低点预计为本次最高点反馈计数减219505。219505是反馈计数，不能直接当作位置命令脉冲数。按约240mm行程换算，下降反馈比例默认约为-914.604167counts/mm，仍可用`arm feedback 5 ...`覆盖；该毫米比例受用户行程粗测精度限制。

6号运行参考可在最内端用`arm zero 6`建立，最外端预计为该参考反馈减约132619计数。这里的负号是电机反馈方向；`arm pulse/mm 6`的正逻辑仍定义为伸出，应另外验证`arm dir 6`的电机方向映射。按约178mm行程换算，伸出反馈比例约为-745.052684counts/mm（现有`arm feedback`仅支持5号轴）。两轴的控制脉冲/圈尚未提供，因此不把这些反馈比例直接写入`arm scale`。

### 百分比位置控制（已加入固件）

| 位置 | 5号下降百分比 | 6号伸出百分比 |
| --- | --- | --- |
| 0% | 最高点 | 最内端 |
| 50% | 下降约120mm | 伸出约89mm |
| 100% | 最低点，下降约240mm | 最外端，伸出约178mm |

采用相对端点的反馈计数定义绝对行程百分比：5号为`(最高点反馈-当前反馈)/219505*100`；6号为`(最内端反馈-当前反馈)/132619.377778*100`。例如目标50%表示到半行程位置，而不是在当前位置继续运动半行程。6号全行程计数后续可用直接端点反馈替换角度换算值。

百分比与毫米使用同一电机位置反馈，换单位不会提高重复定位精度。百分比不需要准确的毫米总行程，适合示教抓取/放置姿态；实测毫米仍用于解释避让高度和100mm旋转联锁。按240mm下降行程，100mm对应下降41.67%；原“下降超过100mm限制±20°”约等于“下降超过41.67%限制±20°”。

百分比默认值位于`Core/Inc/arm_calibration.h`的`ARM_LIFT/REACH_FULL_TRAVEL_COUNTS`和`ARM_LIFT/REACH_FULL_TRAVEL_MM`。运行时可用`arm span 5|6 <signed_counts>`修改整行程反馈计数，用`arm travel 5|6 <mm>`修改实际行程；5号这两项会同步更新下降毫米反馈比例。参数留在RAM，掉电恢复源码默认值。

百分比使用独立的非阻塞动作：先停止旧动作、等待新反馈，再按实际位置误差控制速度，临近目标减速，误差在±0.5个百分点内且后续两次反馈稳定才报`PERCENT ARRIVED`。速度上限由`arm speed 5|6 <rpm>`设置，默认60RPM。反馈每100ms读取，动作轮询仍在ArmTask的10ms循环。目标不写电机Flash，也不依赖控制脉冲/mm。重复发送同一目标不会累加位移；运动期间另一目标返回busy，等待到位后再发。一次只执行一个线性百分比动作。

每次启动的示教示例（115200 8N1，各条等待执行结束）：

```text
# 手动放5号到最高点，6号到完全缩回位置
&arm enable 5
&arm enable 6
&arm top 5
# 等UPPER RECORDED
&arm zero 6
# 等WORK ZERO RECORDED
&dm disable
# 转盘摆到避让零方向，等待新反馈确认静止/失能
&arm zero dm
&arm enable dm
# 保持转盘在±20°内，维持反馈，再做超过41.67%的下降
&arm pct 5 50
# 等PERCENT ARRIVED
&arm pct 6 50
# 等PERCENT ARRIVED
&arm status
```

百分比0%/100%命令会到达端点附近的到位带，不靠堵转撞端点；参数来自本次实测，仍需台架核对。没有参考点或新反馈时显示UNKNOWN并拒绝运动；状态同时显示pos_rx/flags_rx和数据年龄，避免把6号没有反馈误认为位置为0%。动作中反馈中断、轴失能/堵转、方向不符或超时会停止该轴并报原因。`arm stop`取消全部动作，`arm disable 5|6`会取消该轴正在进行的动作。

### 操作步骤

调试口115200 8N1。下面是分步操作，不要一键连发。尖括号必须替换成实际值。

1. 机构手动放最高并支撑好；发送arm enable 5、arm top 5，等UPPER RECORDED，再arm status。
2. 发送dm disable，等新反馈确认静止/失能，把转盘摆到机械安全零方向后arm zero dm。记录零点要求新反馈；不要把写电机Flash当普通置零。
3. 先确认5号脉冲方向。arm pulse 5 <小量负脉冲>按约定应下降；若相反，停止后arm dir 5 1（默认0），重新验证。最高点处正逻辑向上会被拒绝。
4. 在转盘保持±20°内的情况下，用脉冲下降一段，**实际测量这次从最高点下降的毫米数**。例如实测100mm时发arm dropcal 100。命令先停止轴、获取稳定新位置，输出带符号的down feedback和可复制的arm feedback 5 ...。
5. 控制比例另设arm scale 5 <控制脉冲/mm>：本次有效相对控制脉冲量绝对值/实际移动毫米。它和编码器反馈counts/mm不是同一个数，不能用65536当控制脉冲/mm。
6. 把下降量、实际电机方向、比例及限位效果逐项核对后再做较大毫米移动。每条位置命令完成后先看状态，再发下一条，不用快速连发相对脉冲代替轨迹状态机。

若已有可信的反馈比例，以后每次启动输入arm feedback 5 <上次输出的带符号counts/mm>，再在最高点arm top 5；不用重新标定机械最低点。方向/传动/驱动器配置变动后应重新测量这个比例。未知比例时最高点静止可以识别0；离开最高点后不能推算100mm，只按未知高度限制。

## 已接入指令表

普通有线arm命令用CRLF结束，也支持&arm形式。均由ArmTask执行；HAL=0通常表示入队，不表示已到位。

| 指令 | 用途 |
| --- | --- |
| `arm help` / `arm status` | 帮助，5/6反馈、零点、最高点下降量及限位状态 |
| `arm enable 5` / `arm enable 6` | 单轴使能，不自动运动 |
| `arm disable 5` / `arm disable 6` | 单轴失能；与停止保持力矩不同 |
| `arm pulse 5 <signed>` / `arm pulse 6 <signed>` | 相对脉冲，上/伸为正，下/缩为负 |
| `arm mm 5 <signed_mm>` / `arm mm 6 <signed_mm>` | 相对毫米，需各自控制脉冲/mm比例；0不是回零 |
| `arm pct 5 <0..100>` / `arm pct 6 <0..100>` | 绝对百分比目标；5号0%=最高，6号0%=完全缩回；需要已记录零点和使能 |
| `arm pct 5` / `arm pct 6` | 读取当前百分比；`arm percent`同义 |
| `arm span 5 <signed_counts>` / `arm span 6 <signed_counts>` | 修改0%到100%的带符号反馈计数，默认-219505/-132619.378 |
| `arm travel 5 <mm>` / `arm travel 6 <mm>` | 修改整行程毫米，默认240/178；不是运动命令 |
| `arm scale 5 <value>` / `arm scale 6 <value>` | 控制脉冲/mm |
| `arm speed 5 <value>` / `arm speed 6 <value>` | 相对位置命令速度字段/百分比速度上限；实际速度需台架核对 |
| `arm dir 5 0` / `arm dir 5 1` | 选择升降CW/CCW映射，停止后配置；6同样支持 |
| `arm top 5` / `arm zero 5` | 把手动摆好的最高点记录为参考/工作零点 |
| `arm dropcal <measured_mm>` | 用从最高点实测下降量标定反馈比例，不猜毫米 |
| `arm feedback 5 <signed_value>` | 输入已验证反馈counts/mm，符号必须保留 |
| `arm zero 6` | 当前稳定位置作伸缩轴RAM计数零点，不覆盖机械端点 |
| `arm guardtop 100 -20 20` | 设置最高点下降阈值和旋转区间 |
| `arm guardoff` | 显式关闭软件高度联锁，仅调试配置，不是常规动作 |
| `dm disable` → `arm zero dm` | 达妙失能、静止后设arm软件角度零点 |
| `arm enable dm` | 经高度判断使能 |
| `arm rotate <deg>` / `arm by <deg>` | 绝对/相对arm角度，受高度/角度限位 |
| `arm limit <min_deg> <max_deg>` | 失能时修改整体角范围，必须包含受限区间 |
| `arm stop` / `stop` / `&STOP` | 通知机械臂所有者停止并丢弃待执行命令，保持步进使能和夹爪当前PWM |

最高点参考失败、没有新反馈或位置还在变化时不会记录成功。arm zero 6建立计数参考，百分比使用时应在完全缩回位置记录；`arm pct 6 0`返回该参考位置，`arm pct 5 0`返回最高点附近。毫米命令仍是相对量。正常停止不自动清除已记录参考或比例。

## 接入细节与范围

- FDCAN2仍只有既有RX FIFO读取者，ISR把ID5/6的合法位置/状态帧投递ArmTask，并保留真实接收tick；不是在串口打印后给旧数据刷新时间。
- CAN2各次HAL TX FIFO写入用短中断临界区串行化；没有跨日志/等待持锁。ArmTask控制DM，底盘任务只投递命令。
- 原test/zpos对ID5/6被拒绝，改用arm命令，避免绕过升降预测联锁。其他电机诊断不变。限位会在目标入口检查，也在周期中检查越界/反馈失效。
- STOP使用独立请求，不受普通命令队列已满影响，并取消使能握手及旧命令。不是硬件防坠保证；总线异常时不能以软件发送成功推断机械已停止。
- ArmTask栈升至4096B，10ms节拍；舵机依赖模块已链接但上电不输出，载台槽预设要求示教。本轮没有自动夹取或改比赛补偿/相机协议。
- 实测仍需核对ID、驱动器协议兼容、轴方向、反馈比例和物理避让角。本文的100mm、±20°是用户指定的暂定值，软件利用电机反馈换算高度。
