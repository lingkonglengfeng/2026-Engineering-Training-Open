# CAM1圆环/圆盘采样

本目录用于相机端算法开发、专项调试或历史对照。整车双路部署从 [视觉总览](../README.md)进入。

将 `main.py` 单独上传MaixVision运行，或使用交付包中的 `vision_sample.py`。先停止CAM1原识别程序；本脚本占用同一个相机和灯，不与识别程序同时运行。

脚本仅调用相机、现有灯控、屏幕触摸和图片存储，不加载圆环/圆盘检测器、OpenCV、模型或车辆UART。主控固件无需更新。

屏幕上方点击 `RING` / `PLATE` 切换类型和补光；下方 `SNAP` 保存单张，`AUTO` 切换每秒一张的自动采集。切模式会暂停AUTO，需要重新开启。每次切灯/启动相机后至少等待0.5秒，然后清缓存、读取新帧；早于等待期限开始读取或来自旧模式的帧拒绝保存。缺少clear_buff的旧SDK禁止采样并显示原因，不能把旧光照标成新类型。0.5秒是等待策略，不保证所有环境下AE已经完全稳定。

- 相机原图RGB480×360、请求30FPS，沿用当前统一视觉服务的原始配置。
- 圆环：A19/PWM7，20kHz，15%亮度；圆盘：同一路灯50%亮度。保持自动曝光/增益的原默认行为，不修改ISP亮度。
- 每次启动建立 `/root/vision_samples/日期时间_编号/`；其下 `ring/`、`plate/` 保存无文字、无检测框的PNG。
- 圆环保存480×360原图；圆盘额外保存同一帧缩放的 `_320x240.png`，对应当前圆盘算法的处理尺寸。
- `samples.jsonl` 记录每张图片的时间、模式、补光占空比、PWM频率、尺寸和文件名。导出整个会话文件夹用于后续优化；建议分别拍空环、带物料、遮挡、反光和偏出视野等场景。
- 自动采集最多1000张，避免无人值守持续占满存储。保存失败会暂停自动采集并显示错误；退出关闭灯光、相机和屏幕。
- 保存使用独占编号，不覆盖已有PNG；图片与圆盘缩放图先写临时文件，元数据成功后才计数。失败组清理，失败编号不复用，可能出现编号空缺；`.reserved`是失败编号保护文件，可保留。文件名与图像记录以samples.jsonl为准。突然断电无法保证整组事务，应核对清单后使用数据。

维护 `sampler.py`，运行 `python tools/build_vision_sampler.py` 生成独立 `main.py`。生成器嵌入当前CAM1灯控原代码，后续正式程序改灯光后可重新生成同步。默认输出路径和采样间隔位于文件顶部。

审查版启动 `2026-10-13-sampling-audit-v2`。本次12项离线检查通过，包括真实PNG像素/同帧缩放、模式与读取时间隔离、灯失败/不支持清缓存禁止保存、编号冲突/保存中途失败、元数据短写回滚、实体屏幕contain映射，以及正常/异常资源关闭。未连接MaixCAM验证存储、触屏或PWM。运行前停车并停止比赛/正式CAM1程序；采样脚本不回传主控视觉业务数据。

API依据：[Maix图像保存](https://wiki.sipeed.com/maixpy/api/maix/image.html#save)、[Maix触摸屏](https://wiki.sipeed.com/maixpy/api/maix/touchscreen.html)。
