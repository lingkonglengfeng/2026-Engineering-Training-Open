## 单片机切换

普通任务调用，HAL_OK表示已排队，HAL_BUSY表示已有未完成请求；通过后续任务周期检查pending=0、confirmed=1、result=0，再使用新位置。不要在ISR或忙等循环中调用。统一入口支持圆盘模式8，target固定0，按ACK边界清旧观测再发布新切点。

```c
/* USART1：工位1，蓝色物料，20Hz。 */
Vision_RequestMode(1, VISION_MODE_MATERIAL, 1, 3, 20, 0);
/* 其他阶段单独调用，不能连续排队多条。 */
Vision_RequestMode(1, VISION_MODE_RING, 2, 2, 20, 0);
Vision_RequestMode(1, VISION_MODE_PLATE, 1, 0, 20, 0);
Vision_RequestMode(1, VISION_MODE_STOP, 0, 0, 0, 0);

vision_camera_state_t state;
vision_pixel_t point;
uint32_t age_ms;
if (Vision_GetCameraState(1, &state) && !state.pending && state.confirmed && state.result == 0) {
    if (Vision_GetPixel(1, VISION_TYPE_RING_PX, &point, &age_ms) && point.valid) {
        /* 图像dx/dy：右正、下正。observation_id用于新观察判重。 */
    }
}
```

物料target工程编号：1红/2黄/3蓝/4绿/5浅蓝/6黑；原标定文件内部5黑/6浅蓝，程序在线上映射。target=0首次选择颜色后保持该颜色，不提供同色多目标稳定UID，建议指定颜色。圆环target只能0或2，输出中间组ID2；圆盘target固定0，读取PLATE_PX切点X/Y，仅控制切线时读取Y。STOP target/hz=0；活动模式hz=1～50，flags=0。station仍为0通用、1物料区、2粗加工、3最终暂存、4二维码区、5/6始停区，表示主控上下文，不是视觉工位识别。

统一入口不提供触摸取样按钮；现场取样先运行原物料main.py保存颜色样本，再停止它并运行统一入口。未实现毫米/航向/二维码/测距服务；模式4/5失败结果3，其余不支持模式失败结果1。资源初始化失败结果7，尽力恢复旧模式，无法检测时只发无效坐标。

## SET、ACK和心跳

沿用[固定8字节协议](../../docs/electrical/MaixCAM_STM32_统一8字节串口协议_v0.1.md)，帧头6B，TYPE、META、4字节载荷、CRC8。SET=0x80，ACK=0x81，心跳=0x82。ACK回显请求号和目标ID；每次新观察的位置使用独立图像序号。图像坐标小端int16×10、右/下正，界面仍是屏幕右/上正。

| HEX请求 | 内容 |
|---|---|
| `6B 80 03 02 01 14 00 66` | 工位1蓝色物料，20Hz，SEQ0 |
| `6B 80 0A 03 02 14 00 B6` | 工位2中间圆环，20Hz，SEQ1 |
| `6B 80 10 08 01 14 00 6E` | 圆盘切点，工位1，20Hz，SEQ2 |
| `6B 80 18 00 00 00 00 AF` | STOP，工位0，SEQ3 |

主控500ms等ACK，最多重试2次，总3次，失败本地result=254。相机2秒内同完整请求只重发ACK，不重开相机。心跳约500ms（长检测/驱动调用会延后），主控1500ms失联、未知版本或意外模式/工位取消确认，运行流程须重发SET。位置200ms无更新失效。检测中收到SET会在发送前读取并丢弃旧结果；短写放弃旧半帧后异步等待55ms，让接收器50ms超时，再发送ACK/新位置。不插入CRLF、不sleep，退出失效依靠主控超时兜底。
