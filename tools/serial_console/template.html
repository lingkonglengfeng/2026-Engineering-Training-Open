连接与使用

使用Chrome或Edge打开本HTML。主控默认115200，USB-TTL TX接PC11/RX，RX接PC10/TX，共地。

主控与相机端口请选择正确接口；相机SET测试先从主控断开串口，避免双主机同时发送。页面连接时不发送任何运动或使能指令。

电脑串口软件或其他网页占用同一端口时，请先关闭其连接。

底盘

点动控制 按住移动 · 松开停止 · 每次最多2秒

STOP是串口指令；通信断开时无法保证停车，请保留实体急停。

自定义发送

相机 SET / ACK 调试

选择“相机 · 8字节协议”后可发送；生成CRC，不附加换行。

收发监视

RX 0 BTX 0 BCRC错误 0

TX表示字节已交给串口驱动；执行结果以主控回复为准。暂停只暂停画面，接收仍继续，最近5000条可导出。

本地离线运行，无CDN · 指令依据当前工程源代码生成 · 参考 CoolTerm 的收发监视与日志功能；串口使用 Web Serial API。
